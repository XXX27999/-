# DS 剩余时间与服务器时间的端侧限制（GetDSRemainingTime 仅服务器可用）

- 类型：官方确认 + 项目实测排错
- 主题：`UGCGameSystem.GetDSRemainingTime` / `GetServerTimeSec` / `GetServerWorldTimeSeconds` 的端侧适用范围；客户端显示「服务器剩余时间」的正确同步模式

## 一、三条结论

1. **`UGCGameSystem.GetDSRemainingTime()` 生效范围是服务器，单位秒，客户端调用必报错。**
   官方文档原文：“获取DS剩余时间，单位秒 / 生效范围：服务器”。

2. **客户端调用的实际报错不是返回 nil，而是 Lua 运行时异常（会被 pcall 吞成 nil）。**
   项目实测（主界面大厅 UI 客户端刷新）：

   ```
   【AuctionHubUIService+ApplyCountdown】错误 获取DS剩余时间失败
     error=ugc/UGCAPI/UGCGameSystem.lua:2628: attempt to index a nil value (global 'UGCDSShutdownManager')
   ```

   原因：该接口内部依赖全局 `UGCDSShutdownManager`，该管理器只在 DS 侧存在，客户端为 `nil`。
   **排错要点**：UI 侧表现只是“倒计时恒为占位值 `--:--`”，真正的错误只在 pcall 的 error 分支日志里，务必把 error 打出来，否则会误判成“接口返回 0”。

3. **客户端可用的时间接口是 `UGCGameSystem.GetServerTimeSec()`（服务器&客户端）与 `GameState:GetServerWorldTimeSeconds()`（同源服务器世界时间）。**
   `UGCGenericMessageSystem...UGCDSShutDownManager.DSCloseNotify` 也是服务器侧事件，不能作为客户端数据源。

## 二、正确同步模式：服务端换算绝对时间戳，客户端同源推算

不能在客户端直接取 DS 剩余时间；应让服务端把它换算成**绝对时间戳**，随已注册的复制属性下发，客户端用**同源时钟**做差：

```
服务端（HasAuthority=true）：
    endStamp = 当前服务器世界时间 + UGCGameSystem.GetDSRemainingTime()
    → 写入复制属性（如 AuctionPublicState.DSEndTimeStamp）

客户端：
    remain = DSEndTimeStamp - GameState:GetServerWorldTimeSeconds()
    → 格式化 mm:ss
```

要点：

- **必须用同一时钟做差**：服务端用 `GetServerWorldTimeSeconds()` 作基准，客户端也只能用 `GetServerWorldTimeSeconds()` 推算；混用 `GetServerTimeSec()` 会因时基不同而算出错值。
- **只需换算一次**：绝对时间戳不随时间失效，无需每秒 RPC；DS 中途不变的情况下，一次复制即可支持全程递减显示。
- **公共状态每次重建表时字段会丢失**：若 `PublishPublicState` 每轮 `new` 一张表（本项目即如此），必须每次发布都带上该字段，不能只在 BeginPlay 写一次。

## 三、代码模板

```lua
-- 服务端：换算绝对时间戳（仅服务器可调用 GetDSRemainingTime）
local remainOK, remainOrError = pcall(UGCGameSystem.GetDSRemainingTime)
if remainOK and (tonumber(remainOrError) or 0) > 0 then
    publicState.DSEndTimeStamp = nowWorldTime + tonumber(remainOrError)
end

-- 客户端：同源推算
local endStamp = tonumber(publicState and publicState.DSEndTimeStamp) or 0
if endStamp > 0 then
    local remain = math.max(0, math.ceil(endStamp - gameState:GetAuctionServerTime()))
    display = string.format("%02d:%02d", math.floor(remain / 60), remain % 60)
end
```

## 四、排错清单

| 现象 | 优先排查 |
| --- | --- |
| 倒计时恒为占位值，日志无 error | 是否用 pcall 吞掉了 error；把 `error=` 打全 |
| 报错 `attempt to index a nil value (global 'UGCDSShutdownManager')` | 客户端调用了服务器专用接口，改为服务端换算后复制 |
| 拿到时间戳但显示固定值不递减 | 客户端时钟与服务端基准不同源，统一用 `GetServerWorldTimeSeconds()` |
| 首次发布有时间、之后变 0 | 每次 `PublishPublicState` 重建表导致字段丢失，需每次写入 |
