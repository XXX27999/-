# FProgressBarStyle

Represents the appearance of an SProgressBar

## Fields

| Name | Type | Description |
| --- | --- | --- |
| BackgroundImage | [FSlateBrush](../FS/FSlateBrush.md) | Background image to use for the progress bar |
| FillImage | [FSlateBrush](../FS/FSlateBrush.md) | Foreground image to use for the progress bar |
| MarqueeImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use for marquee mode |
