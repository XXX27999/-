## 1.28.13 更新说明

### 编辑器

#### 功能更新

- 新增 [经典团竞](../玩法案例及模板/团竞模板/20015_经典团竞玩法.md) 和 [军备团竞](../玩法案例及模板/团竞模板/20016_军备团竞玩法.md) 两个案例模板
- 新增 [商城模板](../商业化及功能模板/20026_商城模板.md) 与 [抽奖模板](../商业化及功能模板/20027_抽奖模板.md)，助力开发者快速构建商城与抽奖系统，丰富玩法商业化功能
- 全新 [天气系统控件](../新手入门/游戏场景/225_天气系统.md)，实现更精细的光照调控与动态天气效果
- 支持怪物之间的 [动画蓝图复用](../进阶内容/GamePlay系统/怪物系统/20017_怪物动画蓝图复用功能.md)，不同骨骼的怪物都能正确播放姿态动画
- [武装载具](https://developer.gp.qq.com/wikieditor/#/catalog/20025) 已支持动态切换武器，以及设置指定武器的可用性

#### bug Fixes

- 修复更换角色Mesh概率出现崩溃的问题
- 修复Lua资源引用工具的空面板问题
- 修复骑马动画在部分场景下出现APose的问题
- 修复海岛大地图PIE调试下物资刷新点位异常及移动端不刷新物资问题
- 修复多Predict组件触发崩溃问题
- 修复接入二次匹配功能的玩法无法进入默认子模式的问题

### 管理平台

#### 功能更新

- 开发者可上报玩法灰度期间的 [自定义行为数据](../进阶内容/20023_自定义行为统计.md)，管理平台支持上报数据的统计提取
- 优化开启测试的添加白名单功能，单玩法下可统一管理白名单，不用再区分版本
- 新增玩法信息更新生效状态，方便开发者了解信息更新的生效情况
- 新增玩家反馈预警消息通知，帮助开发者快速获取玩法的主要bug反馈
- 新增签约消息提醒，帮助开发者及时进行相关签约
- 新增抢先体验上下架状态展示，帮助开发者了解玩法在抢先体验的上下架状态
- 异常上报和项目日志打通团队查看权限，团队内上传玩法的异常上报、项目日志都可以查看了
- 优化运营数据页面展示，帮助更高效查看相关运营数据
- 供应商入驻流程和玩法解绑，可以直接通过账号管理页面进行供应商入驻

### API

#### 功能更新

- 新增进入/退出跳伞状态的函数 [``TryEnterParachuteState``](https://developer.gp.qq.com/api/#/searchContent/UGCPlayerPawnSystem?classDetailShow=true&path=class%2Fdetail%2FOthers%2FUGCPlayerPawnSystem.json&isSelect=1&apiEnc=%5B%22%E7%B1%BB%22%5D&apiLabel=UGCPlayerPawnSystem&autoJump=TryEnterParachuteState) 与 [``ExitParachuteState``](https://developer.gp.qq.com/api/#/searchContent/UGCPlayerPawnSystem?classDetailShow=true&path=class%2Fdetail%2FOthers%2FUGCPlayerPawnSystem.json&isSelect=1&apiEnc=%5B%22%E7%B1%BB%22%5D&apiLabel=UGCPlayerPawnSystem&autoJump=ExitParachuteState)
- [``HideBoneByBoneName``](https://developer.gp.qq.com/api/#/searchContent/UGCPlayerPawnSystem?classDetailShow=true&path=class%2Fdetail%2FOthers%2FUGCPlayerPawnSystem.json&isSelect=1&apiEnc=%5B%22%E7%B1%BB%22%5D&apiLabel=UGCPlayerPawnSystem&autoJump=HideBoneByBoneName) 支持动态隐藏玩家Pawn的指定骨骼

#### bug Fixes

- 修复 ``SetReloadTime`` 和 ``SetTacticalReloadTime`` 在枪械装配快速弹匣或快速扩容弹匣时，换弹时间异常问题
- 修复枪械调用 ``StopFire`` 概率性无法停止开火的问题
