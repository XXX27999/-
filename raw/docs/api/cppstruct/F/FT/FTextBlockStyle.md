# FTextBlockStyle

Represents the appearance of an STextBlock

## Fields

| Name | Type | Description |
| --- | --- | --- |
| Font | [FSlateFontInfo](../FS/FSlateFontInfo.md) | Font family and size to be used when displaying this text. |
| ColorAndOpacity | [FSlateColor](../FS/FSlateColor.md) | The color and opacity of this text |
| ShadowOffset | [FVector2D](../FV/FVector2D.md) | How much should the shadow be offset? An offset of 0 implies no shadow. |
| ShadowColorAndOpacity | [FLinearColor](../FL/FLinearColor.md) | The color and opacity of the shadow |
| SelectedBackgroundColor | [FSlateColor](../FS/FSlateColor.md) | The background color of selected text |
| HighlightColor | [FLinearColor](../FL/FLinearColor.md) | The color of highlighted text |
| HighlightShape | [FSlateBrush](../FS/FSlateBrush.md) | The shape of highlighted text |
| UnderlineBrush | [FSlateBrush](../FS/FSlateBrush.md) | The brush used to draw an underline under the text (if any) |
