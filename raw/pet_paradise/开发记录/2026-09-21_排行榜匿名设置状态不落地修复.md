## 三、数据存储链路与断点

| 层 | 位置 | 结论 |
| --- | --- | --- |
| 引擎内存 | `RankingListManager` GamePart 的全局 Actor；`SetRankListPrivacy(UID, State)` / `GetRankListPrivacyByUID(UID)` | **服务端在 `AreaID` 为 nil 时直接返回，写入被丢弃** |
| 引擎 RPC | 客户端 `RankingListComponent:SetPrivacyState` → 引擎 `Server_SetRankListPrivacy` | 消息已送达 DS，被 GamePart 丢弃 |
| 工程存档 | `ControllerExitGame.SaveAllPlayerArchive` → `RankPrivacyHelper.CaptureIntoArchive` | 读引擎值 → 恒为 0 → **上一轮落库为空转** |
| 官方 UI | `UGC_RankingList_Set_Popup_UIBP:InitUI` 每次打开都 `GetSelfPrivacySetting()` | 读引擎值 → 必然渲染「关闭」 |

`AreaID` 来源：Python API 分类索引（69 类 858 方法）中**无任何 AreaID 相关接口**；工程内检索 `AreaID` **0 命中**；官方文档检索 `AreaID` **0 命中**。据此推断其由平台/引擎在 DS 启动阶段注入，**该链路属知识库未覆盖**。

## 五、过程中修掉的自引入缺陷（留档）

P6a 最初把桥接函数插在文件末尾。Lua 的 `local` 函数**先声明后使用**，而 `Select` / `Confirm` / `InitUI` 定义在其之前，函数体里的引用会解析成全局 `nil`，触发 `attempt to call a nil value`。已用 `fix_rank_privacy_scope.py` 把补丁块整体上移到类表声明之后、`Construct` 之前，并加了「补丁块索引 < `Construct` 索引」的磁盘断言。**结论：向官方脚本注入本地函数时，插入点必须早于第一个调用方。**
