## 一、现象

关闭图鉴 UI 后，屏幕右下角的「罐子图片」消失。用户提供的截图为角色选择界面，右下角木地板上有一个带绿植的花盆。

## 二、排查：该元素不在本项目内

| 检查项 | 结果 |
| --- | --- |
| `UGCmap.umap` 内 `pot/plant/flower/vase/urn/bush/fern` 相关资产路径 | 只有 `Logging_Grass01_SM_FoliageType` 与 `POT)`（PIVOT 片段），无任何花盆/陶罐 |
| 各 UI Lua 的 `---@field` 图片控件 | `CollectibleCodexUI`、`AuctionTestUI`、`AuctionCharacterSelectUI`、`AuctionHouseSelectUI`、`CharacterPropSelectTestUI` 均无对应装饰图控件；`ZhuJieMian` 只有 保底金/金币/参考图/头像框/帮助/每日任务/顶部UI/玩家名称/服务器剩余时间 |
| 贴图目录 `Asset/TuPian` | 无花盆/陶罐素材 |

结论：该花盆属于**和平原生 UI 或原生场景元素**（待查证具体归属），因此问题不在项目贴图或控件，而在图鉴挂载/卸载所影响的和平 UI 挂点。

图鉴此前用 `AddToSlot(widget)` 单参挂载到官方默认挂点 `UI.UISlot.MainUISlot_Low`，关闭时只用废弃的 `HideWidget` + `DestroyWidget`，**没有从和平 UI 挂点摘除**，挂点侧可能残留已销毁控件并影响同层原生 UI 的显示。

## 四、修改（Script/Function/CollectibleCodexUIService.lua）

1. 新增 `GetCodexSlotConfig()`：读 `UI.Codex.SlotName`（默认 `UI.UISlot.MainUISlot_Low`）与 `UI.Codex.SlotZOrder`（默认 0），表格缺行时用默认值。
2. `CreateAndShow`：`AddToSlot(widget, slotName, slotZOrder)` 按官方签名挂载；失败时记录错误并回退单参调用，再失败才 `error("AddToSlotFailed")`。
3. 新增 `CollapseCodexLayers(widget)`：关闭前先收起 `DetailOverlay`、`DetailPanel` 与图鉴根控件，避免全屏遮罩/底板残留在挂点上。
4. `Hide`：先 `CollapseCodexLayers`，再 `RemoveFromSlot(targetWidget)`（官方摘挂点接口），失败回退 `HideWidget`，最后 `DestroyWidget`；用 `IsWidgetAddedToSlot` 回读是否残留并打印 `stillOnSlot`。
