# 新知识入库完整示例

场景：IslandAuctionKing 发现竞拍阶段时长配置需要记录。示例日期：2026-08-26。

本示例只说明入库路径；证据状态、去重、互链和按需检索规则以 [准确性与关联性读取写回规范](./003_准确性与关联性读取写回规范.md) 为准。

## 1. 写入 Raw

内容包含项目名、配置行和具体数值，属于项目数据。创建：

    D:\知识库\和平精英绿洲起源\raw\IslandAuctionKing\数据参数\2026-08-26_竞拍阶段时长.md

文件应包含：项目 IslandAuctionKing；配置表路径；配置行 Gameplay.Duration.Bidding；类型；当前值；默认回退值；用途；读取代码；验证日志。

Raw 页首至少补充：

    > 类型：项目证据
    > 主题：配置表 / Gameplay
    > 适用范围：IslandAuctionKing
    > 证据状态：项目实测
    > 来源：配置表回读、Lua 文件路径、PIE 日志路径
    > 更新时间：2026-08-26
    > 关联主题：配置表驱动开发、PIE 调试
    > 排除范围：其他项目时长、官方 API 定义
    > 官方依据：若官方资料未覆盖该行值，写“知识库未覆盖”

## 2. 更新项目索引

在 `raw/IslandAuctionKing/000_项目索引.md` 的数据参数项增加：

    raw/IslandAuctionKing/数据参数/2026-08-26_竞拍阶段时长.md
    摘要：Gameplay.Duration.Bidding 的当前时长与默认回退值。

## 3. 更新 Wiki

不在 `wiki/000_索引.md` 新增项目参数。只在 `wiki/项目/000_项目资料总览.md` 的 IslandAuctionKing 行写入最近更新摘要，并链接项目索引。

## 4. 验证

    Test-Path "D:\知识库\和平精英绿洲起源\raw\IslandAuctionKing\数据参数\2026-08-26_竞拍阶段时长.md"
    rg -n "Gameplay.Duration.Bidding" "D:\知识库\和平精英绿洲起源\raw\IslandAuctionKing"

预期：文件存在，项目局部检索命中配置行，`wiki/000_索引.md` 不出现该项目参数条目。

## 5. 写回前后的准确性检查

1. 写回前用配置行名、项目名和文件名检索，确认不是已有页面的重复记录。
2. 如果只新增当前项目的具体数值，不能把数值复制到全局概念页；全局页最多链接到项目证据。
3. 如果发现官方资料与项目实测结果不同，保留两者并标为“官方定义/项目实测”或“冲突”，不能静默覆盖。
4. 如果该结论依赖配置表加载生命周期或 Lua 读取接口，只补读对应的配置表和 API 文档，不读取无关 UI、RPC 或其他项目目录。
5. 在回答或工作记录中写明：主文档、补充依赖、证据复核、排除范围和知识库未覆盖项。
