## Fields

| Name | Type | Description |
| --- | --- | --- |
| Location | [FVector](../FV/FVector.md) | The key's translation value. |
| Rotation | [FRotator](../FR/FRotator.md) | The key's rotation value. |
| Scale | [FVector](../FV/FVector.md) | The key's scale value. |
| Time | `float` | The key's time. |
