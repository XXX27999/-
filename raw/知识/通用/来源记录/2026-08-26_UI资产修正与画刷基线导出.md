## 四、UGCmap 脏标记（**未能自动丢弃，需人工操作**）

**核查结论：脏标记是假脏，关卡内容与磁盘一致。**

- Actor 清单 12 个，全部为引擎/模板自带：`Brush_0`、`DefaultPhysicsVolume_0`、`STWorldSettings`、`BP_STPlayerStart_2`、`PostProcessMgr_3`、`BP_STExtraSkyBox_2`、`AbstractNavData-Default`、`InstancedFoliageActor_0`、`Landscape_0`、`LandscapeGizmoActiveActor_1`、`SphereReflectionCapture_1`、`LevelBounds_1`
- MCP 探针残留检查：`LEFTOVER_PROBES=[]`
- 磁盘 `UGCmap.umap` SHA256 与备份完全一致（`1759510F…1245`），最后写入时间仍是 2026/8/24 14:37:54 —— 说明**从未被保存过**，脏标记只在内存

**为什么不能自动丢弃**：查遍 MCP Python API（`py:index` 68 类 819 方法、`py:dirty` / `py:package` / `py:level` / `py:revert` / `py:discard`）——

| 需求 | API 现状 |
| --- | --- |
| 读脏标记 | ✅ `pkg.package_is_dirty()`（**UWorld 上调用会抛 `uobject is not an UPackage`**，需取到真正的 UPackage） |
| 清除脏标记 | ❌ 无任何 `set_dirty` / `clear_dirty` / `mark_package_dirty` 接口 |
| 重新加载关卡 | ❌ 无 `load_map` / `open_level` / `new_level` |
| 保存关卡 | ✅ `editor_command_save_current_level` / `helpers.save_current_level()`（但这是**保存**，与「不保存」诉求相反） |

`ue.console_exec` 存在但无文档签名；用它执行 `MAP LOAD` 之类命令会重载整个关卡，属高风险且不可回滚的操作，**不适合在无人值守下执行**，因此没有动。

**请你在编辑器内手动完成**：菜单 `文件 → 打开关卡`（或关闭编辑器）时弹出的保存提示中选「**不保存 / Don't Save**」。由于磁盘文件与备份哈希一致，丢弃后不会损失任何内容。若操作失误误保存，可用备份 `D:\UGCBackup\IslandAuctionKing\20260826_UITextureFix\UGCmap.umap` 覆盖还原。

## 五、ZhuJieMian 画刷基线导出（已完成）

控件树 23 个：1 个 `CanvasPanel_0` + 14 个 `Image` + 8 个 `TextBlock`。14 个 Image 的画刷与 Slot 全量数据已整理成 [ZhuJieMian 画刷现状基线表](../UI与交互/ZhuJieMian画刷现状基线表.md)。

三条值得记录的观察：

1. **14 个 `BrushImage` 全为 `None`** —— 资产层面证实本工程改样式只用 `Brush`，与用户轮次 3 的纠正一致。
2. **画刷参数高度同构**：`DrawAs` 全 `Image(3)`、`Tiling`/`Mirroring`/`ImageType` 全 0、`Margin` 全 0、`TintColor` 全纯白且 `ColorUseRule=0`、`ResourceName` 全 `None`、`ImageSize` 全默认 `(32,32)`。差异只在 `ResourceObject` 与 Slot 布局。
3. **`参考图` 的 `Slot.GetSize()` 返回 `(0,0)` 不是异常**：它锚点为四向拉伸 `(0,0)-(1,1)`，此时 Offsets 语义是四边留白而非 `(X,Y,W,H)`，Size 不参与计算。这是读 `CanvasPanelSlot` 时容易误判的点，已写入基线页「常见错误」。

贴图复用关系：`ZJM1` 被 3 个控件共用（三个「上方UI」），`ZJM3` 被 2 个共用（玩家名称、服务器剩余时间）。

## 六、证据边界

- ZJM4 的回读只证明**写入落盘**，`TEXTUREGROUP_UI` 对实机画质/内存的影响未做 PIE 前后对比。
- 画刷基线是**单次静态快照**，未覆盖运行时 Lua 侧对画刷的动态改写。
- 关卡脏标记的「假脏」判定依据是 Actor 清单 + 磁盘哈希一致，未逐个比对 Actor 属性级差异。
- 空目录删除仅影响文件系统，未触碰任何 `.uasset`；但 UE 编辑器的目录视图可能需要刷新或重启才更新。
