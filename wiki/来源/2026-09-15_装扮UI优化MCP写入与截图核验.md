## 一句话

一次 UMG 实写（IslandAuctionKing · AuctionDressUI）暴露的**本绑定 API 真值**与**编辑器截图的确定性判据**。

## 要点（正文看 Raw）

- 本绑定**没有** `set_editor_property` 与 `call_function`；`FVector2D` **没有** `set_field`（须构造后整体写）
- Slot 几何：`CanvasPanelSlot` 在 `LayoutData`；`VerticalBoxSlot` **无** `LayoutData`，只有 `Size`/`Padding`
- `widget_add` 后 `WidgetTree.AllWidgets` **滞后不刷新**（73→仍 73，compile 后才 86）→ 索引以 `RootWidget` 递归为主
- FlaUI 截图：**窗口能列出 ≠ 画面有目标 UI**（桌面 GDI 抓屏会连带遮挡窗口）；用设计 token 像素命中数判定，命中 0 即不得当成功截图交付
