# FScrollBarStyle

Represents the appearance of an SScrollBar

## Fields

| Name | Type | Description |
| --- | --- | --- |
| HorizontalBackgroundImage | [FSlateBrush](./FSlateBrush.md) | Background image to use when the scrollbar is oriented horizontally |
| VerticalBackgroundImage | [FSlateBrush](./FSlateBrush.md) | Background image to use when the scrollbar is oriented vertically |
| VerticalTopSlotImage | [FSlateBrush](./FSlateBrush.md) | The image to use to represent the track above the thumb when the scrollbar is oriented vertically |
| HorizontalTopSlotImage | [FSlateBrush](./FSlateBrush.md) | The image to use to represent the track above the thumb when the scrollbar is oriented horizontally |
| VerticalBottomSlotImage | [FSlateBrush](./FSlateBrush.md) | The image to use to represent the track below the thumb when the scrollbar is oriented vertically |
| HorizontalBottomSlotImage | [FSlateBrush](./FSlateBrush.md) | The image to use to represent the track below the thumb when the scrollbar is oriented horizontally |
| NormalThumbImage | [FSlateBrush](./FSlateBrush.md) | Image to use when the scrollbar thumb is in its normal state |
| HoveredThumbImage | [FSlateBrush](./FSlateBrush.md) | Image to use when the scrollbar thumb is in its hovered state |
| DraggedThumbImage | [FSlateBrush](./FSlateBrush.md) | Image to use when the scrollbar thumb is in its dragged state |
