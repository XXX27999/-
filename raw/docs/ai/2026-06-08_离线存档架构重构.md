# 离线存档架构重构：属性缓存 + Pawn/Controller 分离存档

**日期**: 2026-06-05 ~ 2026-06-08

---

## 功能概述

重构玩家离线存档系统，解决四个核心问题：

1. **玩家退出时属性读取全 0**：Pawn 销毁时属性组件已清理，`GetGameAttributeValue` 返回 0
2. **Pawn/Controller 销毁时无法互相查找**：`GetPlayerControllerByPlayerPawn` 和 `GetPlayerPawnByPlayerController` 在销毁阶段返回 nil
3. **脚本变量/蓝图变量在实体销毁时丢失**：Lua 表和 `ULuaMapHelper` 蓝图变量随 Pawn GC 被回收
4. **称号解锁数据 `ChenHaoShuJu` 未持久化**：Controller 蓝图变量需要跨局保存

---

## 最终架构

```
Pawn 销毁 ──▶ SendModeCustomEvent("PlayerExitGame", self)
                     │
                     ▼
              PlayerExitGame:Execute(self.Player)
                     │
                     ▼
              SavePlayerArchive(PlayerPawn)       ← 属性存档
                     │
                     ├── UID = GetUIDByPlayerPawn(PlayerPawn)
                     ├── Set ExitTime 属性
                     ├── 读 PlayerAttributeCache 模块缓存
                     ├── 写 PlayerAttributes 到 PlayerData
                     └── SavePlayerArchiveData (保留已有 PetData)


Controller 销毁 ──▶ SendModeCustomEvent("ControllerExitGame", self)
                           │
                           ▼
                    ControllerExitGame:Execute(self.Controller)
                           │
                           ▼
                    SaveControllerArchive(Controller)   ← 宠物数据存档
                           │
                           ├── UID = GetUIDByPlayerController(Controller)
                           ├── 遍历 PetDataStrct → 序列化宠物数据
                           ├── 清理 WarehouseData
                           ├── DestroyActor(宠物Actor)
                           ├── 序列化 ChenHaoShuJu → PlayerData["ChenHaoShuJu"]
                           └── SavePlayerArchiveData (保留已有 PlayerAttributes)


玩家登录 ──▶ PetActorDic:Execute
              ├── GetPlayerControllerByPlayerPawn ✓ (可互相查找)
              └── LoadPlayerArchive(PlayerPawn, Controller)
                   ├── 恢复宠物 Actor
                   ├── 恢复玩家属性（含跨天检测重置每日打工计数）
                   └── 恢复 ChenHaoShuJu
```

## 问题与解决方案

### 问题 1：属性读取全 0

**触发条件**：玩家退出时 `UGCPlayerPawn:ReceiveEndPlay` → `SavePlayerArchive` 中调用 `UGCAttributeSystem.GetGameAttributeValue` 返回全 0。

**根因**：Pawn 销毁时属性组件已被框架清理。

**解决**：使用 `UGCAttributeSystem.AddGameAttributeChangedDelegate` 实时监听属性变化，将值缓存到模块级 Lua 表中。

### 问题 2：属性缓存表生命周期

**演进路线**：

| 方案 | 存放位置 | 结果 |
|---|---|---|
| 方案 A | `Pawn.CachedPlayerAttributes`（Lua 表） | 离线存档是静态函数调用，拿不到实例变量 |
| 方案 B | `Pawn.PlayerAttributeNames`（蓝图变量 `ULuaMapHelper<FString, float>`） | Pawn 销毁时随 GC 回收 |
| **方案 C（最终）** | `PlayerExitGame.lua` **模块级** `local PlayerAttributeCache = {}` | 模块级变量不随任何实体销毁 |

**关键原则**：属性缓存必须脱离实体生命周期。Lua 模块顶层变量是最稳定的存储。

### 问题 3：`GetPlayerUIDByPawn(self)` 在 Pawn 销毁时返回 nil

**触发条件**：`ReceiveEndPlay` 兜底同步中调用 `GetPlayerUIDByPawn(self)` 返回 nil，导致 `SetCachedPlayerAttribute(nil, ...)` 静默跳过。

**解决方向**：
- 通过 Controller 获取 UID（Controller 比 Pawn 晚销毁）
- 在 `RegisterPlayerAttributeListeners` 中提前用闭包捕获 `playerUID`

### 问题 4：Pawn/Controller 销毁时无法互相查找

**最终方案**：职责分离。各自在自身 `ReceiveEndPlay` 中发送模式编辑器事件，各自存档自己的数据。

### 问题 5：`self.Player` 类型混乱

`PlayerExitGame:Execute` 中 `self.Player` 始终是 PlayerPawn，不需要类型探测。

### 问题 6：`playerUID` 作用域错误

`ClearCachedPlayerAttributes(playerUID)` 在 `pcall` 块外调用但 `playerUID` 定义在 `pcall` 内 → 移入 `pcall` 块内。

### 问题 7：跨脚本调用 `GetAttrSafe`

`ControllerExitGame` 引用 `PlayerExitGame.GetAttrSafe` → 改为各自实现自己的 `GetAttrSafe`。

### 问题 8：`#chenHaoData` 无效

`#` 对键值对表返回 0 → 改为打印具体字段值。

### 1. PlayerExitGame.lua — 模块级属性缓存 + 属性存档

最终文件：[PlayerExitGame.lua](file:///d:/WeGameApps/rail_apps/OasisEraEditor(2001776)/ShadowTrackerExtra/UGCProjects/pet_paradise/Script/gamemode/PlayerExitGame.lua)

```lua
-- 模块级缓存表（永不 GC）
local PlayerAttributeCache = {}

--- 写入模块级玩家属性缓存（由 UGCPlayerPawn 属性变化回调调用）
function PlayerExitGame.SetCachedPlayerAttribute(playerUID, attrName, value)
    if not playerUID or not attrName then return end
    playerUID = tostring(playerUID)
    if not PlayerAttributeCache[playerUID] then
        PlayerAttributeCache[playerUID] = {}
    end
    PlayerAttributeCache[playerUID][attrName] = value
end

--- 读取模块级玩家属性缓存
function PlayerExitGame.GetCachedPlayerAttributes(playerUID)
    if not playerUID then return nil end
    return PlayerAttributeCache[tostring(playerUID)]
end

--- 清除指定玩家的属性缓存（存档后清理，防内存泄漏）
function PlayerExitGame.ClearCachedPlayerAttributes(playerUID)
    if not playerUID then return end
    PlayerAttributeCache[tostring(playerUID)] = nil
end

--- 安全读取属性值
function PlayerExitGame.GetAttrSafe(owner, attrName, defaultValue)
    if not owner or not attrName then return defaultValue or 0 end
    local ok, value = pcall(function()
        if not UE.IsValid(owner) then return nil end
        return UGCAttributeSystem.GetGameAttributeValue(owner, attrName)
    end)
    return (ok and value ~= nil) and (tonumber(value) or defaultValue) or defaultValue
end

--- 玩家属性存档函数（Pawn 销毁时执行）
function PlayerExitGame.SavePlayerArchive(PlayerPawn)
    -- 权限校验
    if PlayerPawn:HasAuthority() == false then return false end

    -- UID 直接取自 Pawn
    local playerUID = UGCGameSystem.GetUIDByPlayerPawn(PlayerPawn)

    -- ExitTime 用 TimeUtils 获取带偏移的服务器时间
    local TimeStamp = TimeUtils.GetCurrentTimeSec()
    UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, "ExitTime", TimeStamp)

    -- 读取已有的存档数据（可能已有 ControllerExitGame 写入的 PetData）
    local PlayerData = UGCPlayerStateSystem.GetPlayerArchiveData(playerUID) or {}

    -- 优先读模块缓存 PlayerAttributeCache
    local cachedAttrs = PlayerExitGame.GetCachedPlayerAttributes(playerUID)

    -- 【最后防线】缓存为空时从属性系统强制补写
    if not cachedAttrs then
        for _, attrName in ipairs({
            "Gold", "MonthlyCard", "SeasonalCard", "LuxuryGiftBag",
            "AdvTrust", "PermTrust", "TopGiftBag", "WorkIncome", "WorkDouble",
            "ExitTime", "OfflineIncomeTime", "PermanentTrustPrivilege",
            "DaylityWorkCount", "DaylityPerfectWorkCount"
        }) do
            PlayerExitGame.SetCachedPlayerAttribute(playerUID, attrName,
                PlayerExitGame.GetAttrSafe(PlayerPawn, attrName, 0))
        end
        cachedAttrs = PlayerExitGame.GetCachedPlayerAttributes(playerUID)
    end

    -- 构建 PlayerAttributes 表：优先读缓存，其次属性系统
    local playerAttr = {}
    local function GetAttrValue(name, def)
        if cachedAttrs and cachedAttrs[name] ~= nil then return tonumber(cachedAttrs[name]) or def end
        return PlayerExitGame.GetAttrSafe(PlayerPawn, name, def)
    end

    playerAttr.Gold = GetAttrValue("Gold", 0)
    -- ... 其余属性同模式 ...
    playerAttr.ExitTime = TimeStamp  -- 直接用退出时间，不从属性系统读
    playerAttr.DaylityWorkCount = GetAttrValue("DaylityWorkCount", 0)
    playerAttr.DaylityPerfectWorkCount = GetAttrValue("DaylityPerfectWorkCount", 0)
    PlayerData["PlayerAttributes"] = playerAttr

    -- 保留已有的 PetData（ControllerExitGame 可能已写），写入 PlayerAttributes
    UGCPlayerStateSystem.SavePlayerArchiveData(playerUID, PlayerData)

    -- 清理缓存
    PlayerExitGame.ClearCachedPlayerAttributes(playerUID)
end

--- 蓝图Action入口（self.Player = PlayerPawn）
function PlayerExitGame:Execute(...)
    local PlayerPawn = self.Player
    if not PlayerPawn then return false end
    return PlayerExitGame.SavePlayerArchive(PlayerPawn)
end
```

### 2. UGCPlayerPawn.lua — 属性监听注册 + Pawn 销毁发事件

最终文件：[UGCPlayerPawn.lua](file:///d:/WeGameApps/rail_apps/OasisEraEditor(2001776)/ShadowTrackerExtra/UGCProjects/pet_paradise/Script/Blueprint/UGCPlayerPawn.lua)

```lua
-- 属性监听注册（在 ReceiveBeginPlay 中调用）
-- 闭包捕获 playerUID，回调中不依赖 Pawn 引用
function UGCPlayerPawn:RegisterPlayerAttributeListeners()
    if not self:HasAuthority() then return end  -- 属性修改仅在服务端发生

    self.AttributeDelegateHandles = self.AttributeDelegateHandles or {}

    -- 提前获取 playerUID，闭包外捕获（关键！不要在回调中用 GetPlayerUIDByPawn(AttributeOwner)）
    local playerUID = GetPlayerUIDByPawn(self)

    for _, attrName in ipairs(PlayerAttrNameList) do
        -- 先读一次初始值写入缓存
        local initialOk, initialValue = pcall(function()
            return UGCAttributeSystem.GetGameAttributeValue(self, attrName)
        end)
        PlayerExitGame.SetCachedPlayerAttribute(playerUID, attrName,
            (initialOk and tonumber(initialValue)) or 0)

        -- 注册属性变化监听
        local registerOk, delegate = pcall(function()
            return UGCAttributeSystem.AddGameAttributeChangedDelegate(self, attrName,
                function(_, CallbackAttrName, CurValue)
                    PlayerExitGame.SetCachedPlayerAttribute(playerUID, CallbackAttrName, CurValue)
                end
            )
        end)
        if registerOk and delegate then
            self.AttributeDelegateHandles[attrName] = delegate
        end
    end
end

-- 属性监听注销（Pawn 销毁时调用，释放资源）
function UGCPlayerPawn:RemovePlayerAttributeListeners()
    if not self.AttributeDelegateHandles then return end
    for attrName, delegate in pairs(self.AttributeDelegateHandles) do
        pcall(function()
            UGCAttributeSystem.RemoveGameAttributeChangedDelegate(self, attrName, delegate)
        end)
    end
    self.AttributeDelegateHandles = {}
end

-- Pawn 销毁处理
function UGCPlayerPawn:ReceiveEndPlay()
    UGCEventSystem:RemoveListener(RankExclusiveTitle.Events.RankDataChanged, self.OnRankDataChangedEvent, self)
    self.PlayerUID = nil

    -- 先注销属性监听
    self:RemovePlayerAttributeListeners()

    -- 发送模式编辑器事件 → PlayerExitGame 存档（仅服务端）
    if self:HasAuthority() then
        UGCGameSystem.SendModeCustomEvent("PlayerExitGame", self)
    end
end
```

### 3. ControllerExitGame.lua — Controller 宠物数据存档 + ChenHaoShuJu 序列化

最终文件：[ControllerExitGame.lua](file:///d:/WeGameApps/rail_apps/OasisEraEditor(2001776)/ShadowTrackerExtra/UGCProjects/pet_paradise/Script/gamemode/ControllerExitGame.lua)

```lua
-- 自带 GetAttrSafe，不依赖 PlayerExitGame
function ControllerExitGame.GetAttrSafe(owner, attrName, defaultValue) ... end

function ControllerExitGame.SaveControllerArchive(Controller)
    if Controller:HasAuthority() == false then return false end

    local playerUID = UGCGameSystem.GetUIDByPlayerController(Controller)

    -- 读取已有存档（PlayerExitGame 可能已写 PlayerAttributes）
    local PlayerData = UGCPlayerStateSystem.GetPlayerArchiveData(playerUID) or { PetData = {} }
    if not PlayerData["PetData"] then PlayerData["PetData"] = {} end

    -- 遍历 Controller.PetDataStrct → 序列化 PetData
    local PetDataStrct = Controller.PetDataStrct
    local PetDataSave = {}

    for i = 1, #PetDataStrct do
        local srcItem = PetDataStrct[i]
        local PetActorRef = srcItem.PetActor
        local PetItem = {
            Location = { X = srcItem.Location.X or 0, Y = srcItem.Location.Y or 0, Z = srcItem.Location.Z or 0 },
            Path = srcItem.Path or "", Name = srcItem.Name or "", -- ... 其余字段 ...
        }

        -- 用自身 GetAttrSafe 读 Actor 属性
        if PetActorRef then
            PetItem.Hunger = ControllerExitGame.GetAttrSafe(PetActorRef, "Hunger", PetItem.Hunger)
            PetItem.Cleanliness = ControllerExitGame.GetAttrSafe(PetActorRef, "Cleanliness", PetItem.Cleanliness)
            -- ... 其余属性 ...
            PetItem.WorkPerfectTime = ControllerExitGame.GetAttrSafe(PetActorRef, "WorkPerfectCard", PetItem.WorkPerfectTime)
        end

        table.insert(PetDataSave, PetItem)

        -- 清理 WarehouseData 中对应项
        if Controller.WarehouseData then
            for wi = #Controller.WarehouseData, 1, -1 do
                if Controller.WarehouseData[wi] and Controller.WarehouseData[wi].PetActor == PetActorRef then
                    table.remove(Controller.WarehouseData, wi)
                    break
                end
            end
        end

        -- 销毁宠物 Actor
        if PetActorRef then UGCActorComponentUtility.DestroyActor(PetActorRef) end
    end

    PlayerData["PetData"] = PetDataSave

    -- 序列化 ChenHaoShuJu 到存档
    local chenHaoData = {}
    if Controller.ChenHaoShuJu then
        for k, v in pairs(Controller.ChenHaoShuJu) do
            chenHaoData[k] = v
        end
    end
    PlayerData["ChenHaoShuJu"] = chenHaoData

    UGCPlayerStateSystem.SavePlayerArchiveData(playerUID, PlayerData)
end

-- 蓝图Action入口（self.Controller = PlayerController）
function ControllerExitGame:Execute(...)
    local Controller = self.Controller
    if not Controller then return false end
    return ControllerExitGame.SaveControllerArchive(Controller)
end
```

function UGCPlayerController:ReceiveEndPlay()
    -- Controller 销毁时发送模式编辑器事件 → ControllerExitGame 存档
    -- 此时 Controller 实体仍存活，可正常访问蓝图变量
    if self:HasAuthority() then
        UGCGameSystem.SendModeCustomEvent("ControllerExitGame", self)

    for i = #_connectedControllers, 1, -1 do

            table.remove(_connectedControllers, i)
            break
        end
    end
end

function PetActorDic.LoadPlayerArchive(PlayerPawn, Controller)
    -- 此时 Pawn 和 Controller 可以互相查找！
    local playerUID = UGCGameSystem.GetUIDByPlayerPawn(PlayerPawn)
    local PlayeData = UGCPlayerStateSystem.GetPlayerArchiveData(playerUID)

    -- 恢复宠物 Actor（略）

    -- 恢复玩家属性（含跨天检测重置每日打工计数）
    local playerAttributes = PlayeData["PlayerAttributes"]
    if playerAttributes and PlayerPawn then
        local daylityWorkCount = playerAttributes.DaylityWorkCount or 0
        local daylityPerfectWorkCount = playerAttributes.DaylityPerfectWorkCount or 0
        local lastActiveDay = playerAttributes.lastActiveDay or 0

        -- 跨天检测
        local currentDay = TimeUtils.GetCurrentTimeDay()
        if currentDay > lastActiveDay then
            daylityWorkCount = 0
            daylityPerfectWorkCount = 0
        end

        UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, "Gold", playerAttributes.Gold or 0)
        -- ... 其余属性 ...
        UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, "DaylityWorkCount", daylityWorkCount)
        UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, "DaylityPerfectWorkCount", daylityPerfectWorkCount)
    end

    -- 恢复 ChenHaoShuJu 到 Controller 蓝图变量
    local chenHaoData = PlayeData["ChenHaoShuJu"]
    if chenHaoData and Controller and Controller.ChenHaoShuJu then
        for k, v in pairs(chenHaoData) do
            pcall(function() Controller.ChenHaoShuJu[k] = v end)
        end
    end
end

-- 蓝图Action入口（玩家登录触发）
function PetActorDic:Execute(...)
    local PlayerPawn = self.Player
    local Controller = UGCGameSystem.GetPlayerControllerByPlayerPawn(PlayerPawn)
    PetActorDic.LoadPlayerArchive(PlayerPawn, Controller)
end

## 核心设计原则

1. **模块级变量是唯一永不 GC 的存储**。属性缓存、全局状态都应放在脚本顶层 `local` 变量中。
2. **销毁阶段不看对方实体**。Pawn 和 Controller 各自在 `ReceiveEndPlay` 中发事件，各自存各自的数据。
3. **登录时可互相查找**。`ReceiveBeginPlay` 中 `GetPlayerControllerByPlayerPawn` / `GetPlayerPawnByPlayerController` 正常可用。
4. **闭包捕获 UID**。属性变化回调中用闭包捕获 `playerUID`，不要在回调中通过 `AttributeOwner` 去查找 UID。
5. **`self.Player` / `self.Controller` 固定类型**。蓝图Action面板配置什么就传什么，不要做类型探测。
6. **存档合并读取**。`GetPlayerArchiveData` → 修改后 `SavePlayerArchiveData`，不要覆盖他人写入的字段。
7. **每次 `pcall` 保护对外 API 调用**。

## API 使用

| API | 调用端 | 用途 |
|---|---|---|
| `UGCAttributeSystem.AddGameAttributeChangedDelegate` | **服务端&客户端** | 注册属性变化监听 |
| `UGCAttributeSystem.RemoveGameAttributeChangedDelegate` | **服务端&客户端** | 注销属性变化监听 |
| `UGCAttributeSystem.GetGameAttributeValue` | **服务端&客户端** | 读取属性值 |
| `UGCAttributeSystem.SetGameAttributeValue` | **服务端&客户端** | 设置属性值 |

| `UGCPlayerStateSystem.GetPlayerArchiveData` | **服务端** | 读存档 |
| `UGCPlayerStateSystem.SavePlayerArchiveData` | **服务端** | 写存档 |

## 蓝图侧配置提醒

需在模式编辑器中为 `ControllerExitGame` 创建 Action 链路：

1. 新增"自定义事件"，事件名 `ControllerExitGame`
2. 事件 → "执行脚本" Action，脚本选 `ControllerExitGame`
3. Action 的 `Controller` 参数绑定自定义事件的传入参数
