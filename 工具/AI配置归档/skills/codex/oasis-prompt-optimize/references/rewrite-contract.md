## 全局禁止项

只在提示词里保留与当前任务相关的条目：

- 不编造未查证的 API、生命周期、端侧限制或控件字段
- 不把 `_JsonOutput` JSON 当蓝图写入接口，不拿旧 JSON 声称已改编辑器
- 不把备份、`_tmp_*.py`、`_mcp_tmp`、`__pycache__`、`*.pyc` 留在 UGC 工程
- 工程文件名必须以英文字母开头，路径和文件名不得含 `.` 或 `-`
- 不在 `UGCPlayerController` 新增业务 RPC，不直接 `pc:RPC`
- 不用 `if not self:HasAuthority() then return end` 静默退出
- 不把项目 DataTable 行值、截图尺寸或日志原文写成全局官方结论
- 不把「预估成功日志」说成 PIE 已通过

## 证据状态

提示词必须要求执行者区分：`官方确认`、`项目实测`、`经验归纳`、`推断`、`冲突`、`废弃`、`知识库未覆盖`。冲突要同时保留双方来源，禁止静默覆盖。

## 质量门

改写完成前检查：

1. 提示词里至少有一个精确检索实体，或明确标成待补。
2. 读写入口分离：谁用 MCP，谁只改 Lua，谁禁止碰 JSON。
3. 有备份路径或写明本任务只读、无需备份。
4. 有验证方式和生效方式，且二者没有互相矛盾。
5. 没有把 IslandAuctionKing 的具体数值当成所有项目默认值，除非用户任务就在该项目。
6. 没有把本技能、AGENTS.md 或整份知识库规范复读进提示词。
7. 追问任务词保留了上文仍有效的项目、路径、API、约束和未决项，且没有整段粘贴对话历史。

## 精简规则

- 用户原文已经正确的约束原样保留，不要改写成更泛的话。
- 用户指定的项目、资产、模型、文件边界优先于通用示例。
- 不要为了完整把 Lua、UI、PIE、回写规则全部塞进每个提示词；按任务类型裁剪。
- 子任务派发词必须写清可改文件、禁止文件、验证命令和返回格式。
- 追问必须继承上文仍有效的项目、路径、API、文件边界、硬约束、验证门和未决项；本轮新要求覆盖冲突点。不要把整段对话历史复制进任务词。
