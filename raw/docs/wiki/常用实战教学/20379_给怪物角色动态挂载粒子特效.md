# 给怪物/角色动态挂载粒子特效

> 本文档来自 `pet_paradise` 项目的实际调试经验，记录了在 Lua 中为怪物/角色动态加载并附加粒子特效的完整方案。

## 涉及 API

| API | 生效范围 | 说明 |
|-----|---------|------|
| `K2_GetRootComponent()` | 服务端&客户端 | 获取 Actor 的根组件，需要在 pcall 中调用 |
| `UGCGameSystem.GetUGCResourcesFullPath(RelativePath)` | 服务端&客户端 | 将 `Asset/xxx/yyy.yyy` 转为完整路径 `/pet_paradise/Asset/xxx/yyy.yyy` |
| `UGCObjectUtility.LoadObject(FullPath)` | 服务端&客户端 | 同步加载资源，路径必须是完整路径 |
| `UGCObjectUtility.AsyncLoadObject(Path, Callback, Self)` | 服务端&客户端 | 异步加载资源，加载完成通过回调返回 |
| `UGCGameSystem.SpawnEmitterAttached(ParticleSystem, Component, ...)` | **仅客户端** | 在指定组件上附加粒子特效，不进行网络复制 |
| `Component:DestroyComponent(false)` | 服务端&客户端 | 销毁特效组件 |

## 完整代码模板

```lua
function MyActor:SpawnPetEffects()
    ugcprint("[MyActor+SpawnPetEffects] 开始生成特效装饰")

    -- 1. 获取根组件（用 pcall 安全调用）
    local RootComponent = nil
    local ok, result = pcall(function()
        return self:K2_GetRootComponent()
    end)
    if ok and result then
        RootComponent = result
    else
        ugcprint("[MyActor+SpawnPetEffects] 错误: 无法获取根组件")
        return
    end

    -- 2. 加载粒子系统资源
    local EffectAssetPath = "Asset/Effect/YourParticle.YourParticle"
    local ParticleSystem = nil

    local loadOk, loadResult = pcall(function()
        local FullPath = UGCGameSystem.GetUGCResourcesFullPath(EffectAssetPath)
        if FullPath then
            return UGCObjectUtility.LoadObject(FullPath)
        end
        return nil
    end)
    if loadOk and loadResult then
        ParticleSystem = loadResult
    end

    -- 3. 生成特效并附加到根组件
    if ParticleSystem then
        local spawnSuccess, EmitterComponent = pcall(function()
            return UGCGameSystem.SpawnEmitterAttached(
                ParticleSystem,
                RootComponent,
                "None",          -- 插槽名，None表示根组件原点
                { X = 0, Y = 0, Z = 0 },   -- 相对位置偏移
                { X = 0, Y = 0, Z = 0 },   -- 相对旋转
                { X = 1, Y = 1, Z = 1 },   -- 缩放
                0                          -- LocationType: 0=相对偏移
            )
        end)

        if spawnSuccess and EmitterComponent then
            table.insert(self.EffectComponents, EmitterComponent)
        end
    end
end
```

## 关键注意事项

### 1. 客户端 vs 服务端

`SpawnEmitterAttached` **仅客户端生效**。必须在 `not self:HasAuthority()` 分支中执行：

```lua
function MyActor:ReceiveBeginPlay()
    if not self:HasAuthority() then
        self:SpawnPetEffects()
    end
end
```

### 2. 资源路径格式

`UGCObjectUtility.LoadObject` 要求完整路径，必须先用 `GetUGCResourcesFullPath` 转换：

- 正确：`/pet_paradise/Asset/Effect/xxx.xxx`
- 错误：`Asset/Effect/xxx.xxx`（API 会报错 "Path starts with 'Asset', which is not longer supported"）

资源路径格式为 `Asset/目录/文件名.文件名`（不含扩展名 .uasset）。

### 3. 粒子系统 uasset 的 PackageFlags 要求

如果 UAsset 的顶层 `PackageFlags` 包含 `PKG_FilterEditorOnly`，运行时引擎会跳过加载。必须修改 JSON：

```json
"PackageFlags": "PKG_None",
"IsFilterEditorOnly": false
```

同时检查粒子系统导出自身的 `bNotAlwaysLoadedForEditorGame` 也要设为 `false`，否则资源可能在运行时不会被加载。

### 4. 粒子系统不可为空

如果粒子系统 `NumEmitters = 0`（没有发射器），`LoadObject` 返回 nil。必须在编辑器中添加至少一个 Sprite 发射器并配置基本参数。

### 5. 生命周期管理

特效组件生成后不会自动销毁，需要在 `ReceiveEndPlay` 和死亡回调中手动清理：

```lua
function MyActor:CleanupPetEffects()
    for i, Component in ipairs(self.EffectComponents) do
        if Component then
            pcall(function()
                Component:DestroyComponent(false)
            end)
        end
    end
    self.EffectComponents = {}
end
```

### 6. pcall 保护

所有可能失败的 API 调用（组件获取、资源加载、特效生成、组件销毁）都必须用 `pcall` 包裹，防止 Lua 错误导致整个脚本崩溃。

### 7. 粒子系统中的材质引用

创建粒子系统时建议使用编辑器内置的 UGC 材质。如果粒子系统引用了外部材质（如本体游戏材质路径 `/Game/Arts_Effect/...` 或 UGC 模板材质），只要这些材质对应的资源包在项目中存在且 **PackageFlags 正确（无 PKG_FilterEditorOnly）**，加载可以正常进行。如果加载失败，应优先排查资源包的 PackageFlags 设置，而不是材质引用。

## 常见问题排查

### Q: LoadObject 返回 nil

| 排查项 | 检查方法 |
|-------|---------|
| PackageFlags 是否正确 | 打开 uasset JSON，检查顶层 `PackageFlags` 不能包含 `PKG_FilterEditorOnly` |
| bNotAlwaysLoadedForEditorGame | 检查粒子系统导出项的该属性是否为 `false` |
| 粒子系统是否为空 | 检查 JSON 中 `NumEmitters` 是否大于 0 |
| 路径是否正确 | 确认资源路径格式为 `Asset/目录/文件名.文件名` |
| 资源文件是否存在 | 确认 uasset 文件在对应目录下存在 |

### Q: SpawnEmitterAttached 没有效果

| 排查项 | 说明 |
|-------|------|
| 是否在客户端调用 | 该 API **仅客户端生效**，需要在 `not self:HasAuthority()` 中执行 |
| 根组件是否正确 | 确认 `K2_GetRootComponent()` 返回了有效组件 |
| 粒子系统是否有效 | 确认 `LoadObject` 成功返回了粒子系统对象 |
