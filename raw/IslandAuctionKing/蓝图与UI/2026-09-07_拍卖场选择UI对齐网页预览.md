## 六、常见错误（本轮踩到的）

- `Border.BrushColor` 在本版绑定里是 `FLinearColor`，不是 `FSlateColor`：先读 `SpecifiedColor`/`ColorUseRule` 会报 `'FLinearColor' object has no attribute 'ColorUseRule'`，应直接赋值 `ue.FLinearColor(...)`；`TextBlock.ColorAndOpacity` 才是 `FSlateColor`，需要同时写 `SpecifiedColor` 与 `ColorUseRule=0`。
- `Slot.GetPosition()` / `GetSize()` 在 Python 绑定里不可用（报 `object has no attribute`），回读坐标要用 `ue.widget_inspect` 的字符串输出。
- `ue.data_table_as_dict(t)` 不存在，正确写法是表对象方法 `t.data_table_as_dict()`。
- 新控件 `widget_add` 后，`WidgetTree` 句柄要重新加载蓝图再遍历查找，不能沿用旧树。
