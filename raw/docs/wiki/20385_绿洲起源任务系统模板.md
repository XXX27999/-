# 绿洲起源任务系统模板

## 概述

任务系统由 3 个 Widget 脚本组成，采用 **RenWuLan 嵌入式导航栏 + 任务分页** 架构：

| 文件 | 类路径 | 职责 |
|------|--------|------|
| `RenWuLan.lua` | `RenWuLan_C` | 顶部导航栏（嵌入任务页），Image_122 → 页1，Image_123 → 页2 |
| `RenWu_1.lua` | `RenWu_1_C` | 每日打工任务（DaylityWorkCount，10次达标） |
| `RenWu_2.lua` | `RenWu_2_C` | 完美打工任务（DaylityPerfectWorkCount，5次达标） |

**蓝图层次结构：**
```
RenWu_1  (Widget)
  ├── RenWuLan (子Widget，导航栏)
  ├── TextBlock_391 (进度文本)
  ├── Image_386 (状态图标)
  ├── Button_98 (领取按钮)
  └── Button_54 (关闭按钮)

RenWu_2  (Widget)
  ├── RenWuLan (子Widget，导航栏)
  ├── TextBlock_95 (进度文本)
  ├── Image_386 (状态图标)
  ├── Button_98 (领取按钮)
  └── Button_54 (关闭按钮)
```

## 遇到的 7 个问题及解决方法

### 问题 1：`self:GetOuter()` 卡死

**现象：** RenWuLan 中调用 `self:GetOuter()` 获取父 Widget 时导致编辑器卡死。

**原因：** Widget 脚本中 `GetOuter()` 返回的是 UGCWidgetBlueprint 对象而非父 Widget 实例，在 Lua 中调用会进入死循环。

**解决：** 改为**回调注入模式**（后优化为**直接引用注入**）。

### 问题 2：闭包回调 `CloseParent` 不可靠

**现象：** RenWu_1 → RenWuLan 切换 RenWu_2 时，旧 UI 未关闭。

**原因：** 闭包中捕获的 `self` 在 `DestroyWidget` 后指向失效对象。

**解决：** 改为**直接引用注入模式**——RenWu_1/RenWu_2 在 LuaInit 中直接将 self 注入到 RenWuLan：
```lua
-- RenWu_1/RenWu_2 LuaInit 中
if self.RenWuLan then
    self.RenWuLan.ParentWidget = self
end

-- RenWuLan 中直接操作
if self.ParentWidget then
    UGCWidgetManagerSystem.HideWidget(self.ParentWidget)
    UGCWidgetManagerSystem.DestroyWidget(self.ParentWidget)
    self.ParentWidget = nil
end
```

### 问题 3：服务端 API 在客户端调用导致奖励不生效

**现象：** 点击领取后日志显示执行完毕，但金币/物品未加，属性未持久化。

**原因：** 以下 API 均为**服务端专用**，但 UI 按钮在客户端执行：
- `SetGameAttributeValue` → **仅服务器**
- `AddGameAttributeValue` → **仅服务器**
- `AddItemV2` → **仅 DS/服务器**

`GetGameAttributeValue` → **服务器 & 客户端**（双端可用）。

**解决：** 采用 RPC 模式：
```lua
-- === 1. UGCPlayerController 注册 RPC ===
function UGCPlayerController:GetAvailableServerRPCs()
    return "...", "ServerRPC_ClaimDayWorkReward", "ServerRPC_ClaimPerfectWorkReward"
end

-- === 2. UGCPlayerController 实现 RPC（HasAuthority 守卫）===
function UGCPlayerController:ServerRPC_ClaimDayWorkReward()
    if not self:HasAuthority() then return end
    local PlayerPawn = UGCGameSystem.GetPlayerPawnByPlayerController(self)
    -- 发放奖励
    UGCAttributeSystem.AddGameAttributeValue(PlayerPawn, "Gold", 500)
    UGCBackpackSystemV2.AddItemV2(PlayerPawn, 8310012, 1)
    -- 标记已领取
    UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, "DaylityWorkCount", 9999999)
end

-- === 3. UI 中通过 RPC 调用 ===
UnrealNetwork.CallUnrealRPC(PlayerController, PlayerController, "ServerRPC_ClaimDayWorkReward")
-- 客户端乐观更新 UI
self:SetImageTexture(self.Image_386, 'TuPian/RenWu/RW7.RW7')
self.Button_98:SetIsEnabled(false)
```

### 问题 4：避免添加新属性，用现有属性标记

**现象：** 用户要求不要新建 `DaylityWorkClaimed` 属性。

**解决：** 复用现有属性字段，用特殊值 `9999999` 标记已领取：
```lua
DaylityWorkCount == 9999999 → 已领取（不显示进度条）
DaylityPerfectWorkCount == 9999999 → 已领取
```

### 问题 5：页面打开/关闭切换主界面布局

**需求：** 打开任务页时切换到商店布局（ShanDianZhuUI），关闭时恢复默认。

**解决：**
```lua
-- Construct（打开时）
local ShopLayoutPath = UGCGameSystem.GetUGCResourcesFullPath(
    'Asset/Blueprint/Prefabs/UI/ShanDian/ShanDianZhuUI.ShanDianZhuUI_C')
UGCWidgetManagerSystem.SetWidgetLayout(ShopLayoutPath)

-- Button_54_OnClicked（关闭时）
local DefaultLayoutPath = UGCGameSystem.GetUGCResourcesFullPath(
    'Asset/UI/NewUGCWidgetLayoutBlueprint.NewUGCWidgetLayoutBlueprint_C')
UGCWidgetManagerSystem.SetWidgetLayout(DefaultLayoutPath)
```

### 问题 6：蓝图类路径带下划线

**现象：** `RenWu_1.RenWu_1_C` 路径中的下划线是蓝图命名规范，不能删除。

**解决：** 保留完整路径：
```
'Asset/Blueprint/Prefabs/UI/RenWu/RenWu_2.RenWu_2_C'  -- ✅ 正确
'Asset/Blueprint/Prefabs/UI/RenWu/RenWu_2.RenWu2_C'    -- ❌ 错误
```

### 问题 7：TextBlock 绑定属性自动更新

**需求：** 打开 UI 时 TextBlock 自动显示最新进度值。

**解决：** 用 `BindingProperty("Text", callback, self)` ——每次 UI 更新（Tick/刷新）时自动调用回调更新文本：
```lua
-- LuaInit 中绑定
self.TextBlock_391:BindingProperty("Text", self.TextBlock_391_Text, self);

-- 回调函数
function RenWu_1:TextBlock_391_Text(ReturnValue)
    local DaylityWorkCount = UGCAttributeSystem.GetGameAttributeValue(PlayerPawn, "DaylityWorkCount") or 0
    return string.format("(%d / 10)", math.min(math.floor(DaylityWorkCount), 10))
end
```

## 标准代码模式

### 模式 A：任务页面完整结构

```lua
---@class RenWu_X_C:UUserWidget
---@field Button_54 UButton           -- 关闭按钮
---@field Button_98 UButton           -- 领取按钮
---@field Image_386 UImage            -- 状态图标
---@field RenWuLan RenWuLan_C         -- 导航栏子Widget
---@field TextBlock_XX UTextBlock     -- 进度文本
--Edit Below--
local RenWu_X = { bInitDoOnce = false }

function RenWu_X:Construct()
    -- 切换布局
    local ShopLayoutPath = UGCGameSystem.GetUGCResourcesFullPath(
        'Asset/Blueprint/Prefabs/UI/ShanDian/ShanDianZhuUI.ShanDianZhuUI_C')
    UGCWidgetManagerSystem.SetWidgetLayout(ShopLayoutPath)
    -- 绑定按钮
    self.Button_54.OnClicked:Add(self.Button_54_OnClicked, self);
    self.Button_98.OnClicked:Add(self.Button_98_OnClicked, self);
    self:LuaInit();
end

function RenWu_X:LuaInit()
    if self.bInitDoOnce then return end
    self.bInitDoOnce = true;
    -- 绑定文本属性自动更新
    self.TextBlock_XX:BindingProperty("Text", self.TextBlock_XX_Text, self);
    -- 初始化任务状态
    self:RefreshTaskState()
    -- 注入父UI引用到RenWuLan
    if self.RenWuLan then
        self.RenWuLan.ParentWidget = self
    end
end
```

### 模式 B：任务状态刷新

```lua
--- 刷新任务状态（图标 + 按钮可用性）
function RenWu_X:RefreshTaskState()
    local PlayerController = STExtraGameplayStatics.GetFirstPlayerController(self)
    local PlayerPawn = PlayerController:K2_GetPawn()
    local CountValue = UGCAttributeSystem.GetGameAttributeValue(PlayerPawn, "AttrName") or 0
    CountValue = math.floor(CountValue)

    if CountValue >= 9999999 then
        -- 已领取：RW7 + 禁用按钮
        self:SetImageTexture(self.Image_386, 'TuPian/RenWu/RW7.RW7')
        self.Button_98:SetIsEnabled(false)
    elseif CountValue >= TARGET_COUNT then
        -- 达标：RW6 + 可点击
        self:SetImageTexture(self.Image_386, 'TuPian/RenWu/RW6.RW6')
        self.Button_98:SetIsEnabled(true)
    else
        -- 未达标：默认状态 + 禁用按钮
        self.Button_98:SetIsEnabled(false)
    end
end
```

### 模式 C：设置 Image 纹理

```lua
--- 设置Image控件纹理
---@param ImageWidget UImage
---@param RelativePath string 如 'TuPian/RenWu/RW6.RW6'
function RenWu_X:SetImageTexture(ImageWidget, RelativePath)
    if not ImageWidget or not RelativePath then return end
    local FullPath = UGCGameSystem.GetUGCResourcesFullPath(RelativePath)
    local Texture = UGCObjectUtility.LoadObject(FullPath)
    if Texture then
        ImageWidget:SetBrushFromTexture(Texture, true)
    end
end
```

### 模式 D：关闭/销毁 UI

```lua
function RenWu_X:Button_54_OnClicked()
    -- 恢复默认布局
    local DefaultLayoutPath = UGCGameSystem.GetUGCResourcesFullPath(
        'Asset/UI/NewUGCWidgetLayoutBlueprint.NewUGCWidgetLayoutBlueprint_C')
    UGCWidgetManagerSystem.SetWidgetLayout(DefaultLayoutPath)
    -- 隐藏并销毁
    UGCWidgetManagerSystem.HideWidget(self)
    UGCWidgetManagerSystem.DestroyWidget(self)
end
```

### 模式 E：页面跳转（RenWuLan 导航栏）

```lua
function RenWuLan:Image_XX_OnMouseButtonDownEvent(MyGeometry, MouseEvent, ReturnValue)
    -- 1. 关闭当前父UI
    if self.ParentWidget then
        UGCWidgetManagerSystem.HideWidget(self.ParentWidget)
        UGCWidgetManagerSystem.DestroyWidget(self.ParentWidget)
        self.ParentWidget = nil
    end
    -- 2. 创建新目标UI
    local PlayerController = STExtraGameplayStatics.GetFirstPlayerController(self)
    local TargetClass = UE.LoadClass(UGCGameSystem.GetUGCResourcesFullPath(
        'Asset/Blueprint/Prefabs/UI/RenWu/RenWu_X.RenWu_X_C'))
    local TargetUI = UserWidget.NewWidgetObjectBP(PlayerController, TargetClass)
    TargetUI:AddToViewport(500)
end
```

## 编写新任务页面的步骤

1. **创建蓝图**：在 `Asset/Blueprint/Prefabs/UI/RenWu/` 下新建 Widget 蓝图，命名如 `RenWu_3`
2. **添加控件**：TextBlock（进度）、Image（状态图标）、Button（领取）、Button（关闭），嵌入 RenWuLan
3. **编写脚本**：参照上述模式 A~E 填充代码
4. **注册 RPC**：
   - 在 `UGCPlayerController.lua` 的 `GetAvailableServerRPCs` 添加新函数名
   - 在 `UGCPlayerController.lua` 新增 `ServerRPC_ClaimXxxReward` 函数（`HasAuthority` 守卫）
5. **更新 GM**：在 `AttrCommands.lua` 的 `PlayerAttrNames` 中添加新属性名
6. **注册导航**：在 `RenWuLan.lua` 中添加新 Image 的跳转逻辑
