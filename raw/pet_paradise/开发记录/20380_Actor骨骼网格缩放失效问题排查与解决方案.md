# Actor 骨骼网格缩放失效问题排查与解决方案

> 本文档记录了 `pet_paradise` 项目中宠物缩放 `SetActorScale3D` 只改变了碰撞体但模型视觉上没有变大的问题排查与解决过程。核心原因是 **AvatarDisplayProxyComp 接管了角色可视化渲染**，导致直接操作骨骼网格组件无效。经历了多轮调试，最终通过 **统一缩放函数 + 多方法降级 + 客户端重试注册** 彻底解决。

## 涉及 API

| API | 生效范围 | 说明 |
|-----|---------|------|
| `SetActorScale3D({X,Y,Z})` | 服务端&客户端 | 设置 Actor 的根组件世界缩放，会影响碰撞体 |
| `SetWorldScale3D({X,Y,Z})` | 服务端&客户端 | 设置组件的世界缩放（不依赖父级） |
| `SetRelativeScale3D({X,Y,Z})` | 服务端&客户端 | 设置组件相对于父级的缩放 |
| `GetComponentsByClass(Class)` | 服务端&客户端 | 获取 Actor 上指定类的所有组件，返回数组（1-based，用 ipairs 遍历） |
| `UGCObjectUtility.FindClass("SkeletalMeshComponent")` | 服务端&客户端 | 通过类名字符串查找类对象 |
| `UGCAttributeSystem.AddGameAttributeChangedDelegate(Owner, AttrName, Callback)` | 服务端&客户端 | 注册属性变化回调，属性值变化时自动触发 |
| `UGCAttributeSystem.RemoveGameAttributeChangedDelegate(Owner, AttrName, Delegate)` | 服务端&客户端 | 移除属性变化回调（用于清理） |
| `UGCAttributeSystem.SetGameAttributeValue(Owner, AttrName, Value)` | **仅服务端** | 设置属性值，会自动同步到所有客户端 |
| `UGCAttributeSystem.GetGameAttributeValue(Owner, AttrName)` | 服务端&客户端 | 读取属性值 |
| `UGCGameSystem.SetTimer(Target, Callback, Delay, Loop)` | 服务端&客户端 | 设置定时器 |
| `UGCGameSystem.ClearTimer(Target, TimerId)` | 服务端&客户端 | 清除定时器 |
| `UGCActorComponentUtility.GetOwner(Actor)` | 服务端&客户端 | 获取 Actor 的拥有者（Player） |
| `pcall(func)` | 服务端&客户端 | Lua 安全调用，捕获异常防止崩溃 |

> **注意**：`SetWorldScale3D` 和 `SetActorScale3D` 的区别：
> - `SetActorScale3D` 是 Actor 级别，修改**根组件**的缩放，所有**子组件**的 WorldScale = 父级 Scale × 子级 RelativeScale。当根组件缩放时，碰撞体（CapsuleComponent/HitBox）会跟随变化。
> - `SetWorldScale3D` 是组件级别，直接设置该组件的世界缩放。对于根组件的子组件，如果父级没有 `bAbsoluteScale=true`，子组件的缩放会被父级缩放叠加影响。

## 问题现象

执行缩放代码后，从日志和视觉上观察到：

```
[LogUGCServer] [Pet+ApplyPetScale] SetActorScale3D完成, finalScale=7.0
[LogUGCServer] [Pet+ApplyPetScale] 找到AvatarDisplayProxyComp
[LogUGCServer] [Pet+ApplyPetScale] 共缩放 1 个SkeletalMeshComponent
[LogUGCServer] [Pet+ApplyPetScale] 缩放完成, finalScale=7.0
```

- 碰撞体（胶囊体）变大 ✅ → 碰撞检测正确
- 模型（视觉网格）未变大 ❌ → 角色看起来还是原来的大小
- 日志全部输出在 `LogUGCServer`（服务端），**客户端没有任何日志**

## 根因分析

### 1. AvatarDisplayProxyComp 接管角色可视化渲染

通过检查蓝图的 JSON 文件发现，宠物角色的组件结构中包含：

```
AvatarDisplayProxyComp : GenericCharacterAvatarDisplayProxyComponent
```

这是**角色显示代理组件**。它在运行时创建自己的显示网格体系，替代原生的 `CharacterMesh0`。也就是说：

- **碰撞/物理** ← CapsuleComponent（受`SetActorScale3D`控制 ✅）
- **可视化渲染** ← AvatarDisplayProxyComp 管理的一套独立网格（不继承根组件的缩放 ❌）

### 2. CachedMasterPoseComponent 的缩放方法问题

代理组件（`AvatarDisplayProxyComp`）持有 `CachedMasterPoseComponent` 属性，理论上应通过操作它来缩放显示网格。但实际发现：

| 方法 | 执行结果 |
|------|---------|
| `masterComp:SetWorldScale3D({...})` | ❌ 抛错（pcall 返回 false） |
| `masterComp:SetRelativeScale3D({...})` | ❌ 抛错（pcall 返回 false） |
| `masterComp.RelativeScale3D = {...}` | ✅ 属性赋值成功生效 |

说明该组件的 Lua 绑定**不暴露 `SetWorldScale3D` / `SetRelativeScale3D` 方法**，但支持直接属性赋值。

### 3. 服务端执行了但客户端没执行

所有日志都输出在 `LogUGCServer`（服务端），客户端从未执行 `ApplyPetScale`。原因是：

```
DelayDelegate(5秒后) → 检查 self.Player
  ├── 服务端: self.Player 有值 → PetSizeAddRateDelegate 注册成功 ✅
  └── 客户端: self.Player = nil（Owner复制延迟）→ 跳过注册 ❌
```

`PetSizeAddRateDelegate` 没有在客户端注册，因此 `PetSizeAddRate` 属性变化时，客户端不会触发缩放。而**服务端修改组件属性不会自动同步到客户端**。

### 4. pcall + meshScaled 的陷阱

```lua
-- ❌ 错误写法
pcall(function()
    masterComp:SetWorldScale3D(...)   -- 抛错
    ugcprint("缩放成功")               -- 不执行
end)
meshScaled = true                     -- 仍然执行！重试机制被跳过
```

`meshScaled = true` 放在 `pcall` 外部，即使内部方法抛错被 pcall 吞掉，`meshScaled` 仍被设为 `true`，导致后续的重试逻辑不触发。

## 最终解决方案

### 方案概述

采用 **统一缩放函数 + 4 种方法降级 + 客户端重试注册** 三层保障：

```
ApplyPetScale(baseScale)
  ├── Step 1: SetActorScale3D → 碰撞体 ✅
  ├── Step 2: CachedMasterPoseComponent 缩放
  │     ├── 方法A: SetWorldScale3D
  │     ├── 方法B: SetRelativeScale3D
  │     ├── 方法C: RelativeScale3D 属性赋值 ✅ (最终生效方案)
  │     └── 方法D: 遍历子组件缩放
  ├── Step 3: 遍历所有 SkeletalMeshComponent 兜底
  └── Step 4: 如果 Step2 失败，设置 1 秒后重试（最多 5 次）
```

**客户端注册重试**：
```
RegisterPetSizeAddRateDelegate()
  ├── 立即尝试: GetOwner(self) 有值 → 注册 ✅
  └── 失败: 设置 1 秒定时器重试，直到成功
```

### Pet.lua 核心代码

```lua
-- ==========================================
-- 统一缩放函数（4 种方法降级）
-- ==========================================

-- 计算最终缩放值（基础缩放 + PetSizeAddRate）
function Pet:GetFinalScale(baseScale)
    local player = UGCActorComponentUtility.GetOwner(self)
    local petSizeAddRate = UGCAttributeSystem.GetGameAttributeValue(player, "PetSizeAddRate") or 0
    return baseScale + petSizeAddRate
end

-- 统一应用宠物体型缩放
function Pet:ApplyPetScale(baseScale)
    local finalScale = self:GetFinalScale(baseScale)

    -- Step 1: 缩放根组件（控制碰撞体）
    pcall(function()
        self:SetActorScale3D({ X = finalScale, Y = finalScale, Z = finalScale })
    end)

    -- Step 2: 尝试 4 种方法缩放 CachedMasterPoseComponent
    local proxyOk, proxyComp = pcall(function()
        return self.AvatarDisplayProxyComp
    end)
    local meshScaled = false
    if proxyOk and proxyComp then
        local masterOk, masterComp = pcall(function()
            return proxyComp.CachedMasterPoseComponent
        end)
        if masterOk and masterComp then
            -- 方法A: SetWorldScale3D
            local compScaled = pcall(function()
                masterComp:SetWorldScale3D({ X = finalScale, Y = finalScale, Z = finalScale })
            end)
            -- 方法B: SetRelativeScale3D
            if not compScaled then
                compScaled = pcall(function()
                    masterComp:SetRelativeScale3D({ X = finalScale, Y = finalScale, Z = finalScale })
                end)
            end
            -- 方法C: 属性赋值 ✅ 最终生效方案
            if not compScaled then
                compScaled = pcall(function()
                    masterComp.RelativeScale3D = { X = finalScale, Y = finalScale, Z = finalScale }
                end)
            end
            -- 方法D: 遍历子组件
            if not compScaled then
                compScaled = pcall(function()
                    -- 遍历子SkeletalMeshComponent缩放
                    ...
                end)
            end
            if compScaled then
                meshScaled = true  -- 关键：放在 if 内部！
            end
        end
    end

    -- Step 3: 兜底所有 SkeletalMeshComponent
    ...

    -- Step 4: Step2 失败则延迟重试
    if not meshScaled then
        self.ScaleRetryTimer = UGCGameSystem.SetTimer(self, function()
            self:RetryScaleDisplayMesh(finalScale, 1)
        end, 1, false)
    end
end

-- ==========================================
-- 客户端注册重试机制
-- ==========================================

function Pet:RegisterPetSizeAddRateDelegate()
    if self.PetSizeAddRateDelegate then
        return
    end
    local owner = UGCActorComponentUtility.GetOwner(self)
    if owner then
        self.PetSizeAddRateDelegate = UGCAttributeSystem.AddGameAttributeChangedDelegate(
            owner, "PetSizeAddRate",
            function()
                local curSize = UGCAttributeSystem.GetGameAttributeValue(self, "Size") or 1
                self:ApplyPetScale(curSize)
            end
        )
    else
        -- Owner 不可用（客户端复制延迟），1 秒后重试
        self.RegisterPetSizeAddRateRetry = UGCGameSystem.SetTimer(self, function()
            self.RegisterPetSizeAddRateRetry = nil
            self:RegisterPetSizeAddRateDelegate()
        end, 1, false)
    end
end

-- ==========================================
-- 属性变化监听（在 ReceiveBeginPlay 中注册）
-- ==========================================

-- Size 属性变化（双端触发, 控制体型缩放）
self.SizeChangedDelegate = UGCAttributeSystem.AddGameAttributeChangedDelegate(
    self, "Size",
    function(owner, attrName, curValue)
        self:ApplyPetScale(curValue)
    end
)

-- PetSizeAddRate 属性变化（通过重试机制确保客户端也注册成功）
self:RegisterPetSizeAddRateDelegate()
```

## 完整工作流程图

```
服务端 PetSizeAddRate 变化
  │
  ├── PetSizeAddRateDelegate 触发
  │     └── ApplyPetScale(curSize)
  │           ├── SetActorScale3D → 碰撞体变大 ✅
  │           └── CachedMasterPoseComponent.RelativeScale3D = {7,7,7}
  │                 └── 服务端组件已缩放，但视觉不变（不自动同步到客户端）
  │
  └── PetSizeAddRate 属性同步到客户端
        │
        └── 客户端 PetSizeAddRateDelegate 触发（通过重试已注册成功）
              └── ApplyPetScale(curSize)
                    ├── SetActorScale3D → 碰撞体变大（客户端）✅
                    └── CachedMasterPoseComponent.RelativeScale3D = {7,7,7}
                          └── 视觉网格变大 ✅
```

## 调试过程复盘

### 第 1 轮：找到 CachedMasterPoseComponent

发现 `SetActorScale3D` 只变碰撞。确认 `AvatarDisplayProxyComp` 接管了渲染，`CachedMasterPoseComponent` 是操作显示网格的关键。

### 第 2 轮：SetWorldScale3D 抛错

调用 `CachedMasterPoseComponent:SetWorldScale3D()` 抛错被 pcall 吞掉。`meshScaled = true` 在 pcall 外部，导致重试机制被绕过。

**修复**：改为 `meshScaled = true` 放在 pcall 内部的成功分支。

### 第 3 轮：4 种方法降级

追加 `SetRelativeScale3D`、`RelativeScale3D` 属性赋值、子组件缩放。发现**属性赋值生效**。

### 第 4 轮：客户端没执行

虽然服务端缩放成功，但客户端视觉不变。发现 `PetSizeAddRateDelegate` 在客户端没注册（`self.Player` 为 nil）。

**修复**：`RegisterPetSizeAddRateDelegate()` 含重试机制，1 秒后重试直到 Owner 可用。

### 验证日志输出

```
[LogUGCServer] 服务端日志：缩放已执行
[LogUGCClient] 第1次重试: Owner不可用, 1秒后重试
[LogUGCClient] 第2次重试: 注册成功, owner=...
[LogUGCClient] PetSizeAddRate变化 → ApplyPetScale → 视觉缩放 ✅
```

## 关键注意事项

### 1. pcall + meshScaled = true 必须在成功分支内

```lua
-- ✅ 正确写法
if masterOk and masterComp then
    local ok = pcall(function()
        masterComp.RelativeScale3D = { X = 7, Y = 7, Z = 7 }
    end)
    if ok then
        meshScaled = true  -- 只有真正成功才设为 true
    end
end

-- ❌ 错误写法
pcall(function()
    masterComp:SetWorldScale3D(...)   -- 抛错
end)
meshScaled = true                     -- 仍会执行，重试被跳过
```

### 2. 组件属性方法 vs 属性赋值

不同组件的 Lua 绑定暴露的方法不同，部分组件可能不支持 `SetWorldScale3D`/`SetRelativeScale3D`，但支持直接属性赋值：

```lua
-- 可能抛错（方法不存在）
comp:SetWorldScale3D({ X = 7, Y = 7, Z = 7 })

-- 可能生效（属性赋值）
comp.RelativeScale3D = { X = 7, Y = 7, Z = 7 }
```

### 3. GetOwner 在客户端的复制延迟

`UGCActorComponentUtility.GetOwner(self)` 在客户端可能返回 nil（Actor 的 Owner 属性尚未复制完成）。解决方案是使用重试机制：

```lua
function Pet:RegisterDelegateWithRetry()
    if not self.Player then
        -- 1 秒后重试
        UGCGameSystem.SetTimer(self, callback, 1, false)
    end
end
```

### 4. 服务端修改组件属性不自动同步到客户端

服务端对运行时组件的属性赋值不会自动复制到客户端。必须通过**属性系统**（`SetGameAttributeValue` → 自动同步 → `AddGameAttributeChangedDelegate` 回调）来触发客户端的执行。

### 5. 清理所有定时器和委托

必须在 `ReceiveEndPlay` 中清理所有注册回调及定时器：

```lua
function Pet:ReceiveEndPlay()
    -- 清理属性回调
    if self.SizeChangedDelegate then
        UGCAttributeSystem.RemoveGameAttributeChangedDelegate(self, "Size", self.SizeChangedDelegate)
        self.SizeChangedDelegate = nil
    end
    if self.PetSizeAddRateDelegate then
        UGCAttributeSystem.RemoveGameAttributeChangedDelegate(self.Player, "PetSizeAddRate", self.PetSizeAddRateDelegate)
        self.PetSizeAddRateDelegate = nil
    end

    -- 清理定时器
    if self.ScaleRetryTimer then
        UGCGameSystem.ClearTimer(self, self.ScaleRetryTimer)
        self.ScaleRetryTimer = nil
    end
    if self.RegisterPetSizeAddRateRetry then
        UGCGameSystem.ClearTimer(self, self.RegisterPetSizeAddRateRetry)
        self.RegisterPetSizeAddRateRetry = nil
    end
end
```

### 6. 属性变化回调函数的 self 引用

`AddGameAttributeChangedDelegate` 的回调是闭包（closure），`self` 在创建时被捕获：

```lua
-- ReceiveBeginPlay 中，self 是 Pet actor
self.SizeChangedDelegate = UGCAttributeSystem.AddGameAttributeChangedDelegate(
    self, "Size",
    function(owner, attrName, curValue)
        -- 这里的 self 从外部闭包捕获，指向 Pet actor
        self:ApplyPetScale(curValue)
    end
)
```

## 常见问题排查表

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| `SetActorScale3D` 后碰撞体变大但模型不变 | AvatarDisplayProxyComp 接管了渲染 | 使用 `RelativeScale3D` 属性赋值方式缩放 CachedMasterPoseComponent |
| `GetComponentsByClass` 只找到 1 个组件 | 代理系统创建的网格不在组件列表中 | 优先使用 `CachedMasterPoseComponent` 方案 |
| `CachedMasterPoseComponent:SetWorldScale3D()` 抛错 | 该组件不暴露此方法 | 改用 `RelativeScale3D = {...}` 属性赋值 |
| `comp:GetName()` 报 "attempt to call a nil value" | 该环境不支持 GetName 方法 | 改用 `tostring(comp)` 或去掉命名日志 |
| `SetGameAttributeValue` 后回调未触发 | 属性名拼写错误或属性系统未初始化 | 检查属性名是否在枚举中定义，确认回调在 `ReceiveBeginPlay` 中注册 |
| 客户端模型未变化 | 服务端缩放未正确同步 + 客户端未注册回调 | 用 `AddGameAttributeChangedDelegate` 在客户端侧执行缩放，注意 Owner 复制延迟需重试 |
| `meshScaled = true` 重试不触发 | `meshScaled` 在 pcall 外部被错误设置 | 确保 `meshScaled = true` 在 pcall 成功分支内 |
