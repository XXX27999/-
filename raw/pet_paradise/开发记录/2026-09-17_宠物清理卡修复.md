## 一、现象

1. 背包使用「宠物清理卡」后无任何可感知效果（无提示、宠物清洁度照常下降）。
2. 同一道具在工程里两套名字：道具表/掉落表/商店表叫「粪便清理卡」，金币商店表与 UI 硬编码叫「宠物清理卡」。

## 五、工具与流程教训

- **补丁脚本必须幂等**：本轮 Python 补丁脚本重跑了 3 次，凡「old 串被 new 串包含」的项（在函数末尾追加代码）每次都会再插一份，`HelpLienCard` 因此被插入 3 份 `NotifyUseResult`，靠备份恢复重做。正确做法：每项配一个**只存在于新代码里的标识串**，命中即 `SKIP`，再配命中数断言 + 写回后复核。
- **DataTable 回读**：`data_table_as_dict()` 的 value 是 `UScriptStruct`，`str()` 看不到文本，要用 `row.ItemName` 或 `row.as_dict()`；`ue.load_object` 第一个参数必须是类（`from unreal_engine.classes import DataTable`）。
- **注释行前缀要与原文一致**：`Pet.lua` 里是 `-- 属性值变化处理…`（两个横杠），按 `---` 写锚点会 0 命中。
- PowerShell 回显会丢，脚本输出一律**写 UTF-8 文件再读**；`*>` 重定向默认是 UTF-16，不能直接读。
