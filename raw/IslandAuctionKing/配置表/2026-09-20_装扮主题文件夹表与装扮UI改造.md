### 1.1.1 列名（VarName）与列注释（FriendlyName）是两回事——本次只改了注释

用户要求「表格列注释要使用中文」，改的是**列头显示名**（`FriendlyName` / `ToolTip`），
**不是**列名 `VarName`。7 张表实测（2026-09-20 回读）：

- `VarName` 中文数 = **0**（7 张表全部仍为英文：`Category` / `CategoryName` / `Folder` / `ThemeFolder` …）
- `FriendlyName` 中文数 = **14/14**（一级分类标识 / 素材基目录 / 主题专属目录 / 主题中文名 …）
- 行数据按英文列名读取正常：`row.get_field('Folder')` = `ZhuJieMian`、`ThemeName` = `默认灰`、`UnlockState` = `Unlocked`

**为什么不能把 VarName 也改成中文**：

1. **代码按 VarName 取值**：`AuctionConfig.DRESS_THEME_TABLE_COLUMNS` 是英文列名清单，
   Lua 侧 `rowData[columnName]` 逐列取值；VarName 改成中文会让 14 个字段**全部取到空串**，
   进而在必填列校验里被判「行缺少必填列」→ 整张表装载失败 → 装扮 UI 退回内置兜底（静默不生效）。
2. **行数据与列按名序列化**：列名一变，已有行的值对不上新列（本次「删列重加」清空行值就是同一机制）。
3. **UGC 资产/字段命名规则**：工程文件名、变量标识须英文字母开头，中文 VarName 属违规风险区。

**结论：要中文只在 `FriendlyName` / `ToolTip` 上做，`VarName` 永远保持英文。**

**编辑器里看到中文列头 = 预期效果，不是列名被改**：DataTable 编辑器的列头显示的是 `FriendlyName`，
所以「列注释中文化」在编辑器里的表现就是列头变中文（2026-09-20 用户实测看到并确认）。
要看真正的标识名（`VarName`，英文）需打开行结构体资产 `UGCTemplateRowStruct_DressTheme<Key>Table`。
记忆点：**编辑器给人看 `FriendlyName`，代码取值用 `VarName`**。

#### 3.4.1 前置声明坑（Lua 词法作用域）

`ApplyToHostUI` / `PersistSelection` / `LoadStyleThemes` 被定义位置**更靠后**的函数调用，
必须先在模块顶部写 `local X = nil` 前置声明，并把定义从 `local function X` 改成 `function X`。
否则会在调用点拿到 `nil`（attempt to call a nil value），且报错位置在调用处而非定义处，很难定位。

## 5. 建表与改列的实测坑

1. **建表必须先 `objed_open_editor('DataTable')`**（2026-09-18 记录的「三种入口全失败」本次未复现）。
2. **新建表的默认 `MemberVar_0` bool 列删不干净**：要「re-load → 检查 → 删 → save」循环 3~4 轮。
3. **列注释（FriendlyName / ToolTip）改不动**：`v.set_field('FriendlyName', ...)` 与 `v.FriendlyName = ...`
   都只在 `struct_get_variables()` 返回的**副本**上生效，save 后回读仍是英文。
   **唯一可靠做法：删列 → 重加（`desc.set_field('FriendlyName', 中文)`）**。
   代价：① **行数据会被清空，重加后必须重写行**；② 可能残留一个同名重复列（本次多出一个 `SortOrder`），
   要按「FriendlyName 仍是英文」筛出来补删。
4. 改列/重写行前**先清空所有行**，否则旧行值与新列对不上。
5. `data_table_add_row` 返回 `None` 也算成功，一律以回读为准。
6. **扩展主题前先查 `Dress.Theme.StyleIds`**，不要凭印象写主题数量。
7. **表能加行 ≠ 主题可选**：`ThemeId` 必须落在 `Dress.Theme.StyleIds` 白名单内，否则 `IsValidStyleId` 校验失败、
   点按钮必然切换失败（日志 `主题ID不在配置列表中 styleId=g`）。2026-09-20 用户新加行填了 `g` 就是此坑。
8. **`Folder` 与 `ThemeFolder` 别填反**：`Folder` 恒存**基目录**（默认主题目录），只有 `ThemeFolder` 才是主题专属目录。
   把新行的 `Folder` 也写成 `ZhuJieMian_TestTopic` 会破坏「默认态 = 基目录不加后缀」的语义。
9. **`Preview` 要填真在用的素材名**：`ZJM2`/`ZJM4` 已被资源清单确认为「未被任何控件使用的废弃素材」，填了预览会取到无意义的图。
10. **行名不是摆设**：编辑器里新建行默认叫 `NewRow`，应按 `Dress.Theme.<UiKey>.<ThemeId>` 改名，否则后续排查认不出。
