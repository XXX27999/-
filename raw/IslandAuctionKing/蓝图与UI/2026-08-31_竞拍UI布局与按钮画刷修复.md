## 三、按钮画刷与点击入口

官方确认 `UButton.WidgetStyle` 是 `FButtonStyle`，包含 `Normal`、`Hovered`、`Pressed`、`Disabled` 四态 `FSlateBrush`；项目 MCP 回读确认目标控件类型为 `Button`。生产蓝图已对 22 个按钮写入 `AuctionUI_BottomButton`，对 `BidDisplayButton` 写入 `AuctionUI_FooterBid`，四态回读均为 `Texture2D`。

新增/更新运行时服务：

`D:\WeGameApps\rail_apps\OasisEraEditor(2001776)\ShadowTrackerExtra\UGCProjects\IslandAuctionKing\Script\Function\AuctionUITextureReplacementService.lua`

服务新增 `BUTTON_BINDINGS` 和 `ApplyButtonTexture`：

- 初始化时从 `UGCPlayerController.AuctionUITexturePaths.BottomButton` / `FooterBid` 读取路径。
- 通过 `button.WidgetStyle` 修改四态资源，再调用官方 `UButton:SetStyle(FButtonStyle&)` 提交完整样式。
- `FooterBidControlPanel` 纳入 `UBorder` 绑定，仍从控制器结构体读取 `FooterBid`。
- 原有 `OnClicked` 入口保留；`BidDisplayButton`、`LockBidButton`、底部功能按钮、数字键和藏品图鉴按钮继续由现有按钮事件触发，不改为不可点击的 `UImage` 事件。
- 局内切换路径后调用 `AuctionUITextureReplacementService.Refresh(widget)`，按钮与面板会一起重新读取结构体路径并刷新画刷。
