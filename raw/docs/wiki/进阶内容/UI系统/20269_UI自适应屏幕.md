# UI自适应屏幕

制作UI界面时，如果想要保证UI在不同分辨率的设备上以固定的比例正常显示，需要提前对UI进行自适应适配，否则可能出现缩放比例不正确或者非预期的控件间隔现象。

![UI自适应效果图.gif](../../_assets/images/e27e2ef0_k1xhMUI自适应效果图.gif)

## 设置层次结构

创建并进入【控件蓝图】界面（具体操作可参考 [UI系统快速入门](./347_快速入门.md)），将屏幕分辨率设定为1920*1080（16：9）或点击 ``设计师 -> 屏幕尺寸`` 设定为“Apple iPhone 6+(Landscape)”。

![image.5.png](../../_assets/images/c42d7673_6JNVWimage.5.png)

右键 ``画布面板 -> 包裹 -> 尺寸框`` 在承载UI界面的“画布面板”外包裹一层“尺寸框”。

![image.21.png](../../_assets/images/31c5e72b_UMf5Kimage.21.png)

右键 ``尺寸框 -> 包裹 -> 缩放框`` 在“尺寸框”外包裹一层“缩放框”。

![image.22.png](../../_assets/images/2b5414d9_xyCp7image.22.png)

右键 ``缩放框 -> 包裹 -> 画布面板`` 在“缩放框”外包裹一层“画布面板”。

![image.23.png](../../_assets/images/10b40447_LZz6Pimage.23.png)

最终层次结构如图所示。

![image.18.png](../../_assets/images/37d43493_N5boyimage.18.png)

## 相关参数设置

在 ``层次结构`` 中点击缩放框，在【详细信息】中将 ``锚点`` 更改为“四向拉伸”，并将“偏移左侧”、“偏移顶部”、“偏移右侧”和“偏移底部”数值均设置为0。

![image.24.png](../../_assets/images/2141c787_LuMPqimage.24.png)

点击尺寸框，在【详细信息】中对尺寸框的尺寸进行设置，``宽度重载`` 设定为1920，``高度重载`` 设定为1080。

![image.33.png](../../_assets/images/31e808fe_Iepmhimage.33.png)

点击画布面板，在【详细信息】中将 ``水平对齐`` 设定为“水平对齐填充”，``垂直对齐`` 为“垂直居中填充”。

![image.27.png](../../_assets/images/02c47d5c_lIILuimage.27.png)

---

### 居中型控件

若属于道具弹窗这类无需贴边的UI，调整尺寸框的 ``水平对齐`` 为水平对齐居中，``垂直对齐`` 为垂直居中对齐。

![image.31.png](../../_assets/images/51696e68_vY1VPimage.31.png)
![image.29.png](../../_assets/images/2d126f7d_2uIxRimage.29.png)

---

### 贴边型控件

若按钮有贴边需求，则调整尺寸框的 ``水平对齐`` 为水平右对齐，``垂直对齐`` 为垂直居中对齐。

![ScreenShot_2025-12-22_155524_627.png](../../_assets/images/ff3de549_S8tGpScreenShot_2025-12-22_155524_627.png)
![image.28.png](../../_assets/images/34f7368f_8znyIimage.28.png)

## 实现UI界面

完成以上层级结构设置后，开发者根据自身需要添加UI控件元素，该控件蓝图即带有自适应缩放效果。
