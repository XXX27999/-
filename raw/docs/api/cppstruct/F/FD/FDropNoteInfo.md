# FDropNoteInfo

Info about one note dropped in the map during PIE.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| Location | [FVector](../FV/FVector.md) | Location to create Note actor in edited level. |
| Rotation | [FRotator](../FR/FRotator.md) | Rotation to create Note actor in edited level. |
| Comment | `FString` | Text to assign to Note actor in edited level. |
