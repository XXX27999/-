# FPrimaryAssetRulesOverride

Simple structure to allow overriding asset rules for a specific primary asset. This can be used to set chunks

## Fields

| Name | Type | Description |
| --- | --- | --- |
| PrimaryAssetId | [FPrimaryAssetId](./FPrimaryAssetId.md) | Which primary asset to override the rules for |
| Rules | [FPrimaryAssetRules](./FPrimaryAssetRules.md) | What to overrides the rules with |
