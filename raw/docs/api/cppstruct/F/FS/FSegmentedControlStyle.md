# FSegmentedControlStyle

Represents the appearance of an SSegmentedControl

## Fields

| Name | Type | Description |
| --- | --- | --- |
| ControlStyle | [FCheckBoxStyle](../FC/FCheckBoxStyle.md) | The style to use for our Center Control |
| FirstControlStyle | [FCheckBoxStyle](../FC/FCheckBoxStyle.md) | The style to use for our Left Control |
| LastControlStyle | [FCheckBoxStyle](../FC/FCheckBoxStyle.md) | The style to use for our Left Control |
| BackgroundBrush | [FSlateBrush](./FSlateBrush.md) | Background of the segmented control |
| UniformPadding | [FMargin](../FM/FMargin.md) | Padding between each control |
