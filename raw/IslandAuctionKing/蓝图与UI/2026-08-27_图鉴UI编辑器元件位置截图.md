# 图鉴 UI 编辑器元件位置截图

- **日期**：2026-08-27
- **项目**：IslandAuctionKing（海岛竞拍王）
- **用途**：记录使用 FlaUI 在绿洲编辑器中打开 UI 编辑器并进入“元件”页后的可见状态。

## 实测步骤

1. 通过 FlaUI 唯一匹配窗口进程 `ShadowTrackerExtraUGCEditor`，激活绿洲编辑器。
2. 点击顶部工具栏“UI编辑器”。
3. 点击 UI 编辑器左侧“元件”。
4. 截取无遮挡的完整编辑器窗口。

## 实测结果

- “元件”页路径显示为 `IslandAuctionKing/Asset/Blueprint/Prefabs/UI`。
- 列表中可见 `CollectibleCodexItemUI` 与 `CollectibleCodexUI`，同时可见 `AuctionSettlementUI`、`AuctionTestUI`、`CharacterPropSelectTestUI`、`ZhuJieMian`。
- 截图为完整编辑器窗口，不是 UMG 画布裁剪。
- 截图文件：[2026-08-27_图鉴UI技能测试_步骤3_元件.png](../../../Screenshots/2026-08-27_图鉴UI技能测试_步骤3_元件.png)

## 工具与限制

- 操作和截图均使用 FlaUI helper，未使用 Windows 原生辅助组件。
- FlaUI 使用桌面 GDI 捕获，目标窗口必须可见且无遮挡。
- 本记录只证明当前编辑器中的可见位置，不改变 UI、蓝图、Lua、DataTable 或资产。
