## 实测结论摘要

| 项 | 错误做法（实测失败） | 正确做法（实测通过） |
|---|---|---|
| 控件蓝图类 | `from unreal_engine.classes import WidgetBlueprint` → ImportError | `ue.find_class('UGCWidgetBlueprint')` |
| 加载对象 | `ue.load_object(path)` 单参 | `ue.load_object(cls, path)` 双参 |
| plan mutations | 字符串列表 → `PRV_PLAN_INVALID` | `[{property, value}]` 对象列表 |
| 保存资产 | `ue.save_package(wbp)` → 无此属性 | `ue.objed_save_asset('Name', 'UI')` |
| 读 DataTable | `ue.data_table_as_dict(dt)` → 无此属性 | `dt.data_table_as_dict()` 对象方法 |
| 读行字段 | `v.get('MaterialSource')` → UScriptStruct 无 get | `v.MaterialSource`（逐个 try/except） |
| 写布局 | `ue.widget_slot(..., 'Position', ...)` → failed to set | Lua 运行时 `Slot:SetPosition` |

## 实测验证数据

- 创建：`ue.objed_create_asset('UI', '元件', '用户控件模板', 'AuctionDressUI')` → `/IslandAuctionKing/Asset/Blueprint/Prefabs/UI/AuctionDressUI`
- 控件树：70 控件分 4 批搭建（7 / 10 / 20 / 32），全部 `ADD_OK`，单批最快约 4 ms
- 保存后 `disk_size` 由建时 8,759 B 增至 35,460 B
- 控件名与 Lua 契约双向 diff：期望 68 项，`MISSING=[]`，`MATCH=True`
