# FComboButtonStyle

Represents the appearance of an SComboButton

## Fields

| Name | Type | Description |
| --- | --- | --- |
| ButtonStyle | [FButtonStyle](../FB/FButtonStyle.md) | The style to use for our SButton |
| DownArrowImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use for the down arrow |
| MenuBorderBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush to use to add a "menu border" around the drop-down content |
| MenuBorderPadding | [FMargin](../FM/FMargin.md) | Padding to use to add a "menu border" around the drop-down content |
