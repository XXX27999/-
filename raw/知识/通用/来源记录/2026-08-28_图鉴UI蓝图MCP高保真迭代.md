## 实测结论

1. `widget_slot` 不能可靠写入 `Position`、`Size` 或 `Offsets`。Canvas 控件几何必须通过 `w.Slot.SetPosition(ue.FVector2D(x, y))` 与 `w.Slot.SetSize(ue.FVector2D(width, height))`，然后编译、保存并回读 `LayoutData.Offsets`。
2. `from unreal_engine.structs import FVector2D` 在当前 UGCAskQ Python 环境会失败；应使用 `ue.FVector2D(x, y)`。
3. `widget_add` 后同一执行上下文中既有的 `WidgetTree.AllWidgets` 列表可能不包含新节点。可用 `ue.tobject_iterator(ue.find_class("Widget"))` 按控件名获取新节点句柄；新增节点仍须通过 `ue.widget_inspect` 回读树结构。
4. `UImage.Brush` 与 `Border.Background` 的贴图写入应采用现有画刷结构 `clone()`，设置 `ResourceObject` 与 `DrawAs` 后再 `set_property`；直接将资产路径写入画刷属性会失败或不渲染。
5. 目标蓝图本轮已通过 PRV Resolve/Plan/Execute 写入并截图验证：主背景、顶部栏、筛选面板、画廊面板、底部栏使用 `Codex_*` 贴图；关闭图标可见；摘要胶囊 Border 位于 `x=502/770/1038/1306,y=120,w=268,h=36`；排序按钮为 `1610,120,274,36`；清除按钮为 `50,764,372,46`。
