# FVolumeControlStyle

Represents the appearance of an SVolumeControl

## Fields

| Name | Type | Description |
| --- | --- | --- |
| SliderStyle | [FSliderStyle](../FS/FSliderStyle.md) | The style of the volume control slider |
| HighVolumeImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the volume is set to high |
| MidVolumeImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the volume is set to mid-range |
| LowVolumeImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the volume is set to low |
| NoVolumeImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the volume is set to off |
| MutedImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the volume is muted |
