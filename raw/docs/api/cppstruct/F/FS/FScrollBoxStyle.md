Represents the appearance of an SScrollBox

## Fields

| Name | Type | Description |
| --- | --- | --- |
| TopShadowBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the top shadow of a scrollbox |
| BottomShadowBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the bottom shadow of a scrollbox |
| LeftShadowBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the left shadow of a scrollbox |
| RightShadowBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the right shadow of a scrollbox |
