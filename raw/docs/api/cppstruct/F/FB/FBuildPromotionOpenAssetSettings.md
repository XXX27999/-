| MaterialAsset | [FFilePath](../FF/FFilePath.md) | The material asset to open |
| ParticleSystemAsset | [FFilePath](../FF/FFilePath.md) | The particle system asset to open |
| SkeletalMeshAsset | [FFilePath](../FF/FFilePath.md) | The skeletal mesh asset to open |
| StaticMeshAsset | [FFilePath](../FF/FFilePath.md) | The static mesh asset to open |
| TextureAsset | [FFilePath](../FF/FFilePath.md) | The texture asset to open |
