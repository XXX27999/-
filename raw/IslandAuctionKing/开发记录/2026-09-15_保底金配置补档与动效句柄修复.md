## 一、真因：表存在，但没人加载

`Asset/Data/Table/Customized/Guarantee/GuaranteeConfigTable`（含独立行结构
`UGCTemplateRowStruct_GuaranteeConfigTable`）**在 2026-09-15 之前就已建好**，里面已经有 10 行
`Guarantee.*` 与 `UI.Guarantee.*`。但 `AuctionConfig.LoadFromTable` 只加载了三张表：

| 加载器 | 表 | 本轮前是否加载 |
| --- | --- | --- |
| `AuctionGlobalConfigTableService` | 全局玩法表 | 是 |
| `AuctionUIConfigTableService` | `UI/UIConfigTable` | 是 |
| `AuctionConfig.LoadGameplayConfigTable` | `Gameplay/GameplayConfigTable` | 是 |
| **（无）** | **`Guarantee/GuaranteeConfigTable`** | **否 ← 缺陷** |

所以 `AuctionConfig.GetNumber("Guarantee.GoldFloor", 10000)` 每次都走回退常量，
表面上「值刚好一样」掩盖了缺陷 —— 只有日志里 `未命中配置 path=Guarantee.*` 才暴露。

> **排查结论**：判断「配置是否生效」不能只看界面数值，要看 `AuctionConfig+LoadFromTable`
> 的 `xxxConfigLoaded=` 汇总与 `rowName=` 逐行日志。

### 2.5 `AuctionUIMotionService.lua`：句柄改 Lua 侧弱键缓存

缺陷：原实现把 Tween 句柄直接写到控件上（`target.AuctionMotionPressHandle = handle`）。
`UButton` / `UTextBlock` 这类纯 UObject 子控件**不接受 Lua 动态属性**，引擎抛
`LuaExtend::Lua_SetPropertyValue Failed ... PropName [AuctionMotionPressHandle]: property not exist`，
而且句柄实际没存下来 —— 同一按钮连点时无法 kill 上一个 Tween。

修复：模块内加弱键缓存表，三处状态全部改走缓存：

```lua
local MotionState = setmetatable({}, { __mode = "k" }) -- 控件 → { PressHandle, FadeHandle, CloseToken }

local function GetMotionState(target)
    local state = MotionState[target]
    if state == nil then
        state = {}
        MotionState[target] = state
    end
    return state
end
```

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| `StopPress` | `target.AuctionMotionPressHandle` | `GetMotionState(target).PressHandle` |
| `StopFade` | `target.AuctionMotionFadeHandle` | `GetMotionState(target).FadeHandle` |
| `PlayPress` | 回写控件属性 | `GetMotionState(target).PressHandle = handleOrError` |
| `PlayOpacityTween` | 回写控件属性 | `GetMotionState(target).FadeHandle = handleOrError` |
| `PlayPanelOpen/Close` | `panel.AuctionMotionCloseToken` | `GetMotionState(panel).CloseToken` |

> `AuctionMotionHiding`（各处 UIService 写在**页面级 UserWidget** 上）不报错，本轮**未动**。
