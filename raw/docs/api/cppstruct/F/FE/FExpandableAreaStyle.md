# FExpandableAreaStyle

Represents the appearance of an SExpandableArea

## Fields

| Name | Type | Description |
| --- | --- | --- |
| CollapsedImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the area is collapsed |
| ExpandedImage | [FSlateBrush](../FS/FSlateBrush.md) | Image to use when the area is expanded |
| RolloutAnimationSeconds | `float` | How long the rollout animation lasts |
