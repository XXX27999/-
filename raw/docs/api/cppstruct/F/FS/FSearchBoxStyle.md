# FSearchBoxStyle

Represents the appearance of an SSearchBox

## Fields

| Name | Type | Description |
| --- | --- | --- |
| TextBoxStyle | [FEditableTextBoxStyle](../FE/FEditableTextBoxStyle.md) | Style to use for the text box part of the search box |
| ActiveFontInfo | [FSlateFontInfo](./FSlateFontInfo.md) | Font to use for the text box part of the search box when a search term is entered |
| UpArrowImage | [FSlateBrush](./FSlateBrush.md) | Image to use for the search "up" arrow |
| DownArrowImage | [FSlateBrush](./FSlateBrush.md) | Image to use for the search "down" arrow |
| GlassImage | [FSlateBrush](./FSlateBrush.md) | Image to use for the search "glass" |
| ClearImage | [FSlateBrush](./FSlateBrush.md) | Image to use for the search "clear" button |
| ImagePadding | [FMargin](../FM/FMargin.md) | Padding to use around the images |
| bLeftAlignButtons | `bool` | If true, buttons appear to the left of the search text |
