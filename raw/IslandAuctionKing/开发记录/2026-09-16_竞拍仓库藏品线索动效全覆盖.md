# 2026-09-16 竞拍仓库藏品线索动效全覆盖

## 一、术语对齐（重要检索提示）

工程内**没有「线索」二字**。玩家口中的「藏品线索」在本工程对应的是**情报（Intel / InfoType）**，分两大来源：

| 来源 | 代码位置 | 说明 |
| --- | --- | --- |
| 角色技能情报（含开局） | 服务端 `AuctionCharacterSkillService.ExecuteForPlayer` → `player.LastSkillIntel` → `AuctionPlayerService.BuildPrivateState` | **开局线索**即 `mainRound == 1` 时按 `character.InitialTargetCount` 发放的那一份 |
| 道具情报 | `AuctionPropUseService` → `AuctionWarehouseFeedbackService.StartClientFeedback` | 按 `InfoType` 分 Quality/Shape/Full/Value/Count/… |
| 公共情报 | `AuctionPublicIntelService.PublishForBidRound`（第 1、3 竞价轮） | 五类聚合：ItemCount/OccupiedSlots/QualityCount/TypeCount/TotalValueRange |

## 二、开局线索定位链（关键结论）

1. `AuctionCharacterSkillService:ShouldTrigger`：`GameStart` → `mainRound == 1`；`GameStartAndEachRound` / `EachRound` → `mainRound >= 1`。
2. `ExecuteForPlayer` 第 288 行：`if tonumber(mainRound) == 1 and tonumber(character.InitialTargetCount) > 0 then targetCount = InitialTargetCount end` → **开局发放量走 `InitialTargetCount`**。
3. 结果写入 `player.LastSkillIntel`，经 `AuctionPlayerService.BuildPrivateState`（第 644 行 `LastSkillIntel`）下发。
4. 客户端 `AuctionTestUIService.RefreshPrivateState` 缓存到 `widget.AuctionPrivateState`，`AuctionCharacterSkillUIService.Refresh` 只把文本写进 `SkillIntelText`；`RefreshWarehouse` 里 `isSkillMarked` 只影响**资源加载失败时的回退标签**（第 1033 行 `"★"`），资源显示成功时标签为空 → **开局线索此前完全没有动效**。

## 三、四类零动效缺口（本轮补齐）

| 缺口 | 位置 | 原因 |
| --- | --- | --- |
| ① 开局 / 每轮技能线索 | `AuctionCharacterSkillUIService.Refresh` | 只有文本，无 Tween |
| ② 公共情报 | `AuctionWarehouseFeedbackService.RefreshClientPublicIntelFeedback` | 末尾 `warehouseCellFeedbackSuppressed=true`，主动不做仓库格反馈 |
| ③ 道具 Shape / Full | `ApplyClientFeedback` 的 `suppressSingleCell` 分支 | 由整轮廓/藏品图承担，单格反馈被抑制且无替代动效 |
| ④ 道具 Aggregate（`Scope == "Warehouse"`） | `StartClientFeedback` 的 `scope == "Warehouse"` 分支 | 直接 `warehouseScopeSkippedCount + 1` 跳过 |

## 四、实现

### 4.1 新增 `Script/Function/AuctionClueFeedbackService.lua`（编排层）

- `InitializeClient` / `ShutdownClient`：状态为 `widget.AuctionClueFeedbackState = {SkillIntelToken, PublicIntelSequence, Initialized}`。
- `ObserveSkillIntel(widget)`：用 `Character|MainRound|InfoType|Triggered|#Items|有序 MarkedItemIndices` 构造指纹去重；`Triggered ~= true` 不播；`ReplayOnFirstObserve`（默认 true）保证 UI 首帧拿到的开局线索不漏播。
  - 有轮廓（`widget.AuctionItemByIndex[idx].Cells`）→ `PlayOutlineClue`（整轮廓格波浪 + 藏品图飞入 + 情报卡闪）
  - 无轮廓（纯品质技能线索）或 `MarkedItemIndices` 为空 → `PlayAggregateClue`（整仓波浪 + 情报卡闪）
- `PlayPublicIntelClue` / `PlayAggregateClue` / `PlayOutlineClue` / `PlayIntelCardClue` / `StopAllClueMotions`。

### 4.2 `AuctionUIMotionService.lua` 新增动效原语

- `PlayClueFeedbackMotion(target, options)`：**飞入（`SetRenderTranslation`）+ 弹出 + 渐显** → `PlayClueFlashPhase` → 复位。
- `PlayClueFlashPhase(target, token, settings)`：1.0 ↔ `FlashMinOpacity` 往返 `FlashCount` 次。
- `PlayClueWaveMotion(targets, options)`：**单个 Tween 驱动全部目标错峰脉冲**（`localPhase = (progress - stagger) / span`，`pulse = sin(localPhase * π)`），Tween 数量恒为 1。
- `StopClueMotion(target, options)`：token 自增 + kill + 复位 scale/opacity/translation/背景色。
- `ApplyCachedScale` / `ApplyCachedOpacity`：千分位/百分位量化缓存，跳过重复写入。

**强度对齐品质闪烁（实测基线）**

| 参数 | 品质线索（旧） | 线索反馈（新） |
| --- | --- | --- |
| PopScale | 1.35 | **1.45** |
| FlashCount | 3 | **4**（代码强制 `math.max(3, …)`） |
| FlashMinOpacity | 0.45 | **0.28** |
| 飞入 | 无 | **有**（`FlyInOffsetY = -36`） |
| 高亮底色 | 无 | **有**（按线索类型分色） |

**规避 FSlateColor 坑**：全部只用 `SetRenderScale` / `SetRenderOpacity` / `SetRenderTranslation` / `SetBackgroundColor`，**不调用 `SetColorAndOpacity`**。

### 4.3 触发点接入

- `AuctionTestUIService`：Initialize 调 `InitializeClient`；`RefreshPrivateState` 末尾调 `ObserveSkillIntel`；Shutdown 调 `ShutdownClient`。
- `AuctionWarehouseFeedbackService`：
  - `RefreshClientPublicIntelFeedback` 命中新 Sequence → `PlayPublicIntelClue`
  - `ApplyClientFeedback` 的 `suppressSingleCell` 分支收集整轮廓格 → `state.OutlineMotionPlayed` 去重后 `PlayOutlineClue`
  - `StartClientFeedback` 的 `Scope == "Warehouse"` 且无归属格 → `PlayAggregateClue`
  - `ClearClientFeedback` / `ShutdownClient` 联动停止与清理

## 五、性能约束

- 多目标走**单 Tween 错峰波浪**：36 格整仓波浪 Tween 数 = 1，不是 36。
- 量化缓存跳过重复属性写入；`MaxTargets`（当前 36）封顶。
- 单目标最多 2 个 Tween（弹出 + 闪烁），全部走既有弱键 `MotionState` 与 token 机制，可被后续动效 kill。
- 未使用定时器轮询，不新增 Tick 负担。
