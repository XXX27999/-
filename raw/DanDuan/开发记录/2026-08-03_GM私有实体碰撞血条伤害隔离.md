## 已实现功能

- GM 在指定玩家右侧默认 150 单位、抬高 20 单位的位置创建怪物或物件。
- 服务端设置 `PrivateEntityId`、`PrivateEntityType`、`PrivateEntityOwnerKey` 和 Actor Owner。
- Actor 始终复制，客户端根据本地 PlayerKey 与 OwnerKey 比较结果应用显隐。
- 非 Owner 客户端关闭 Actor 碰撞，并对 HitBox、Capsule、Mesh 等关键 PrimitiveComponent 设置 `NoCollision`。
- 非 Owner 客户端将默认血条显示距离、条件距离和显示时长设为 0，并关闭受伤、锁定、瞄准和遮挡显示条件。
- Owner 客户端缓存并恢复原始 Actor 碰撞、组件碰撞和血条配置。
- 服务端遍历所有 PlayerPawn，对非 Owner 玩家和实体组件双向调用 `IgnoreActorWhenMoving`。
- 实体碰撞组件设置 `bBulletCanBreakThrough=true`，降低隐藏实体阻挡其他玩家子弹的影响。
- `TakeDamage` 在父类扣血流程前按 PlayerKey 拒绝非 Owner 伤害。
- `PreOverrideDamageValue` 在公式层再次把非 Owner 伤害归零。
- `PostTakeDamageEvent` 只为 Owner 伤害更新表现并发送受伤 RPC。
- 每秒重新应用客户端隔离和服务端玩家移动忽略，兼容新加入玩家及父类重新开启状态。
- RPC 保持固定 `CF_KHDRPC` / `CF_FWDRPC` 分发模式，没有向 `UGCPlayerController.lua` 增加普通业务 RPC。

-- 脚本: UGCGameMode.lua
---@class UGCGameMode_C:BP_UGCGameBase_C

local UGCGameMode = {
    PrivateEntitySerial = 0, -- 私有实体序号
}

--- GM创建指定玩家的私有实体，实体由服务端生成并复制，由客户端按Owner决定显隐。
---@param PlayerKey number 目标玩家Key
---@param EntityType string 实体类型，Monster或Object
---@param SpawnOffset table 生成位置相对玩家Pawn的偏移，字段为X/Y/Z
---@return AActor|nil 生成成功的实体，失败时返回nil
function UGCGameMode:GM_CreatePrivateEntity(PlayerKey, EntityType, SpawnOffset)
    local HasAuthority = self:HasAuthority() -- 当前GameMode是否运行在服务端
    ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】入口 PlayerKey=%s EntityType=%s HasAuthority=%s self=%s", tostring(PlayerKey), tostring(EntityType), tostring(HasAuthority), tostring(self)))

    if HasAuthority then
        local NormalizedEntityType = string.lower(tostring(EntityType or "")) -- 规范化后的实体类型
        local EntityClassPath = nil -- 实体蓝图类路径
        local PlayerController = nil -- 目标玩家Controller
        local PlayerPawn = nil -- 目标玩家Pawn
        local PawnLocation = nil -- 目标玩家当前位置
        local PawnRightVector = nil -- 目标玩家右方向向量
        local PawnForwardVector = nil -- 目标玩家前方向向量
        local OffsetX = 150 -- 玩家右侧默认偏移
        local OffsetY = 0 -- Y轴默认偏移
        local OffsetZ = 20 -- Z轴默认偏移
        local SpawnLocation = nil -- 实体生成位置
        local EntityClass = nil -- 实体蓝图类
        local SpawnedActor = nil -- 新生成的实体
        local ActualOwner = nil -- 实体实际Owner
        local PrivateEntityId = nil -- 私有实体唯一标识
        local CollisionFilterResult = false -- 私有实体服务端碰撞隔离结果
        local PCallSuccess = false -- 保护调用是否成功
        local PCallError = nil -- 保护调用错误信息

        if NormalizedEntityType == "monster" then
            EntityClassPath = "Asset/Blueprint/Prefabs/Monsters/guaiwu.guaiwu_C"
            ugcprint("【UGCGameMode+GM_CreatePrivateEntity】分支=Monster")
        elseif NormalizedEntityType == "object" then
            EntityClassPath = "Asset/Blueprint/Prefabs/LevelEntities/wujian.wujian_C"
            ugcprint("【UGCGameMode+GM_CreatePrivateEntity】分支=Object")
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 EntityType不支持=%s", tostring(EntityType)))
            return nil
        end

        if type(SpawnOffset) == "table" then
            OffsetX = tonumber(SpawnOffset.X) or OffsetX
            OffsetY = tonumber(SpawnOffset.Y) or OffsetY
            OffsetZ = tonumber(SpawnOffset.Z) or OffsetZ
        else
            ugcprint("【UGCGameMode+GM_CreatePrivateEntity】分支=使用默认偏移 SpawnOffset不是table")
        end

        PlayerController = UGCGameSystem.GetPlayerControllerByPlayerKey(PlayerKey)
        if PlayerController == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 找不到PlayerController PlayerKey=%s", tostring(PlayerKey)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 PlayerController=%s", tostring(PlayerController)))
        end

        PlayerPawn = UGCGameSystem.GetPlayerPawnByPlayerKey(PlayerKey)
        if PlayerPawn == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 找不到PlayerPawn PlayerKey=%s", tostring(PlayerKey)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 PlayerPawn=%s", tostring(PlayerPawn)))
        end

        PCallSuccess, PCallError = pcall(function()
            PawnLocation = PlayerPawn:K2_GetActorLocation()
            PawnRightVector = PlayerPawn:GetActorRightVector()
            PawnForwardVector = PlayerPawn:GetActorForwardVector()
        end)
        if PCallSuccess == false or PawnLocation == nil or PawnRightVector == nil or PawnForwardVector == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 获取Pawn位置或方向失败 Location=%s Right=%s Forward=%s Error=%s", tostring(PawnLocation), tostring(PawnRightVector), tostring(PawnForwardVector), tostring(PCallError)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 PawnLocation=%s RightVector=%s ForwardVector=%s", tostring(PawnLocation), tostring(PawnRightVector), tostring(PawnForwardVector)))
        end

        SpawnLocation = Vector.New(
            PawnLocation.X + PawnRightVector.X * OffsetX + PawnForwardVector.X * OffsetY,
            PawnLocation.Y + PawnRightVector.Y * OffsetX + PawnForwardVector.Y * OffsetY,
            PawnLocation.Z + OffsetZ
        )
        EntityClass = UGCObjectUtility.LoadClass(UGCGameSystem.GetUGCResourcesFullPath(EntityClassPath))
        if EntityClass == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 加载实体Class失败 Path=%s", EntityClassPath))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 EntityClass=%s SpawnLocation=%s", tostring(EntityClass), tostring(SpawnLocation)))
        end

        PCallSuccess, PCallError = pcall(function()
            SpawnedActor = UGCActorComponentUtility.SpawnActor(
                self,
                EntityClass,
                SpawnLocation,
                Rotator.New(0, 0, 0),
                Vector.New(1, 1, 1),
                PlayerController
            )
        end)
        if PCallSuccess == false or SpawnedActor == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 SpawnActor失败 Error=%s", tostring(PCallError)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 SpawnedActor=%s Owner=%s", tostring(SpawnedActor), tostring(PlayerController)))
        end

        self.PrivateEntitySerial = self.PrivateEntitySerial + 1
        PrivateEntityId = string.format("PE_%s_%d", tostring(PlayerKey), self.PrivateEntitySerial)
        SpawnedActor.PrivateEntityId = PrivateEntityId
        SpawnedActor.PrivateEntityType = NormalizedEntityType
        SpawnedActor.PrivateEntityOwnerKey = PlayerKey

        PCallSuccess, PCallError = pcall(function()
            UGCActorComponentUtility.SetOwner(SpawnedActor, PlayerController)
            ActualOwner = UGCActorComponentUtility.GetOwner(SpawnedActor)
        end)
        if PCallSuccess == false or ActualOwner == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 设置或回读Owner失败 PrivateEntityId=%s ExpectedOwner=%s ActualOwner=%s Error=%s", PrivateEntityId, tostring(PlayerController), tostring(ActualOwner), tostring(PCallError)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键数据 Owner校验成功 PrivateEntityId=%s ExpectedOwner=%s ActualOwner=%s OwnerMatched=%s", PrivateEntityId, tostring(PlayerController), tostring(ActualOwner), tostring(ActualOwner == PlayerController)))
        end

        PCallSuccess, PCallError = pcall(function()
            SpawnedActor.bOnlyRelevantToOwner = false
            SpawnedActor.bOwningSpecificNetConsideration = false
            SpawnedActor.bAlwaysRelevant = true
            SpawnedActor:SetReplicates(true)
            SpawnedActor:SetReplicateMovement(true)
            SpawnedActor:ForceNetUpdate()
        end)
        if PCallSuccess == false then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 配置Owner相关复制失败 PrivateEntityId=%s ActualOwner=%s Error=%s", PrivateEntityId, tostring(ActualOwner), tostring(PCallError)))
            return nil
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键逻辑 始终复制已开启，客户端按Owner显隐 PrivateEntityId=%s ActualOwner=%s", PrivateEntityId, tostring(ActualOwner)))
        end

        if SpawnedActor.ApplyPrivateEntityServerCollisionFilters == nil then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 实体未实现服务端碰撞隔离 PrivateEntityId=%s SpawnedActor=%s", PrivateEntityId, tostring(SpawnedActor)))
            return nil
        else
            PCallSuccess, PCallError = pcall(function()
                CollisionFilterResult = SpawnedActor:ApplyPrivateEntityServerCollisionFilters()
            end)
        end
        if PCallSuccess == false or CollisionFilterResult == false then
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】错误 首次服务端碰撞隔离失败，实体定时器将继续重试 PrivateEntityId=%s Result=%s Error=%s", PrivateEntityId, tostring(CollisionFilterResult), tostring(PCallError)))
        else
            ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键逻辑 首次服务端碰撞隔离成功 PrivateEntityId=%s", PrivateEntityId))
        end

        ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】关键逻辑 客户端显隐复制 PrivateEntityId=%s bOnlyRelevantToOwner=%s bOwningSpecificNetConsideration=%s bAlwaysRelevant=%s", PrivateEntityId, tostring(SpawnedActor.bOnlyRelevantToOwner), tostring(SpawnedActor.bOwningSpecificNetConsideration), tostring(SpawnedActor.bAlwaysRelevant)))
        ugcprint(string.format("【UGCGameMode+GM_CreatePrivateEntity】出口 成功 PrivateEntityId=%s EntityType=%s", PrivateEntityId, NormalizedEntityType))
        return SpawnedActor
    else
        ugcprint("【UGCGameMode+GM_CreatePrivateEntity】分支=客户端 拒绝执行，GM创建必须在服务端")
        return nil
    end
end

--- 获取怪物需要隔离的碰撞组件，并去除重复组件。
---@return table 碰撞组件列表
function guaiwu:GetPrivateEntityCollisionComponents()
    local Components = {} -- 怪物碰撞组件列表
    local CandidateComponents = {HitBox = self.HitBox, CapsuleComponent = self.CapsuleComponent, Mesh = self.Mesh} -- 怪物候选碰撞组件
    ugcprint(string.format("【guaiwu+GetPrivateEntityCollisionComponents】入口 self=%s HasAuthority=%s", tostring(self), tostring(self:HasAuthority())))
    for CandidateName, CandidateComponent in pairs(CandidateComponents) do -- 遍历候选组件名称和对象
        local IsDuplicated = false -- 当前组件是否已经加入列表
        if CandidateComponent ~= nil then
            for ExistingIndex, ExistingComponent in ipairs(Components) do -- 遍历已加入组件索引和对象
                if ExistingComponent == CandidateComponent then
                    IsDuplicated = true
                    ugcprint(string.format("【guaiwu+GetPrivateEntityCollisionComponents】分支=跳过重复组件 CandidateName=%s ExistingIndex=%s Component=%s", tostring(CandidateName), tostring(ExistingIndex), tostring(CandidateComponent)))
                    break
                end
            end
            if IsDuplicated == false then
                table.insert(Components, CandidateComponent)
            end
        else
            ugcprint(string.format("【guaiwu+GetPrivateEntityCollisionComponents】分支=组件为空 CandidateName=%s", tostring(CandidateName)))
        end
    end
    ugcprint(string.format("【guaiwu+GetPrivateEntityCollisionComponents】出口 ComponentCount=%s", tostring(#Components)))
    return Components
end

            bHealthBarShowWhenBeAimAt = self.bHealthBarShowWhenBeAimAt,
            ComponentCollisionStates = {},
        }
        for ComponentIndex, Component in ipairs(Components) do -- 遍历碰撞组件索引和对象
            table.insert(self.PrivateEntityClientDefaults.ComponentCollisionStates, {
                Component = Component,
                CollisionEnabled = Component:GetCollisionEnabled(),
            })
            ugcprint(string.format("【guaiwu+CachePrivateEntityClientDefaults】关键数据 ComponentIndex=%s Component=%s CollisionEnabled=%s", tostring(ComponentIndex), tostring(Component), tostring(Component:GetCollisionEnabled())))
        end
    end)
    if PCallSuccess then
        ugcprint("【guaiwu+CachePrivateEntityClientDefaults】出口 缓存成功")
        return true
    else
        self.PrivateEntityClientDefaults = nil
        ugcprint(string.format("【guaiwu+CachePrivateEntityClientDefaults】错误 缓存失败 Error=%s self=%s", tostring(PCallError), tostring(self)))
        return false
    end
end

--- 根据复制的OwnerKey设置当前客户端怪物的显隐和本地碰撞。
---@return boolean 是否成功应用客户端显隐
function guaiwu:ApplyPrivateEntityVisibility()
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local LocalPlayerKey = nil -- 当前客户端玩家Key
    local IsOwnerClient = false -- 当前客户端是否为实体Owner
    local PCallSuccess = false -- 显隐调用是否成功
    local PCallError = nil -- 显隐调用错误信息
    ugcprint(string.format("【guaiwu+ApplyPrivateEntityVisibility】入口 HasAuthority=%s self=%s PrivateEntityId=%s OwnerKey=%s", tostring(HasAuthority), tostring(self), tostring(self.PrivateEntityId), tostring(self.PrivateEntityOwnerKey)))
    if HasAuthority then
        ugcprint("【guaiwu+ApplyPrivateEntityVisibility】分支=服务端 不调用客户端显隐API")
        return true
    else
        LocalPlayerKey = UGCGameSystem.GetLocalPlayerKey()
        IsOwnerClient = LocalPlayerKey ~= nil and self.PrivateEntityOwnerKey ~= nil and tostring(LocalPlayerKey) == tostring(self.PrivateEntityOwnerKey)
        local CacheResult = self:CachePrivateEntityClientDefaults() -- 客户端默认状态缓存结果
        if CacheResult == false then
            ugcprint("【guaiwu+ApplyPrivateEntityVisibility】错误 默认状态缓存失败，继续强制应用隔离")
        else
            ugcprint("【guaiwu+ApplyPrivateEntityVisibility】关键逻辑 默认状态缓存可用")
        end
        PCallSuccess, PCallError = pcall(function()
            self:SetActorHiddenInGame(not IsOwnerClient)
            if IsOwnerClient and self.PrivateEntityClientDefaults ~= nil then
                self:SetActorEnableCollision(self.PrivateEntityClientDefaults.ActorCollisionEnabled)
                self.HealthBarWidgetClass = self.PrivateEntityClientDefaults.HealthBarWidgetClass
                self.HealthBarMaxShowDistance = self.PrivateEntityClientDefaults.HealthBarMaxShowDistance
                self.HealthBarConditionShowDistance = self.PrivateEntityClientDefaults.HealthBarConditionShowDistance
                self.HealthBarShowDuration = self.PrivateEntityClientDefaults.HealthBarShowDuration
                self.bHealthBarShowWhenOcclusionHide = self.PrivateEntityClientDefaults.bHealthBarShowWhenOcclusionHide
                self.bHealthBarShowWhenTakeDamage = self.PrivateEntityClientDefaults.bHealthBarShowWhenTakeDamage
                self.bHealthBarShowWhenLockPlayer = self.PrivateEntityClientDefaults.bHealthBarShowWhenLockPlayer
                self.bHealthBarShowWhenBeAimAt = self.PrivateEntityClientDefaults.bHealthBarShowWhenBeAimAt
                for StateIndex, ComponentState in ipairs(self.PrivateEntityClientDefaults.ComponentCollisionStates) do -- 遍历Owner待恢复的组件状态
                    ComponentState.Component:SetCollisionEnabled(ComponentState.CollisionEnabled)
                    ugcprint(string.format("【guaiwu+ApplyPrivateEntityVisibility】关键数据 Owner恢复组件碰撞 StateIndex=%s Component=%s CollisionEnabled=%s", tostring(StateIndex), tostring(ComponentState.Component), tostring(ComponentState.CollisionEnabled)))
                end
            else
                self:SetActorEnableCollision(false)
                self.HealthBarMaxShowDistance = 0
                self.HealthBarConditionShowDistance = 0
                self.HealthBarShowDuration = 0
                self.bHealthBarShowWhenOcclusionHide = false
                self.bHealthBarShowWhenTakeDamage = false
                self.bHealthBarShowWhenLockPlayer = false
                self.bHealthBarShowWhenBeAimAt = false
                local Components = self:GetPrivateEntityCollisionComponents() -- 非Owner客户端待关闭的碰撞组件
                for ComponentIndex, Component in ipairs(Components) do -- 遍历非Owner碰撞组件索引和对象
                    Component:SetCollisionEnabled(ECollisionEnabled.NoCollision)
                    Component.bBulletCanBreakThrough = true
                    ugcprint(string.format("【guaiwu+ApplyPrivateEntityVisibility】关键数据 非Owner关闭组件碰撞 ComponentIndex=%s Component=%s", tostring(ComponentIndex), tostring(Component)))
                end
            end
            if self.Mesh ~= nil then
                self.Mesh:SetVisibility(IsOwnerClient, true, false)
                self.Mesh:SetHiddenInGame(not IsOwnerClient, true)
            end
        end)
        if PCallSuccess then
            ugcprint(string.format("【guaiwu+ApplyPrivateEntityVisibility】出口 显隐已应用 LocalPlayerKey=%s OwnerKey=%s IsOwnerClient=%s", tostring(LocalPlayerKey), tostring(self.PrivateEntityOwnerKey), tostring(IsOwnerClient)))
            return true
        else
            ugcprint(string.format("【guaiwu+ApplyPrivateEntityVisibility】错误 显隐调用失败 LocalPlayerKey=%s OwnerKey=%s Error=%s", tostring(LocalPlayerKey), tostring(self.PrivateEntityOwnerKey), tostring(PCallError)))
            return false
        end
    end
end

--- 在服务端为非Owner玩家建立双向移动忽略，避免隐藏实体阻挡玩家。
---@return boolean 是否完成碰撞隔离
function guaiwu:ApplyPrivateEntityServerCollisionFilters()
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local PlayerPawns = nil -- 当前全部玩家Pawn
    local Components = nil -- 怪物碰撞组件列表
    local PCallSuccess = false -- 服务端碰撞隔离调用是否成功
    local PCallError = nil -- 服务端碰撞隔离错误信息
    ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】入口 HasAuthority=%s self=%s OwnerKey=%s", tostring(HasAuthority), tostring(self), tostring(self.PrivateEntityOwnerKey)))
    if HasAuthority == false then
        ugcprint("【guaiwu+ApplyPrivateEntityServerCollisionFilters】分支=客户端 拒绝执行服务端碰撞隔离")
        return false
    elseif self.PrivateEntityOwnerKey == nil then
        ugcprint("【guaiwu+ApplyPrivateEntityServerCollisionFilters】错误 OwnerKey=nil，等待生成逻辑设置Owner后重试")
        return false
    end

    PCallSuccess, PCallError = pcall(function()
        PlayerPawns = UGCGameSystem.GetAllPlayerPawn() or {}
        Components = self:GetPrivateEntityCollisionComponents()
        for ComponentIndex, Component in ipairs(Components) do -- 遍历怪物碰撞组件索引和对象
            Component.bBulletCanBreakThrough = true
            ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】关键数据 开启子弹穿透 ComponentIndex=%s Component=%s", tostring(ComponentIndex), tostring(Component)))
        end
        for PawnIndex, PlayerPawn in ipairs(PlayerPawns) do -- 遍历玩家Pawn索引和对象
            local PlayerKey = UGCGameSystem.GetPlayerKeyByPlayerPawn(PlayerPawn) -- 当前玩家Key
            local IsOwnerPlayer = PlayerKey ~= nil and tostring(PlayerKey) == tostring(self.PrivateEntityOwnerKey) -- 当前玩家是否为实体Owner
            for ComponentIndex, Component in ipairs(Components) do -- 遍历实体碰撞组件索引和对象
                Component:IgnoreActorWhenMoving(PlayerPawn, not IsOwnerPlayer)
                ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】关键数据 实体侧移动忽略 PawnIndex=%s ComponentIndex=%s PlayerKey=%s IsOwner=%s", tostring(PawnIndex), tostring(ComponentIndex), tostring(PlayerKey), tostring(IsOwnerPlayer)))
            end
            if PlayerPawn.CapsuleComponent ~= nil then
                PlayerPawn.CapsuleComponent:IgnoreActorWhenMoving(self, not IsOwnerPlayer)
                ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】关键数据 玩家侧移动忽略 PawnIndex=%s PlayerKey=%s IsOwner=%s", tostring(PawnIndex), tostring(PlayerKey), tostring(IsOwnerPlayer)))
            else
                ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】错误 PlayerPawn.CapsuleComponent=nil PawnIndex=%s PlayerKey=%s", tostring(PawnIndex), tostring(PlayerKey)))
            end
        end
    end)
    if PCallSuccess then
        ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】出口 隔离成功 PlayerCount=%s", tostring(PlayerPawns and #PlayerPawns or 0)))
        return true
    else
        ugcprint(string.format("【guaiwu+ApplyPrivateEntityServerCollisionFilters】错误 隔离失败 Error=%s self=%s", tostring(PCallError), tostring(self)))
        return false
    end
end

--- 校验本次伤害是否由私有实体Owner玩家造成。
---@param EventInstigator AController 伤害来源Controller
---@return boolean 是否为Owner伤害
function guaiwu:IsPrivateEntityOwnerDamage(EventInstigator)
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local InstigatorPlayerKey = nil -- 伤害来源玩家Key
    local PCallSuccess = false -- PlayerKey查询是否成功
    local PCallError = nil -- PlayerKey查询错误信息
    local IsOwnerDamage = false -- 是否为Owner玩家造成伤害
    ugcprint(string.format("【guaiwu+IsPrivateEntityOwnerDamage】入口 EventInstigator=%s HasAuthority=%s self=%s OwnerKey=%s", tostring(EventInstigator), tostring(HasAuthority), tostring(self), tostring(self.PrivateEntityOwnerKey)))
    if HasAuthority == false then
        ugcprint("【guaiwu+IsPrivateEntityOwnerDamage】错误 当前为客户端，伤害归属必须在服务端校验")
        return false
    elseif EventInstigator == nil then
        ugcprint("【guaiwu+IsPrivateEntityOwnerDamage】错误 EventInstigator=nil，拒绝未知来源伤害")
        return false
    end

    PCallSuccess, PCallError = pcall(function()
        InstigatorPlayerKey = UGCGameSystem.GetPlayerKeyByPlayerController(EventInstigator)
    end)
    if PCallSuccess == false then
        ugcprint(string.format("【guaiwu+IsPrivateEntityOwnerDamage】错误 获取攻击者PlayerKey失败 Error=%s EventInstigator=%s", tostring(PCallError), tostring(EventInstigator)))
        return false
    else
        IsOwnerDamage = InstigatorPlayerKey ~= nil and self.PrivateEntityOwnerKey ~= nil and tostring(InstigatorPlayerKey) == tostring(self.PrivateEntityOwnerKey)
        ugcprint(string.format("【guaiwu+IsPrivateEntityOwnerDamage】出口 InstigatorPlayerKey=%s OwnerKey=%s IsOwnerDamage=%s", tostring(InstigatorPlayerKey), tostring(self.PrivateEntityOwnerKey), tostring(IsOwnerDamage)))
        return IsOwnerDamage
    end
end

---@param DamageCauser AActor 伤害来源Actor

--- 在Actor伤害入口拒绝非Owner玩家，并仅为Owner调用父类伤害流程。

---@param DamageEvent FDamageEvent 伤害事件
---@param EventInstigator AController 伤害来源Controller
---@param DamageCauser AActor 伤害来源Actor
---@return float 实际应用的伤害值
function guaiwu:TakeDamage(Damage, DamageEvent, EventInstigator, DamageCauser)
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local IsOwnerDamage = false -- 是否为Owner玩家伤害

    ugcprint(string.format("【guaiwu+TakeDamage】入口 Damage=%s DamageEvent=%s EventInstigator=%s DamageCauser=%s HasAuthority=%s self=%s OwnerKey=%s", tostring(Damage), tostring(DamageEvent), tostring(EventInstigator), tostring(DamageCauser), tostring(HasAuthority), tostring(self), tostring(self.PrivateEntityOwnerKey)))

        IsOwnerDamage = self:IsPrivateEntityOwnerDamage(EventInstigator)

        end
    else
        ugcprint("【guaiwu+TakeDamage】分支=客户端 不做权威过滤，保持父类表现流程")
    end

    SuperCallSuccess, AppliedDamage = pcall(function()
        return guaiwu.SuperClass.TakeDamage(self, Damage, DamageEvent, EventInstigator, DamageCauser)
    end)
    if SuperCallSuccess then
        ugcprint(string.format("【guaiwu+TakeDamage】出口 父类伤害流程完成 AppliedDamage=%s", tostring(AppliedDamage)))

--- 定时重应用私有实体隔离，处理新加入玩家和父类重新开启碰撞的情况。
---@param DeltaTime float 帧间隔
---@return nil 无返回值
function guaiwu:ReceiveTick(DeltaTime)
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local RefreshInterval = 1 -- 隔离状态刷新间隔秒数
    self.PrivateEntityIsolationElapsed = (self.PrivateEntityIsolationElapsed or RefreshInterval) + (tonumber(DeltaTime) or 0)
    if self.PrivateEntityIsolationElapsed >= RefreshInterval then
        self.PrivateEntityIsolationElapsed = 0
        if HasAuthority then
            local FilterResult = self:ApplyPrivateEntityServerCollisionFilters() -- 服务端移动碰撞隔离结果
            ugcprint(string.format("【guaiwu+ReceiveTick】分支=服务端 定时刷新碰撞隔离 Result=%s self=%s OwnerKey=%s", tostring(FilterResult), tostring(self), tostring(self.PrivateEntityOwnerKey)))
        else
            local VisibilityResult = self:ApplyPrivateEntityVisibility() -- 客户端显隐、血条和碰撞隔离结果
            ugcprint(string.format("【guaiwu+ReceiveTick】分支=客户端 定时刷新隔离 Result=%s self=%s OwnerKey=%s", tostring(VisibilityResult), tostring(self), tostring(self.PrivateEntityOwnerKey)))
        end
    else
        if self.PrivateEntityIsolationTickLogged ~= true then
            self.PrivateEntityIsolationTickLogged = true
            ugcprint(string.format("【guaiwu+ReceiveTick】关键数据 隔离定时器已启动 DeltaTime=%s HasAuthority=%s self=%s", tostring(DeltaTime), tostring(HasAuthority), tostring(self)))
        end
    end
end

--- 通过固定FWDRPC入口通知Owner客户端私有实体受伤或死亡。
---@param FuncName string 客户端事件函数名
---@param ... any 事件参数
---@return boolean 是否已发起RPC
function guaiwu:SendPrivateEntityEvent(FuncName, ...)
    local HasAuthority = self:HasAuthority() -- 当前怪物是否在服务端
    local OwnerController = self.Owner -- 私有怪物Owner Controller
    local PCallSuccess = false -- 保护调用是否成功
    local PCallError = nil -- 保护调用错误信息
    ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】入口 FuncName=%s HasAuthority=%s self=%s Owner=%s PrivateEntityId=%s", tostring(FuncName), tostring(HasAuthority), tostring(self), tostring(OwnerController), tostring(self.PrivateEntityId)))

    if self.PrivateEntityIsClientOnly == true then
        local Value = nil -- 受伤值或致死伤害
        local ExtraValue = nil -- 伤害类型ID
        local PrivateEntityId = nil -- 私有实体ID
        local PrivateEntityType = nil -- 私有实体类型
        local EventType = nil -- 上报事件类型
        OwnerController = UGCGameSystem.GetLocalPlayerController()
        if OwnerController == nil then
            ugcprint("【guaiwu+SendPrivateEntityEvent】错误 客户端本地PlayerController=nil")
            return false
        end
        if FuncName == "ClientPrivateEntityTakeDamage" then
            Value, PrivateEntityId, PrivateEntityType = ...
            EventType = "Damage"
        elseif FuncName == "ClientPrivateEntityDie" then
            Value, ExtraValue, PrivateEntityId, PrivateEntityType = ...
            EventType = "Die"
        else
            ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】错误 客户端私有实体事件未注册 FuncName=%s", tostring(FuncName)))
            return false
        end
        PCallSuccess, PCallError = pcall(UnrealNetwork.CallUnrealRPC, OwnerController, OwnerController, "KHDRPC_Call", "ServerPrivateEntityEvent", EventType, PrivateEntityId, PrivateEntityType, Value, ExtraValue)
        if PCallSuccess then
            ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】出口 客户端事件已上报 EventType=%s PrivateEntityId=%s", tostring(EventType), tostring(PrivateEntityId)))
            return true
        else
            ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】错误 客户端事件上报失败 EventType=%s Error=%s", tostring(EventType), tostring(PCallError)))
            return false
        end
    end

    if HasAuthority then
        if OwnerController == nil then
            ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】错误 OwnerController=nil FuncName=%s", tostring(FuncName)))
            return false
        else
            PCallSuccess, PCallError = pcall(UnrealNetwork.CallUnrealRPC, OwnerController, OwnerController, "FWDRPC_Call", FuncName, self, ...)
            if PCallSuccess then
                ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】出口 RPC已发起 FuncName=%s", tostring(FuncName)))
                return true
            else
                ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】错误 RPC调用失败 FuncName=%s Error=%s", tostring(FuncName), tostring(PCallError)))
                return false
            end
        end
    else
        ugcprint(string.format("【guaiwu+SendPrivateEntityEvent】分支=客户端 拒绝从客户端发起事件 FuncName=%s", tostring(FuncName)))
        return false
    end
end

--- 怪物受到伤害后在服务端触发，并通过RPC通知Owner客户端。
---@param Damage float 伤害值
---@param EventInstigator AController 伤害来源Controller
---@param DamageCauser AActor 伤害来源Actor
---@param DamageContext FGameMagnitudeContext 伤害上下文
---@return nil 无返回值

                if Rate < 1 and Rate > 0.5 then
                    self.ShakeAmplitude = 4
                    self.ShakeSpeed = 1
                    ugcprint(string.format("【wujian+PostTakeDamageEvent】分支=轻度受伤 Rate=%s", tostring(Rate)))

                    self.ShakeAmplitude = 9
                    self.ShakeSpeed = 6
                    ugcprint(string.format("【wujian+PostTakeDamageEvent】分支=重度受伤 Rate=%s", tostring(Rate)))
                else
                    ugcprint(string.format("【wujian+PostTakeDamageEvent】分支=无震荡 Rate=%s", tostring(Rate)))
                end
            end

            local RPCResult = self:SendPrivateEntityEvent("ClientPrivateEntityTakeDamage", Damage, self.PrivateEntityId, self.PrivateEntityType) -- 受伤RPC结果
            ugcprint(string.format("【wujian+PostTakeDamageEvent】关键判断 Owner伤害已通知Owner客户端 RPCResult=%s", tostring(RPCResult)))

        end

        ugcprint("【wujian+PostTakeDamageEvent】分支=客户端 未执行服务端属性和RPC逻辑")

--- 物件每帧在Owner客户端执行震荡表现。
---@param DeltaTime float 帧间隔
---@return nil 无返回值
function wujian:ReceiveTick(DeltaTime)
    local HasAuthority = self:HasAuthority() -- 当前物件是否在服务端
    local RefreshInterval = 1 -- 隔离状态刷新间隔秒数
    self.PrivateEntityIsolationElapsed = (self.PrivateEntityIsolationElapsed or RefreshInterval) + (tonumber(DeltaTime) or 0)
    if self.PrivateEntityIsolationElapsed >= RefreshInterval then
        self.PrivateEntityIsolationElapsed = 0
        if HasAuthority then
            local FilterResult = self:ApplyPrivateEntityServerCollisionFilters() -- 服务端移动碰撞隔离结果
            ugcprint(string.format("【wujian+ReceiveTick】分支=服务端 定时刷新碰撞隔离 Result=%s self=%s OwnerKey=%s", tostring(FilterResult), tostring(self), tostring(self.PrivateEntityOwnerKey)))
        else
            local VisibilityResult = self:ApplyPrivateEntityVisibility() -- 客户端显隐、血条和碰撞隔离结果
            ugcprint(string.format("【wujian+ReceiveTick】分支=客户端 定时刷新隔离 Result=%s self=%s OwnerKey=%s", tostring(VisibilityResult), tostring(self), tostring(self.PrivateEntityOwnerKey)))
        end
    end
    if HasAuthority then
        if self.PrivateEntityTickLogged ~= true then
            self.PrivateEntityTickLogged = true
            ugcprint("【wujian+ReceiveTick】分支=服务端 跳过客户端震荡表现")
        end
    else
        if self.ShakeAmplitude > 0 and self.ShakeSpeed > 0 then
            self.ShakeTime = self.ShakeTime + DeltaTime
            local ShakeX = math.sin(self.ShakeTime * self.ShakeSpeed * 2 * math.pi) * self.ShakeAmplitude -- X轴震荡值
            local ShakeY = math.cos(self.ShakeTime * self.ShakeSpeed * 2 * math.pi * 1.5) * self.ShakeAmplitude * 0.7 -- Y轴震荡值
            local NewLocation = Vector.New(ShakeX, ShakeY, self.CacheZ) -- 新的相对位置
            self.StaticMesh:K2_SetRelativeLocation(NewLocation, false, nil, false)
        end
    end
end

## 遇到的问题

### 1. Owner-only 网络相关性导致实体延迟出现

早期方案依赖 `bOnlyRelevantToOwner` 和 Owner ActorChannel。历史日志表明，实体没有在创建后立即到达 Owner 客户端，而是在实体受伤后才打开 ActorChannel，导致“攻击到怪物或物件时才看得见”。这说明当前两个通用实体基类和项目网络相关性组合下，单纯依赖 Owner-only 复制不稳定。

### 2. 仅隐藏模型没有关闭碰撞

切换为始终复制后，非 Owner 客户端能够隐藏模型，但 Actor 和组件碰撞是独立状态。服务端仍然参与玩家移动和权威命中判定，所以其他玩家仍可能被看不见的实体阻挡。

### 3. 默认血条由通用实体基类独立管理

`SetActorHiddenInGame` 和 Mesh 的 `SetVisibility` 不等于关闭 `UGCGenericCharacter` 的默认血条。受伤、锁定或瞄准条件仍可能触发血条显示。

### 4. 客户端关闭碰撞不能阻止服务端扣血

伤害和生命值由服务端权威处理。即使非 Owner 客户端已经执行 `SetActorEnableCollision(false)`，其他玩家的攻击仍可能在服务端命中实体并调用父类扣血流程。

### 5. 可破坏物伤害覆盖文档不完整

官方 Markdown 明确记录了怪物的 `PreOverrideDamageValue`，但没有单独确认 `BP_UGC_DamagableActor_C` 的同名事件。为避免只依赖不完整文档，本次增加了 UGCAskQ 反射确认存在的 `TakeDamage` 前置过滤，同时保留 `PreOverrideDamageValue` 作为第二层防线。其实际 Lua 覆写链仍需 PIE 日志确认。

### 6. 运行证据覆盖范围不同

最新 DS 日志已经命中服务端碰撞隔离逻辑，用户也明确确认最终版测试成功，因此可以记录功能已通过 PIE 验收。但 `guaiwu+TakeDamage` 和 `wujian+TakeDamage` 的定向扫描均为 0 命中，所以伤害隔离、死亡与 RPC 的成功属于用户验收证据，不能写成日志直接证明。

## 解决方案

### 问题 1：复制可见性

采用“服务端 Actor 始终复制，客户端按 OwnerKey 隔离”的方案。完整实现已嵌入上面的 `UGCGameMode.lua`、`guaiwu.lua` 和 `wujian.lua`。关键点是先设置私有标识和 Owner，再开启始终复制并调用 `ForceNetUpdate`。

### 问题 2：其他玩家仍有实体碰撞

客户端同时关闭 Actor 与每个关键 PrimitiveComponent 的碰撞；服务端对实体组件与非 Owner 玩家 CapsuleComponent 双向调用 `IgnoreActorWhenMoving`。官方文档特别指出：只让一侧忽略可能不够，移动的另一侧也可能需要同样设置，因此代码两侧都执行。

### 问题 3：其他玩家仍显示血条

非 Owner 客户端不修改蓝图 CDO，而是只修改当前客户端上的 Actor 实例：

- 所有血条触发布尔值设为 `false`
- `HealthBarMaxShowDistance=0`
- `HealthBarConditionShowDistance=0`
- `HealthBarShowDuration=0`

Owner 客户端从 `PrivateEntityClientDefaults` 恢复原始值，避免全局关闭 Owner 的正常血条。

### 问题 4：其他玩家仍能造成伤害

服务端使用两层校验：

1. `TakeDamage` 在调用父类前比较 `UGCGameSystem.GetPlayerKeyByPlayerController(EventInstigator)` 与 `PrivateEntityOwnerKey`，非 Owner 直接返回 0。
2. `PreOverrideDamageValue` 在全局伤害公式前再次执行同样判断，非 Owner 返回 0。

`PostTakeDamageEvent` 再次校验，防止零伤害或异常回调触发震荡、受伤 RPC 和 Owner 客户端表现。

### 问题 5：玩家中途加入或状态被父类覆盖

两个实体都在 `ReceiveTick` 中按 1 秒间隔重新应用隔离：

- 服务端刷新所有 PlayerPawn 的移动忽略关系。
- 客户端重新应用 Owner 显隐、碰撞和血条条件。

首次隔离失败只记录错误，由定时器继续重试，不会因为隔离初始化失败直接把 GM 创建结果判定为失败。

### RPC 调用链

客户端请求创建：

```text
客户端 GM 操作
-> UnrealNetwork.CallUnrealRPC(..., "KHDRPC_Call", "ServerGM_CreatePrivateEntity", EntityType)
-> UGCPlayerController:KHDRPC_Call

-> ServerGM_CreatePrivateEntity

```

服务端通知 Owner 受伤或死亡：

```text

-> UnrealNetwork.CallUnrealRPC(..., "FWDRPC_Call", ClientFunction, ...)
-> UGCPlayerController:FWDRPC_Call
-> CF_FWDRPC
-> OnPrivateEntityTakeDamage / OnPrivateEntityDie
```

## 关键经验

- Actor 隐藏、Mesh 隐藏、组件碰撞、服务端移动碰撞、伤害判定和血条显示是不同系统，必须分别处理。
- 客户端关闭碰撞只影响本地表现，不能代替服务端权威伤害过滤。
- `IgnoreActorWhenMoving` 是移动忽略关系，不等于全局关闭碰撞；按玩家隔离时应在实体组件和玩家移动组件两侧设置。
- 私有血条不能通过修改蓝图 CDO 全局关闭，应在每个客户端 Actor 实例上根据 OwnerKey 设置。
- 伤害过滤应尽量发生在父类扣血前，同时在公式覆盖和后置事件中保留防线与日志。
- 未知攻击来源的 `EventInstigator=nil` 默认拒绝，避免环境伤害或异常调用绕过私有 Owner 校验。
- Owner-only 网络相关性在通用怪物/可破坏物基类上必须以实际 ActorChannel 日志验证，不能只依赖属性名称推断。
- RPC 继续使用 `CF_KHDRPC` / `CF_FWDRPC` 白名单分发，Controller 只保留固定入口。
- 新增生命周期函数、Tick、复制属性响应或伤害覆写后，应重新调试 PIE，不能把热更新当作可靠验证。
- 静态语法通过、蓝图 CDO 回读成功和 API 文档命中都不等于运行成功；最终需结合 PIE 用户验收与可获得的客户端、DS 日志形成证据闭环。
