## 现象

双击 `D:\知识库\和平精英绿洲起源\双击运行本地同步.cmd` 后：

1. Wiki 同步完成：词条 323，新增 9，更新 18，删除 1，下载图片 102，耗时 5.7 秒。
2. API 目录 4/4 完成。
3. API 详情停在 `2734/6196 (44%)`。
4. PowerShell 抛出：`Sync process failed with exit code: -1073740791`。
5. 知识库镜像未开始替换，因为 `Sync-OasisDocs.ps1` 只在远端进程退出码为 0 后才复制。

## 根因

退出码 `-1073740791` 对应 `0xC0000409`（`STATUS_STACK_BUFFER_OVERRUN`）。`cli-runner.mjs` 若捕获到 JS 异常会打印 `同步失败：...` 并返回 1；本次没有该行，说明 Node 进程在 API 详情阶段直接崩溃。

修复前的 `syncApi`：

- 使用 Node 24 内置 `fetch`
- 默认 12 路并发
- 先把全部详情 Markdown 放进内存，再进入 finalize 写盘

Wiki 已写入 `D:\oasis-skill-plus\docs\wiki`，但 API 未完成，知识库仍保留上一份完整镜像。

## 修复

1. 新增 `D:\oasis-skill-plus\src\http-client.mjs`：原生 `http/https`、20 秒超时、连接池 `maxSockets=4`、429/5xx/超时重试。
2. `api-client.mjs` / `wiki-client.mjs` 改为走该 HTTP 层。
3. `api-sync.mjs` 默认并发改为 4，抓到一条 API 详情立即写盘，不再缓存全部正文。
4. `Sync-OasisDocs.ps1` 增加 `-SkipRemote`，远端已成功时只镜像。

## 验证

- `npm test`：新增 HTTP 测试与原有 `syncApi` / `syncWiki` 测试通过。启动脚本中英文文案和查询脚本路径测试是既有失败，与本次崩溃无关。
- `node src/cli.mjs sync-api` 完成：实体 6196，class 1401，cppenum 3692，cppstruct 1100，globalfunc 3，`lastSyncedAt=09/11/2026 06:06:30`。
- `-SkipRemote` 镜像后源/目标文件数一致：Wiki 3773，API 6201；抽样 SHA-256 一致。
