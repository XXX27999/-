# FBlueprintEditorPromotionSettings

Holds settings for the blueprint editor build promotion tests

## Fields

| Name | Type | Description |
| --- | --- | --- |
| FirstMeshPath | [FFilePath](../FF/FFilePath.md) | The starting mesh for the blueprint |
| SecondMeshPath | [FFilePath](../FF/FFilePath.md) | The mesh to set on the blueprint after the delay |
| DefaultParticleAsset | [FFilePath](../FF/FFilePath.md) | Default particle asset to use for tests |
