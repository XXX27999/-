Holds settings for the editor build promotion test

## Fields

| Name | Type | Description |
| --- | --- | --- |
| DefaultStaticMeshAsset | [FFilePath](../FF/FFilePath.md) | Default static mesh asset to apply materials to |
| ImportWorkflow | [FBuildPromotionImportWorkflowSettings](./FBuildPromotionImportWorkflowSettings.md) | Import workflow settings |
| OpenAssets | [FBuildPromotionOpenAssetSettings](./FBuildPromotionOpenAssetSettings.md) | Open assets settings |
| NewProjectSettings | [FBuildPromotionNewProjectSettings](./FBuildPromotionNewProjectSettings.md) | New project settings |
| SourceControlMaterial | [FFilePath](../FF/FFilePath.md) | Material to modify for the content browser step |
