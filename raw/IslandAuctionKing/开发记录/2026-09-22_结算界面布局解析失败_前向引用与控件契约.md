## 三、根因 1（主因）：local 函数前向引用 → nil

```lua
806  local scrollGeometryOK, scrollGeometryReason = ApplySettlementScrollGeometry(widget, metrics, ...)   -- 使用点
870  local function ApplySettlementScrollGeometry(widget, metrics, originX, originY)                       -- 定义点（更靠后）
```

Lua 的 `local function X` 只在**定义语句执行之后**才绑定；806 行所在闭包在运行时被调用时，若该 upvalue 尚未赋值就是 `nil`，于是报
`attempt to call a nil value (global 'ApplySettlementScrollGeometry')`（注意报的是 **global**，因为 local 未捕获）。

连锁后果：

1. `ResolveSettlementOverlayLayout` 走 `pcall` 捕获异常 → 返回 `nil, error` → `出口 success=false`；
2. `BuildSettlementOverlays` 判定「等待有效几何」→ 返回 false，**36 个背景格从未被 `LayoutSettlementGridCells` 重排到滚动内容画布**；
3. 格子仍由 `WarehouseGrid`(WrapBox) 按 `WrapWidth = GridWidth = 118*6 + 4*5 = 728` 流式排布，每格实占 `118 + InnerSlotPadding 4 = 122`，6 格需 732 > 728 → **折行，视觉上不是 6 列**；
4. 覆盖层 / 揭晓动画控件（依赖 `layout.ParentCanvas`）全部未创建；
5. `Tick` 每帧重试 122 次，均失败。

## 四、根因 2：控件契约列了两个蓝图里根本不存在的控件

MCP 回读（`ue_read schema:/IslandAuctionKing/Asset/Blueprint/Prefabs/UI/AuctionSettlementUI.AuctionSettlementUI_C`）：蓝图变量 34 个；
`ue_py` 读 `bp.WidgetTree.AllWidgets`：控件树共 **123** 个控件。二者均**不含**：

- `AssetTitleText`
- `LabelExpImage`
- `EstimatedCaptionText` / `SellCaptionText` / `SellValueText`（非契约项，代码已有 `ResolveCellNamedWidget` 与 nil 兜底）

`Script/Blueprint/Prefabs/UI/AuctionSettlementUI.lua:56` 仍留着 `---@field LabelExpImage UImage` 注解 → 说明控件曾在蓝图里被删，但 `REQUIRED_WIDGET_NAMES` 没同步。

后果：`ValidateWidgetContract` 恒失败 → `Initialize` 提前 return → **`BindEvents` 不执行、`ActiveWidget` 不写入**（`StartShowcase` 里已有 1400–1404 行的藏品行补加载兜底，所以藏品图仍在，但按钮交互链路缺失）。

## 五、修改（改动最小，只动 1 个文件）

文件：`Script\Function\AuctionSettlementUIService.lua`

1. **前向声明 + 赋值**（不搬移函数体，diff 最小）：
   - L752 新增 `local ApplySettlementScrollGeometry -- 前向声明…`
   - L875 由 `local function ApplySettlementScrollGeometry(...)` 改为 `ApplySettlementScrollGeometry = function(...)`
   - 注：此处**不能**保留 `local function`，否则会新建同名 local，使上方声明仍为 nil。
2. **契约清单剔除不存在项**：`REQUIRED_WIDGET_NAMES` 移除 `AssetTitleText`、`LabelExpImage`（31 → 29 项），并加注释说明事实源为蓝图控件树。
   - `PopulateSettlementData` 对 `AssetTitleText` 的使用本就有 `if widget.AssetTitleText ~= nil then` 保护，不受影响。
