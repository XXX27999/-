## 1. 根因（日志实证）

调用链：`LockBid → ResolveBidRound → SettleWinner → BeginReveal → PublishPublicState / SendAllPrivateStates`。

揭晓阶段两条 RPC 同时踩 `net.MaxRepArraySize = 4096`：

| RPC | 载荷 | 实测元素数 | 结果 |
| --- | --- | --- | --- |
| `ClientAuctionPublicState` | `publicState.Warehouse` 28 件 × 13 字段 | **6656**（53297 字节） | 超限 |
| `ClientAuctionPrivateState` | `Collectibles` 28 件（含 Cells/Shape/Texture/Rotation） | **4290** | 超限 |

超限后 DS 侧：`SerializeProperties_DynamicArray_r: ArraySize > net.MaxRepArraySize(4096)` → `Failed to serialize properties` → `LogLuaNetwork: Error: ---LuaNetwork: FlushError` → `OnLogLuaStack: Assertion failed:false` → DS 停止响应 → 客户端断线。**`Saved\Crashes` 无 09-22 新目录，确认是 DS 停摆不是客户端崩溃。**

对照：LockBid 那次公共状态（StateVersion=7）仅约 844 字节，未踩线，故只有揭晓瞬间断。

## 2. 改动清单（5 个文件，均在 `Script\`）

| 文件 | 改动 |
| --- | --- |
| `Function\AuctionWarehouseService.lua` | `BuildRevealedPublicWarehouse` 的揭晓藏品由 **13 字段裁到 6 字段**：`Index / ID / Name / Quality / Valuation / Cells`；删 `Type / SlotCount / IncomePerHour / Shape / ArtStatus / Rotation / Texture`（端侧由本地表按 ID 补全） |
| `Function\AuctionGameService.lua` | 新增模块级 `GetWarehouseChunkSize()`（读 `Network.WarehouseChunkSize`，默认 8）、`GetMaxRepSafeElements()`（读 `Network.MaxRepSafeElements`，默认 3000）、`EstimateContentElements()`；`PublishPublicState` 在 `#items > chunkSize` 时主包只带元信息（含 `ChunkTotal`/`ChunkStateVersion`）并在发送前后做体积自检；新增 `AuctionGameService:SendWarehouseChunks(reason, chunkTotal)` 逐片发 `ClientAuctionWarehouseChunk`；`BeginReveal` 结算 RPC 加守卫（超分片阈值时 `warehouseItems = {}`，改由分片合并结果提供）；`SendPrivateState` 加体积自检 |
| `Function\AuctionPlayerService.lua` | 新增 `BuildCompactOwnedCollectibles(player)`，私有状态 `Collectibles` 由整件深拷贝改为 **只带 `ID` + `Name`**（端侧图鉴 `CollectibleCodexUIService.BuildOwnedSet` 只消费这两个字段） |
| `Blueprint\CF_FWDRPC.lua` | 新增 `CF_FWDRPC.ClientAuctionWarehouseChunk(playerController, chunk)`（含 HasAuthority 校验、入参校验、GameState 兜底解析、调合并）；注册进 `AllowedHandlers` 白名单；`ClientAuctionSettlementUI` 增加兜底：`#safeItems == 0` 时回读 `gameState.AuctionPublicState.Warehouse.Items` |
| `Function\AuctionClientPhaseUIService.lua` | 新增 `MergeWarehouseChunk(gameState, chunk)`（按 `StateVersion` 累积、Index 去重、收齐后调 `RefreshWarehouse` + `RefreshEstimatedValue`）与 `ReplayWarehouseChunks(gameState)`（分片早于主包到达时缓存回放）；`ApplyPublicState` 写入公共状态后即回放 |

顺序保证：可靠 RPC 按发送顺序到达，`BeginReveal` 先 `PublishPublicState`（内含分片）、后发结算 RPC，故结算打开时分片已合并完成。
