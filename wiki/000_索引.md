## 使用约定

1. 回答问题先查本目录和目标领域目录，再读取命中的 Raw 正文；官方 API 是否存在、参数、端侧限制以 `raw/docs/api` 为准。
2. `wiki/概念/` 与 `wiki/来源/` 只做导航，不承载完整结论、代码、详细步骤或日志；未确认内容在 Raw 正文单独标注为「待查证」。
3. 通用正文写入 `raw/知识/通用/`；项目数值、资产路径、DataTable 行值和日志证据写入 `raw/<项目名>/`；调试备份写入 `备份/<项目名>/`，不得放回 UGC 工程。
4. 新资料进入前先分流：通用 → `raw/知识/通用/` 并建立 Wiki 短索引；项目专属 → `raw/<项目名>/`。混合内容必须拆分。
5. 检索按 L0 → L1 → 条件扩展 L2/L3 执行：先读索引和领域目录，再读主 Raw 正文；只有直接依赖、官方核验、冲突或待查证项才扩大范围。详细规则见 [准确性与关联性读取写回规范](./概念/知识库准确性与关联性读取写回.md)。

## 知识库回写机制

每次回答后必须自检并回写，检查清单见 [AGENTS.md](../AGENTS.md)。

| 情形 | 动作 |
| --- | --- |
| 结论已完整存在于概念页 | 无需回写，在回复中说明 |
| 已有概念页需补充或订正 | 在对应小节追加或订正，并更新页首「来源」行 |
| 出现新通用主题 | 在 `raw/知识/通用/<领域>/` 建正文，在 `wiki/概念/` 建短索引，登记进本索引，并与至少一个已有页互加链接 |
| 出现项目专属数据 | 写 `raw/<项目名>/<子目录>/`，登记进该项目 `000_项目索引.md`；**不进本索引** |
| 出现新项目 | 建 `raw/<项目名>/` 与其 `000_项目索引.md`，在 [项目资料总览](./项目/000_项目资料总览.md) 加一行 |
| 引入新原始资料或成批新结论 | 在 `raw/知识/通用/来源记录/` 建 `YYYY-MM-DD_<主题>.md` 来源页；需要导航时在 `wiki/来源/` 建短索引 |

Raw 正文固定结构：标题 → 来源与官方依据 → 证据状态与适用范围 → 核心结论 → 可执行步骤或代码 → 常见错误 → 相关页面 → 待查证。Wiki 概念页只保留导航摘要。

`raw/docs/` 是只读原始资料，禁止改动；回写写入 `raw/知识/通用/`、`raw/<项目名>/`、必要的 Wiki 短索引与仓库根说明文件。
