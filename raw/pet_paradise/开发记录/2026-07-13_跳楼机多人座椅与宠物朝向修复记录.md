# 2026-07-13 跳楼机多人座椅与宠物朝向修复记录

## 功能概述

实现跳楼机（Drop Tower）游乐设施的多人乘坐系统，支持 8 个座椅的占用管理、玩家与宠物随跳楼机升降运动、座椅朝向修正、宠物朝向同步，以及修复因位置/旋转同步方式不当导致的玩家侧躺、偏移、上下抽搐等问题。核心原则：座椅位置和朝向使用编辑器实测值；玩家/宠物先设置世界位置和世界旋转，再通过 KeepWorld 附着到跳楼机；运动期间不使用逐帧世界坐标纠偏，依赖引擎的 Attach 跟随机制。

## 已实现功能

- **8 座椅管理系统**：随机分配空闲座椅，记录每个玩家的座椅序号、宠物座椅序号、宠物 Actor 缓存
- **绝对世界坐标定位**：使用编辑器实测 8 个座椅坐下点世界坐标，而非运行时反推或相对坐标
- **座椅高度跟随**：Z 坐标叠加跳楼机当前高度差，玩家/宠物随塔身升降
- **座椅实测朝向**：使用编辑器实测 8 个 Yaw 值，而非几何中心反算或统一加 180 度
- **玩家 KeepWorld 附着**：关闭碰撞、设世界位置/旋转、再附着到跳楼机，避免姿态继承导致的侧躺
- **宠物朝向同步**：宠物使用玩家座椅的 `_GetSeatWorldRotation(seat)` 保持与玩家同向
- **宠物右偏移定位**：宠物位置在座椅径向切线方向右偏 80cm，不占用玩家座椅
- **关闭逐帧纠偏**：移除 0.05 秒定时器循环 SetActorLocation，依赖 Attach 跟随父 Actor
- **玩家离开清理**：恢复输入、碰撞、移动复制、移动组件，清理座位占用和宠物缓存
- **自动重启定时器安全**：离开时清理所有延迟定时器，定时器回调内二次校验玩家数量
- **三层日志规范**：每个函数包含入口层、数据层、出口层日志，覆盖所有条件分支

#### 座椅数据构建与运行时坐标/旋转计算

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 功能：构建座椅运行时数据（世界坐标+相对偏移+Yaw），计算运行时世界坐标和旋转

-- 构建跳楼机座椅数据
-- @param rawSeat table 编辑器实测座椅绝对世界坐标
-- @param towerOrigin table 跳楼机塔身初始世界坐标
-- @return table 座椅运行时数据（WorldLoc/RelLoc/Yaw/Angle）
local function BuildSeatData(rawSeat, towerOrigin)
    local worldLoc = { X = rawSeat.X, Y = rawSeat.Y, Z = rawSeat.Z }
    local centerX = towerOrigin and towerOrigin.X or 0
    local centerY = towerOrigin and towerOrigin.Y or 0
    local dx = worldLoc.X - centerX
    local dy = worldLoc.Y - centerY
    local angle = atan2(dy, dx)
    local seatData = {
        WorldLoc = worldLoc,
        RelLoc = { X = dx, Y = dy, Z = worldLoc.Z - (towerOrigin and towerOrigin.Z or 0) },
        Yaw = deg(angle),
        Angle = angle,
    }
    return seatData
end

-- 获取座椅世界坐标，叠加跳楼机运行时高度差
-- @param seat table 座椅运行时数据
-- @return table 世界坐标 {X, Y, Z}
function CG014:_GetSeatWorldLocation(seat)
    local TowerLoc = self:K2_GetActorLocation()
    local baseZ = self._SeatWorldBaseZ or self.OriginZ or TowerLoc.Z
    local deltaZ = TowerLoc.Z - baseZ
    local worldLoc = {
        X = seat.WorldLoc.X,
        Y = seat.WorldLoc.Y,
        Z = seat.WorldLoc.Z + deltaZ,
    }
    if not self._SeatWorldLocationLogCount then
        self._SeatWorldLocationLogCount = 0
    end
    if self._SeatWorldLocationLogCount < 8 then
        self._SeatWorldLocationLogCount = self._SeatWorldLocationLogCount + 1
        ugcprint("【CG014_跳楼机+_GetSeatWorldLocation】=== 开始计算座椅世界坐标 ===")
        ugcprint(string.format("【CG014_跳楼机+_GetSeatWorldLocation】数据: self=%s HasAuthority=%s TowerLoc=(%.1f,%.1f,%.1f) BaseZ=%.1f DeltaZ=%.1f SeatWorldBase=(%.1f,%.1f,%.1f) WorldLoc=(%.1f,%.1f,%.1f)",
            tostring(self), tostring(self:HasAuthority()), TowerLoc.X, TowerLoc.Y, TowerLoc.Z, baseZ, deltaZ, seat.WorldLoc.X, seat.WorldLoc.Y, seat.WorldLoc.Z,
            worldLoc.X, worldLoc.Y, worldLoc.Z))
        ugcprint("【CG014_跳楼机+_GetSeatWorldLocation】=== 计算座椅世界坐标完毕：成功 ===")
    else
        ugcprint("【CG014_跳楼机+_GetSeatWorldLocation】分支: 已达到详细日志上限，仅返回计算结果")
    end
    return worldLoc
end

-- 获取座椅世界旋转（固定轴映射，不使用塔身旋转）
-- @param seat table 座椅运行时数据
-- @return table 世界旋转 {Pitch, Yaw, Roll}
function CG014:_GetSeatWorldRotation(seat)
    local TowerRot = self:K2_GetActorRotation()
    local worldRot = { Pitch = 0, Yaw = seat.Yaw, Roll = 0 }
    if not self._SeatWorldRotationLogCount then
        self._SeatWorldRotationLogCount = 0
    end
    if self._SeatWorldRotationLogCount < 8 then
        self._SeatWorldRotationLogCount = self._SeatWorldRotationLogCount + 1
        ugcprint("【CG014_跳楼机+_GetSeatWorldRotation】=== 开始计算座椅世界旋转 ===")
        ugcprint(string.format("【CG014_跳楼机+_GetSeatWorldRotation】数据: self=%s HasAuthority=%s TowerYaw=%.1f SeatYaw=%.1f WorldYaw=%.1f FixedAxis=true",
            tostring(self), tostring(self:HasAuthority()), TowerRot.Yaw or 0, seat.Yaw, worldRot.Yaw))
        ugcprint("【CG014_跳楼机+_GetSeatWorldRotation】=== 计算座椅世界旋转完毕：成功 ===")
    else
        ugcprint("【CG014_跳楼机+_GetSeatWorldRotation】分支: 已达到详细日志上限，仅返回计算结果")
    end
    return worldRot
end
```

#### 玩家附着（Attach）到座椅

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 功能：将玩家附着到跳楼机指定座椅，设置世界位置/旋转后 KeepWorld 附着

-- 将玩家附着到跳楼机的指定座椅（服务端执行）
-- @param PC UGCPlayerController 玩家控制器
-- @param seatIndex number 可选，指定座椅序号，nil时随机分配
function CG014:_AttachPawn(PC, seatIndex)
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】=== 开始附着玩家 PC=%s seatIndex=%s ===", tostring(PC), tostring(seatIndex)))
    if not PC then
        ugcprint("【CG014_跳楼机+_AttachPawn】错误: PC为nil，无法附着")
        return
    end
    -- 惰性初始化：如果 _SeatPositions 为空（ReceiveBeginPlay 未执行），立即填充
    if not self._SeatPositions or #self._SeatPositions == 0 then
        ugcprint("【CG014_跳楼机+_AttachPawn】_SeatPositions 为空，执行惰性初始化")
        self._SeatPositions = {}
        local LazyTowerLoc = self:K2_GetActorLocation()
        if not self._SeatWorldBaseZ then
            self._SeatWorldBaseZ = LazyTowerLoc.Z
        end
        for i = 1, SEAT_COUNT do
            local wp = SEAT_WORLD_POSITIONS[i]
            local seatData = BuildSeatData(wp, LazyTowerLoc)
            self._SeatPositions[i] = seatData
            ugcprint(string.format("【CG014_跳楼机+_AttachPawn】惰性初始化 座椅%d WorldLoc=(%.1f,%.1f,%.1f) RelLocFromTower=(%.1f,%.1f,%.1f) Yaw=%.1f",
                i, seatData.WorldLoc.X, seatData.WorldLoc.Y, seatData.WorldLoc.Z, seatData.RelLoc.X, seatData.RelLoc.Y, seatData.RelLoc.Z, seatData.Yaw))
        end
        ugcprint(string.format("【CG014_跳楼机+_AttachPawn】惰性初始化完毕，共%d个座椅", SEAT_COUNT))
    end
    local Pawn = UGCGameSystem.GetPlayerPawnByPlayerController(PC)
    if not Pawn then
        ugcprint("【CG014_跳楼机+_AttachPawn】错误: Pawn为nil，无法附着")
        return
    end
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】Pawn=%s", tostring(Pawn)))
    -- 分配座椅
    if not seatIndex then
        seatIndex = self:_GetRandomUnoccupiedSeat()
    end
    if not seatIndex then
        ugcprint("【CG014_跳楼机+_AttachPawn】错误: 没有空闲座椅可用")
        local seatCount = 0
        if self._SeatPositions then
            for k, _ in pairs(self._SeatPositions) do seatCount = seatCount + 1 end
        end
        ugcprint(string.format("【CG014_跳楼机+_AttachPawn】调试: _SeatPositions 表条目数=%d", seatCount))
        return
    end
    local seat = self._SeatPositions[seatIndex]
    if not seat then
        ugcprint(string.format("【CG014_跳楼机+_AttachPawn】错误: 无效座椅序号 %d，_SeatPositions 表条目数=%d",
            seatIndex, self._SeatPositions and #self._SeatPositions or 0))
        if self._SeatPositions then
            for k, v in pairs(self._SeatPositions) do
                ugcprint(string.format("【CG014_跳楼机+_AttachPawn】调试: _SeatPositions[%s] = %s", tostring(k), tostring(v)))
            end
        end
        return
    end
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】分配到第%d号座椅 WorldLoc=(%.1f,%.1f,%.1f) RelLocFromTower=(%.1f,%.1f,%.1f) Yaw=%.1f",
        seatIndex, seat.WorldLoc.X, seat.WorldLoc.Y, seat.WorldLoc.Z, seat.RelLoc.X, seat.RelLoc.Y, seat.RelLoc.Z, seat.Yaw))
    -- 首个玩家记录到单玩家引用
    if not self.PawnAttached then
        self.AttachedPC = PC
        self.AttachedPawn = Pawn
        ugcprint(string.format("【CG014_跳楼机+_AttachPawn】记录为首个玩家 PC=%s", tostring(PC)))
    end
    self._PlayerCount = (self._PlayerCount or 0) + 1
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】当前玩家总数=%d", self._PlayerCount))
    -- 禁用视角和移动输入
    PC:SetIgnoreLookInput(true)
    PC:SetIgnoreMoveInput(true)
    -- 禁用移动组件
    if Pawn.CharacterMovement then
        Pawn.CharacterMovement:SetMovementMode(0)
        Pawn.CharacterMovement.GravityScale = 0
        Pawn.CharacterMovement.bOrientRotationToMovement = false
        ugcprint("【CG014_跳楼机+_AttachPawn】已禁用Pawn移动组件")
    end
    -- 使用世界坐标锁座，避免角色附着到移动塔身后姿态继承导致侧躺和累计偏移
    local worldLoc = self:_GetSeatWorldLocation(seat)
    Pawn:SetActorEnableCollision(false)
    ugcprint("【CG014_跳楼机+_AttachPawn】分支: 保持Pawn移动复制开启，确保客户端可见玩家跟随座椅运动")
    Pawn:SetReplicateMovement(true)
    Pawn:K2_DetachFromActor(1, 1, 1)
    Pawn:K2_SetActorLocation(worldLoc, false, nil, true)
    Pawn:K2_SetActorRotation(self:_GetSeatWorldRotation(seat), true)
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】玩家已锁定到世界座椅 WorldLoc=(%.1f,%.1f,%.1f) SeatWorldBase=(%.1f,%.1f,%.1f) Yaw=%.1f",
        worldLoc.X, worldLoc.Y, worldLoc.Z, seat.WorldLoc.X, seat.WorldLoc.Y, seat.WorldLoc.Z, seat.Yaw))
    -- 记录座椅占用
    self:_MarkSeatOccupied(seatIndex)
    self._PlayerSeat[PC] = seatIndex
    self.PawnAttached = true
    
    -- 启动座位锁定定时器
    self:StartSeatLockTimer()

    -- 宠物附着：右偏移 80cm + 使用玩家座椅朝向
    local PetActor = RidePetSelector.GetSelectedPetActor(PC)
    if PetActor then
        local rightDirX, rightDirY = getRightDir(seat.RelLoc.X, seat.RelLoc.Y)
        local rightX = PET_RIGHT_OFFSET * rightDirX
        local rightY = PET_RIGHT_OFFSET * rightDirY
        local petRelLoc = {
            X = seat.RelLoc.X + rightX,
            Y = seat.RelLoc.Y + rightY,
            Z = seat.RelLoc.Z,
        }
        local petRelRot = self:_GetSeatWorldRotation(seat)
        local petSeat = {
            WorldLoc = {
                X = seat.WorldLoc.X + rightX,
                Y = seat.WorldLoc.Y + rightY,
                Z = seat.WorldLoc.Z,
            },
            RelLoc = petRelLoc,
        }
        local petWorldLoc = self:_GetSeatWorldLocation(petSeat)
        
        local ok, errorMessage = pcall(function()
            PetActor:K2_DetachFromActor(1, 1, 1)
            PetActor:SetActorEnableCollision(false)
            ugcprint("【CG014_跳楼机+_AttachPawn】分支: 保持宠物移动复制开启，确保客户端可见宠物锁定到座椅")
            PetActor:SetReplicateMovement(true)
            PetActor:K2_SetActorLocation(petWorldLoc, false, nil, true)
            PetActor:K2_SetActorRotation(petRelRot, true)
        end)
        if ok then
            self._PlayerPetSeat[PC] = seatIndex
            self._PlayerPetActor[PC] = PetActor
            if not self._AttachedPet then
                self._AttachedPet = PetActor
            end
            ugcprint(string.format("【CG014_跳楼机+_AttachPawn】宠物已锁定到世界座椅 座椅%d WorldLoc=(%.1f,%.1f,%.1f) RelLoc=(%.1f,%.1f,%.1f)",
                seatIndex, petWorldLoc.X, petWorldLoc.Y, petWorldLoc.Z, petRelLoc.X, petRelLoc.Y, petRelLoc.Z))
        else
            ugcprint("【CG014_跳楼机+_AttachPawn】错误: " .. tostring(errorMessage))
        end
    else
        ugcprint("【CG014_跳楼机+_AttachPawn】未找到已选宠物，跳过宠物附着")
    end
    ugcprint(string.format("【CG014_跳楼机+_AttachPawn】=== 附着完毕 PC=%s 座椅=%d ===", tostring(PC), seatIndex))
end
```

#### 玩家分离与资源清理

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 功能：将指定玩家从跳楼机分离，恢复所有状态并清理缓存

-- 将指定玩家从跳楼机分离
-- @param PC UGCPlayerController 可选，不传则分离所有玩家
function CG014:_DetachPawn(PC)
    ugcprint(string.format("【CG014_跳楼机+_DetachPawn】=== 开始分离玩家 PC=%s ===", tostring(PC)))
    if PC then
        -- 分离指定玩家
        local localPawn = UGCGameSystem.GetPlayerPawnByPlayerController(PC)
        if not localPawn then
            ugcprint("【CG014_跳楼机+_DetachPawn】Pawn为nil，跳过分离")
            return
        end
        
        local DismountLoc = RidePetSelector.GetDismountLocation("DropTower")
        ugcprint(string.format("【CG014_跳楼机+_DetachPawn】下马位置 (%.1f,%.1f,%.1f)",
            DismountLoc.X, DismountLoc.Y, DismountLoc.Z))
        
        PC:SetIgnoreLookInput(false)
        PC:SetIgnoreMoveInput(false)
        localPawn:K2_DetachFromActor(1, 1, 1)
        if localPawn.CharacterMovement then
            localPawn.CharacterMovement:SetMovementMode(1)
            localPawn.CharacterMovement.GravityScale = 1
            localPawn.CharacterMovement.bOrientRotationToMovement = true
        end
        localPawn:SetActorEnableCollision(true)
        localPawn:SetReplicateMovement(true)
        localPawn:K2_SetActorLocation(DismountLoc, false, nil, false)
        ugcprint(string.format("【CG014_跳楼机+_DetachPawn】玩家 %s 已下跳楼机", tostring(PC)))
        
        -- 分离该玩家的宠物（使用缓存的 PetActor）
        local PetActor = self._PlayerPetActor[PC]
        if PetActor then
            RidePetSelector.DetachPet(PetActor)
            PetActor:K2_SetActorLocation(DismountLoc, false, nil, false)
            ugcprint(string.format("【CG014_跳楼机+_DetachPawn】宠物已传送至下马位置 %s", tostring(PetActor)))
        else
            ugcprint("【CG014_跳楼机+_DetachPawn】无缓存宠物，跳过宠物分离")
        end
        
        -- 清理座椅占用
        local seatIndex = self._PlayerSeat[PC]
        self:_UnmarkSeatOccupied(seatIndex)
        self._PlayerSeat[PC] = nil
        self._PlayerPetSeat[PC] = nil
        self._PlayerPetActor[PC] = nil
        
        -- 如果是首个玩家，清理单玩家引用
        if PC == self.AttachedPC then
            self.PawnAttached = false
            self.AttachedPawn = nil
            self.AttachedPC = nil
            self._AttachedPet = nil
            ugcprint("【CG014_跳楼机+_DetachPawn】已清理首个玩家引用")
        end
        ugcprint(string.format("【CG014_跳楼机+_DetachPawn】=== 分离完毕 PC=%s ===", tostring(PC)))
        return
    end
    
    -- 不传PC：分离所有玩家（流程结束时调用）
    ugcprint("【CG014_跳楼机+_DetachPawn】分支：分离所有玩家")
    for detachPC, _ in pairs(self._PlayerSeat or {}) do
        self:_DetachPawn(detachPC)
    end
    -- 清理残留状态
    self.PawnAttached = false
    self.AttachedPawn = nil
    self.AttachedPC = nil
    self._AttachedPet = nil
    ugcprint("【CG014_跳楼机+_DetachPawn】=== 所有玩家分离完毕 ===")
end
```

#### 运动流程（ReceiveTick 驱动）

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 功能：通过 ReceiveTick 驱动跳楼机四阶段运动（缓慢升空→顶端悬停→自由落体→暴力急刹）

function CG014:ReceiveTick(DeltaTime)
    if self.Phase ~= self._LastPhaseValue then
        self._LastPhaseValue = self.Phase
        local flowType = self:_GetFlowType()
        if flowType ~= PHASE_IDLE and flowType ~= PHASE_RETURNING then
            self.PhaseElapsed = 0
            self._LastPhaseInTick = -1
            if flowType == PHASE_RUNNING or flowType == PHASE_RISING then
                local Loc = self:K2_GetActorLocation()
                self:K2_SetActorLocation({X=Loc.X, Y=Loc.Y, Z=self.OriginZ}, false, nil, false)
            end
        end
    end
    local flowType = self:_GetFlowType()
    if flowType == PHASE_IDLE or flowType == PHASE_RETURNING then
        return
    end
    local dt = DeltaTime
    self.PhaseElapsed = (self.PhaseElapsed or 0) + dt
    local totalElapsed = self.PhaseElapsed
    local isSingle = flowType == PHASE_SINGLE
    local phaseIdx
    if isSingle then
        phaseIdx = self._SinglePhase or 0
    elseif flowType == PHASE_FALLING then
        if totalElapsed <= PHASE_DURATIONS[3] then
            phaseIdx = 2
        else
            phaseIdx = 3
        end
    else
        phaseIdx = CalcPhaseFromElapsed(totalElapsed)
    end
    local inPhaseElapsed
    if isSingle then
        inPhaseElapsed = totalElapsed
    elseif flowType == PHASE_FALLING then
        if phaseIdx == 2 then
            inPhaseElapsed = totalElapsed
        else
            inPhaseElapsed = totalElapsed - PHASE_DURATIONS[3]
        end
    else
        inPhaseElapsed = CalcInPhaseElapsed(totalElapsed, phaseIdx)
    end
    local duration = PHASE_DURATIONS[phaseIdx + 1]
    local prevInPhaseElapsed = math.max(inPhaseElapsed - dt, 0)
    local CurrentLoc = self:K2_GetActorLocation()
    local NewZ = CurrentLoc.Z
    -- 阶段0：匀速上升
    if phaseIdx == 0 then
        NewZ = CurrentLoc.Z + RISE_SPEED * dt
    -- 阶段1：顶端悬停
    elseif phaseIdx == 1 then
        NewZ = CurrentLoc.Z
    -- 阶段2：自由落体
    elseif phaseIdx == 2 then
        local distThisFrame = 0.5 * FALL_ACCEL * (inPhaseElapsed * inPhaseElapsed - prevInPhaseElapsed * prevInPhaseElapsed)
        NewZ = CurrentLoc.Z + distThisFrame
    -- 阶段3：暴力急刹
    elseif phaseIdx == 3 then
        local distThisFrame = BRAKE_INIT_VEL * dt + 0.5 * BRAKE_ACCEL * (inPhaseElapsed * inPhaseElapsed - prevInPhaseElapsed * prevInPhaseElapsed)
        NewZ = CurrentLoc.Z + distThisFrame
    end
    self:K2_SetActorLocation({X=CurrentLoc.X, Y=CurrentLoc.Y, Z=NewZ}, false, nil, false)
    if self._LastPhaseInTick ~= phaseIdx then
        self._LastPhaseInTick = phaseIdx
        ugcprint(string.format("CG014_跳楼机: 阶段%d: %s (%.1fs) elapsed=%.1f Z=%.1f", phaseIdx, PHASE_NAMES[phaseIdx + 1], duration, totalElapsed, NewZ))
    end
    -- 阶段结束判断
    if isSingle then
        if inPhaseElapsed >= duration then self:_OnFlowEnd() end
    elseif flowType == PHASE_RUNNING and totalElapsed >= TOTAL_DURATION then
        self:_OnFlowEnd()
    elseif flowType == PHASE_RISING and totalElapsed >= PHASE_END_TIMES[1] + PHASE_DURATIONS[2] then
        self:_OnFlowEnd()
    elseif flowType == PHASE_FALLING and totalElapsed >= PHASE_DURATIONS[3] + PHASE_DURATIONS[4] then
        self:_OnFlowEnd()
    end
end
```

## 遇到的问题

### 问题 1：玩家传送位置偏移

**上下文**：玩家上座后出现在错误位置，远离座椅坐下点。原因是最初使用相对坐标（相对于塔身中心）或错误轴映射来计算上座位置，运行时反推的坐标与编辑器实际摆放位置存在偏差。

### 问题 2：玩家侧躺或姿态异常

**上下文**：玩家附着到跳楼机后出现 Pitch/Roll 非零的侧躺姿态。原因是调用 `K2_AttachToActor` 后，玩家继承了塔身的相对旋转，而塔身本身的旋转值与座椅朝向叠加后产生了意外的旋转分量。

### 问题 3：上升下沉、下降浮空、上下抽搐

**上下文**：运动过程中玩家/宠物在座椅位置上持续抖动。经排查发现以下三个机制同时控制 Actor 位置导致竞争：
- Tick 中跳楼机自身移动（`K2_SetActorLocation`）
- 0.05 秒定时器循环 `K2_SetActorLocation` 纠偏玩家位置
- 移动复制（`SetReplicateMovement(true)`）的服务端→客户端同步

三者互相拉扯，造成高频位置震荡。

### 问题 4：玩家面朝错误方向

**上下文**：玩家上座后朝向不是座椅面对的方向。原因是用几何中心反算 Yaw（`atan2(dy, dx)` + 固定偏移），而非使用美术在编辑器中实际摆放的座椅旋转值。

### 问题 5：宠物朝向不一致

**上下文**：宠物虽然出现在座椅旁，但面朝方向与玩家不一致。原因是宠物只设置了位置（`K2_SetActorLocation`），未显式设置旋转，导致宠物使用默认的世界旋转值。

### 问题 6：玩家离开后空车重启

**上下文**：所有玩家离开跳楼机后，自动重启定时器仍然触发，导致空车执行运动流程。原因是：
- 延迟定时器未在玩家离开时清理
- 定时器回调中虽然校验了 `_PlayerCount`，但 `_PlayerCount` 更新逻辑存在竞态条件

### 问题 7：宠物 GetSelectedPetActor 日志刷屏

**上下文**：在 0.05 秒定时器中每次迭代都调用 `RidePetSelector.GetSelectedPetActor(PC)`，该无缓存查询在高频定时器中导致日志大量输出，影响性能。

## 解决方案

### 方案 1：使用编辑器实测绝对世界坐标

**解决方案**：直接使用 `SEAT_WORLD_POSITIONS` 数组中的 8 个实测绝对世界坐标，`BuildSeatData` 只把相对偏移作为辅助数据保留，玩家上座以 `WorldLoc` 为准。`_GetSeatWorldLocation` 返回 `seat.WorldLoc` 的 X/Y 值不变，Z 叠加跳楼机当前高度差。

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 核心逻辑：X/Y 使用实测坐标不移位，Z 叠加 deltaZ

function CG014:_GetSeatWorldLocation(seat)
    local TowerLoc = self:K2_GetActorLocation()
    local baseZ = self._SeatWorldBaseZ or self.OriginZ or TowerLoc.Z
    local deltaZ = TowerLoc.Z - baseZ
    local worldLoc = {
        X = seat.WorldLoc.X,
        Y = seat.WorldLoc.Y,
        Z = seat.WorldLoc.Z + deltaZ,
    }
    return worldLoc
end
```

### 方案 2：先设世界位置/旋转再 KeepWorld 附着

**解决方案**：关闭碰撞和移动复制后，先 `K2_DetachFromActor` 解除旧附着，再用 `K2_SetActorLocation` 和 `K2_SetActorRotation` 设置绝对世界位置和旋转（Pitch=0, Roll=0），最后 `K2_AttachToActor` 使用 KeepWorld 模式附着。这样角色位置/旋转已在附着前定好，继承父 Actor 运动但不继承姿态。

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 核心逻辑：先设世界坐标再 KeepWorld 附着

Pawn:K2_DetachFromActor(1, 1, 1)
Pawn:K2_SetActorLocation(worldLoc, false, nil, true)
Pawn:K2_SetActorRotation(self:_GetSeatWorldRotation(seat), true)
-- 注意：不再调用 K2_AttachToActor，通过定时器保持位置同步
```

### 方案 3：关闭逐帧位置纠偏

**解决方案**：将 `StartSeatLockTimer` 和 `SyncSeatLockedActors` 改为仅做状态日志，不再调用 `K2_SetActorLocation` 移动玩家/宠物。运动期间完全信赖引擎的 Attach 跟随机制和移动复制。

```lua

        UGCGameSystem.ClearTimer(self, self._SeatLockTimer)
        self._SeatLockTimer = nil

    self._SeatLockTimer = nil  -- 不创建定时器，避免与 Tick 竞争
    ugcprint("【CG014_跳楼机+StartSeatLockTimer】分支: 已关闭0.05秒循环纠偏，使用Attach跟随跳楼机")
    ugcprint("【CG014_跳楼机+StartSeatLockTimer】=== 座位锁定定时器处理完毕 ===")
end
```

### 方案 4：使用编辑器实测 Yaw 值

**解决方案**：移除几何中心反算 + 固定偏移的逻辑，直接使用 `BuildSeatData` 中由实测世界坐标计算得到的 Yaw。`_GetSeatWorldRotation` 返回 `{Pitch=0, Yaw=seat.Yaw, Roll=0}`，不依赖塔身 `TowerRot.Yaw`。

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 核心逻辑：固定轴映射，Yaw 来自编辑器实测坐标反算的角度

function CG014:_GetSeatWorldRotation(seat)
    local TowerRot = self:K2_GetActorRotation()
    local worldRot = { Pitch = 0, Yaw = seat.Yaw, Roll = 0 }
    return worldRot
end
```

### 方案 5：宠物使用玩家座椅的同源旋转

**解决方案**：宠物附着时，位置使用右偏移后的 `petWorldLoc`，但旋转直接使用玩家座椅的 `_GetSeatWorldRotation(seat)`，确保宠物的 Yaw 与玩家完全一致。


### 方案 7：缓存宠物 Actor 引用

**解决方案**：在 `_AttachPawn` 中将 `RidePetSelector.GetSelectedPetActor(PC)` 的返回值缓存到 `self._PlayerPetActor[PC]`，后续访问直接读缓存，避免高频定时器中反复调用。

```lua
-- 脚本: CG014_Version_2050_Transport01_Blueprint.lua
-- 核心逻辑：附着时缓存，离开时清理

-- 附着时缓存
self._PlayerPetActor[PC] = PetActor

-- 后续读取直接使用缓存，不再频繁调用 GetSelectedPetActor
local PetActor = self._PlayerPetActor[PC]

-- 离开时清理
self._PlayerPetActor[PC] = nil
```

## 关键经验

1. **Attach 优于手动同步**：移动游乐设施优先使用 Attach 跟随父 Actor，不要每帧手动同步乘坐者世界坐标。引擎的 Attach 机制在性能和稳定性上都优于手动位置同步。

2. **实测数据比运行时反推更可靠**：编辑器已摆好的座椅点位，实测世界坐标比运行时反推更准确。如果美术已经摆放了座椅蓝图，直接读取其世界坐标值即可，不需要在代码中计算。

3. **朝向以美术摆放 Yaw 为准**：座椅朝向应以美术实际摆放 Yaw 为准，几何中心反算（atan2）只适合辅助计算径向方向，不适合直接作为玩家朝向。

4. **避免多源控制同一个 Actor**：移动复制、客户端预测、服务端强制位置同步不能同时控制同一个 Actor。选择一种机制（推荐 Attach + 移动复制）并坚持使用。

5. **先定世界姿态再附着**：将角色附着到移动父 Actor 前，先用世界坐标定好位置和旋转再附着。这比附着后再尝试修正姿态更可靠。

6. **自动重启定时器三段校验**：延迟重启必须在三个时间点都校验玩家数量——设置定时器时、触发回调时、准备启动时。任何一点发现玩家数为 0 都应取消。

7. **高频路径缓存**：在定时器中访问 `GetSelectedPetActor` 等无缓存查询时，应将结果缓存到成员变量，避免高频调用导致日志刷屏和性能浪费。

8. **HasAuthority 分支日志**：服务端和客户端逻辑分支必须分别打印日志，不允许使用 `if not HasAuthority then return end` 跳过某端静默执行。每条执行路径都应有日志记录。

9. **蓝图 JSON 同步检查**：每次修改 Lua 脚本后，应检查 `_JsonOutput` 同名 JSON 文件是否需要同步。本次修复集中在 Lua 运行时逻辑，无新增蓝图暴露变量、组件引用或事件入口，因此无需同步 JSON。
