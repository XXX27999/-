# FInlineEditableTextBlockStyle

Represents the appearance of an SInlineEditableTextBlock

## Fields

| Name | Type | Description |
| --- | --- | --- |
| EditableTextBoxStyle | [FEditableTextBoxStyle](../FE/FEditableTextBoxStyle.md) | The style of the editable text box, which dictates the font, color, and shadow options. |
| TextStyle | [FTextBlockStyle](../FT/FTextBlockStyle.md) | The style of the text block, which dictates the font, color, and shadow options. Style overrides all other properties! |
