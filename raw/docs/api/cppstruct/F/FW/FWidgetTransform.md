# FWidgetTransform

Describes the standard transformation of a widget

## Fields

| Name | Type | Description |
| --- | --- | --- |
| Translation | [FVector2D](../FV/FVector2D.md) | The amount to translate the widget in slate units |
| Scale | [FVector2D](../FV/FVector2D.md) | The scale to apply to the widget |
| Shear | [FVector2D](../FV/FVector2D.md) | The amount to shear the widget in slate units |
| Angle | `float` | The angle in degrees to rotate |
