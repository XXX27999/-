# FFontRenderInfo

information used in font rendering

## Fields

| Name | Type | Description |
| --- | --- | --- |
| bClipText | `uint32` | whether to clip text |
| bEnableShadow | `uint32` | whether to turn on shadowing |
| GlowInfo | [FDepthFieldGlowInfo](../FD/FDepthFieldGlowInfo.md) | depth field glow parameters (only usable if font was imported with a depth field) |
