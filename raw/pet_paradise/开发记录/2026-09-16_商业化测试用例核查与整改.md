### 1. 在线/离线完美打工金币倍率口径统一（`Pet.lua` L3062-3078）

**核查结论（修正原判断）**：两侧**等效数值原本就已一致**，差异只在表达形式。

- 离线 `WorkIncomeCalculator.lua` L163-177 用「倍率」写：`perfectGoldMul` = 1.5 / max 2.5（季卡）/ max 3.0（顶级+至尊）/ max 2.0（体型5），再 `perfectGoldBonus = baseGold * (perfectGoldMul - 1)`。
- 在线旧写法用「加成量」写：0.5 / max 1.5 / max 2.0 / max 1.0，直接 `otherGoldRate + perfectGoldMul`。

两者折算后都是 **+0.5 / +1.5 / +2.0 / +1.0**。故本次统一的是**口径与常量**，不涉及数值变更：

```lua
local perfectGoldMul = 1.5                                                     -- 原 0.5
if seasonalCard ~= 0 then perfectGoldMul = math.max(perfectGoldMul, 2.5) end    -- 原 1.5
if topGiftBag == 1 and isSupremeArea then perfectGoldMul = math.max(perfectGoldMul, 3.0) end -- 原 2.0
if size == 5 then perfectGoldMul = math.max(perfectGoldMul, 2.0) end            -- 原 1.0
otherGoldRate = otherGoldRate + (perfectGoldMul - 1)                           -- 原 + perfectGoldMul
```
