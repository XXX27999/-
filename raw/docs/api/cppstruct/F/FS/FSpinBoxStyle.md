# FSpinBoxStyle

Represents the appearance of an SSpinBox

## Fields

| Name | Type | Description |
| --- | --- | --- |
| BackgroundBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the background of the spinbox |
| HoveredBackgroundBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to draw the background of the spinbox when it's hovered over |
| ActiveFillBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to fill the spinbox when it's active |
| InactiveFillBrush | [FSlateBrush](./FSlateBrush.md) | Brush used to fill the spinbox when it's inactive |
| ArrowsImage | [FSlateBrush](./FSlateBrush.md) | Image used to draw the spinbox arrows |
| ForegroundColor | [FSlateColor](./FSlateColor.md) | Color used to draw the spinbox foreground elements |
| TextPadding | [FMargin](../FM/FMargin.md) | Padding to add around the spinbox and its text |
