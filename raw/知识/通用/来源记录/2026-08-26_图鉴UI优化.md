### 口径核对结论（本轮订正）

`Script/Function/CollectibleCodexUIService.lua` 第 48-78 行的 `FILTER_BUTTONS` 中，Type 与 Shape 分组各含一个「全部」按钮（`Value = ""`）。剔除「全部」后：

- Type 实际筛选值 6 个（古董/科技/宝石/异象/食品/日用），与表内 6 类**完全一致**
- Shape 实际筛选值 11 个（1×1、1×2、2×1、1×3、3×1、2×2、1×4、2×3、3×2、3×3、3×4），与表内 11 种**完全一致**，不存在 `2×4`

结论：**Lua 筛选定义与表数据无缺口**。此前「Lua 7 类型 / 12 形状 vs 表内 6 类型 / 11 形状」的差异，是把「全部」按钮误计入了筛选值。

## 五、可执行代码：DataTable 只读导出模板（已实测）

```python
import unreal_engine as ue, json
from unreal_engine.classes import DataTable

t = ue.load_object(DataTable, "/IslandAuctionKing/Asset/Data/Table/Customized/CollectibleTable")
rows = t.data_table_get_all_rows()          # 返回 UScriptStruct 列表，不是行名列表
IMG = 'Imger_3_0044C0DC499330E8E35A17939926C2AC'
out = []
for r in rows:
    d = r.as_dict()                          # r.fields() 可取字段名
    tex = d.get(IMG)
    out.append({
        'name': d.get('Name'),
        'tex': tex.get_path_name() if tex else '',
    })
__askq_result = json.dumps(out, ensure_ascii=False)
```

**陷阱**：
1. `data_table_find_row()` 只接受 `str` 行名，传其他类型直接抛异常。
2. `data_table_get_all_rows_name()` **不存在**，不要调用。
3. `data_table_get_all_rows()` 返回的是行结构体实例，行名需另行获取或按顺序对齐。

## 六、可执行流程：本地 HTTP 预览 + in-app browser 验证

绿洲项目的 UI 预览必须给用户可运行网页，且需自己截图核对。本轮实测出的可复现流程：

### 6.1 常驻服务（必须写成独立脚本文件）

```powershell
node "<项目>/Preview/_preview_server.js" "<项目>/Preview"
# exec_command 配 yield_time_ms 让其进入 running，输出 "ready"
# 监听 127.0.0.1:7391，Cache-Control: no-store，默认页 CollectibleCodexOptimizedPreview.html
```

### 6.2 浏览器接管与截图

```js
const { setupBrowserRuntime } = await import("<CODEX_HOME>/plugins/cache/openai-bundled/browser/<ver>/scripts/browser-client.mjs");
globalThis.agent = await setupBrowserRuntime();
globalThis.iab = await agent.browsers.get("iab");
globalThis.tab = await iab.tabs.new({ url: 'http://127.0.0.1:7391/CollectibleCodexOptimizedPreview.html' });
await tab.goto(url, { waitUntil: 'load', timeoutMs: 30000 });
await nodeRepl.emitImage(await tab.screenshot());   // screenshot({clip:{x,y,width,height}}) 可局部
```

### 6.3 本轮踩到的 6 个坑

| 现象 | 原因 | 正确做法 |
| --- | --- | --- |
| `ERR_CONNECTION_REFUSED`，服务莫名消失 | node REPL 的 `globalThis.__srv` / `globalThis.CTX` 会随 cell 间 session 重置而丢失 | 服务写成独立 `.js` 文件，用 `exec_command` 后台常驻 |
| `Start-Process` 被拒绝（`blocked by policy`） | exec_command 策略限制 | 直接前台 `node ...` + `yield_time_ms` |
| `file://` 打不开 | in-app browser 策略拦截本地文件协议 | 必须走 HTTP；用户自己的浏览器可直开 `file://` |
| 想执行页面内 JS 取 DOM 断言 | `tab` 仅有 `goto/back/forward/reload/close/screenshot/title/url/getJsDialog/markHandoff/markDeliverable/requestManualHandoff/nameSession`，**无 `evaluate`/`content`**；`iab` 仅 `documentation/nameSession` | 只能靠截图目视核对；断言逻辑前置到生成数据的 node 侧 |
| `Identifier 'x' has already been declared` | node REPL 变量在同 session 内不可重复 `const` 声明 | 用 IIFE 包裹或前缀化变量名，或 `js_reset` |
| `require is not defined` | node REPL 无 CommonJS `require` | `await import('node:fs')` |

### 6.4 素材落位自检（必做）

上一轮曾出现「声称 70 张 PNG 已复制，实际目录只有 1 个 `undefined.png`」的假成功——根因是 `codex_preview_data.js` 缺 `tex` 字段，HTML 里 `it.tex` 全为 `undefined`，浏览器把 70 个请求折叠成同一个 404。

**自检命令**：

```powershell
(Get-ChildItem "<项目>\Preview\assets\items" -Filter *.png).Count   # 期望 70
Test-Path "<项目>\Preview\assets\items\undefined.png"               # 期望 False
```

并在生成数据时同步输出 `missingPng` 数组，期望为 `[]`。
