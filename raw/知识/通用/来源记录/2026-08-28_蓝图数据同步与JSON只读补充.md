## 一、确认的规则

1. 蓝图和 UI 属性读取优先使用 UGCAskQ MCP。
2. MCP 未查询到时，可以查看 `_JsonOutput` JSON 补充字段和结构信息，但 JSON 不保证是编辑器蓝图的最新内容。
3. 查看 JSON 前，在项目根目录执行 `powershell -ExecutionPolicy Bypass -File ".\ConvertUAssetToJson.ps1"` 进行编辑器 `.uasset` 到 JSON 的同步；该脚本会交互选择 `1` 增量全量转换或 `2` 自动监视模式。
4. `_JsonOutput` JSON 只能只读核查、字段补充和差异定位，不能直接修改 JSON、用 JSON 覆盖 `.uasset`，也不能据此声称已修改编辑器蓝图。
5. 蓝图结构、组件、UI 属性、事件入口和资源引用的修改必须通过 UGCAskQ MCP 的 `Resolve → Plan → Execute`，写后立即 MCP 回读验证。
6. MCP 和同步后的 JSON 都无法确认目标属性时必须停止写入，明确记录“未查询到/未验证”。
