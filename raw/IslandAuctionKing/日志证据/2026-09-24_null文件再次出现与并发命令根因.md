## 一、问题现象

用户复问「为什么项目中还是会出现 `$null` 这个文件阻碍 PIE 调试」。复核时工程根 `$null` 已被并发会话删除，但上传副本仍存在：

| 路径 | 大小 | 创建时间 | 状态 |
| --- | ---: | --- | --- |
| `D:\WeGameApps\rail_apps\OasisEraEditor(2001776)\ShadowTrackerExtra\UGCProjects\IslandAuctionKing\$null` | 0 B | 2026-09-24 14:26:17 | 已被并发会话删除 |
| `D:\WeGameApps\rail_apps\OasisEraEditor(2001776)\ShadowTrackerExtra\Saved\UGCLinuxDebug\IslandAuctionKing\$null` | 0 B | 2026-09-24 14:26:49 | 本次复核删除 |

历史 PIE 报错链为 `Content=$null may contain the following characters: $`、`CheckUploadFileNameFailed Result 10001`、`lua file validation failed`；同时 luacheck `ReturnCode: 0`。这证明中断发生在文件名校验阶段，不是 Lua 语法阶段。

## 二、精确时间线

1. 14:26:09，并发 Codex 会话 `01a0d216-d64a-7db3-ac18-ed5e2f9512f4` 启动，工作目录为 UGC 工程根。
2. 该会话开头已加载含禁止 `$null` 的 `AGENTS.md` 规则；扫描其会话记录可见 `HasNullRule=True`。
3. 14:26:17，会话发出第一条违规命令，参数为 `shell:"bash"`：

```powershell
rg -n --hidden -S "匹配|补位|人机|机器人|Match|match|bot|Bot|Robot|20" Script Saved _JsonOutput 2>$null | Select-Object -First 400
```

4. 该次命令输出 `'Select-Object' is not recognized as an internal or external command`，进程码 `255`。按 Windows `cmd.exe` 的解析语义，`2>$null` 被当成真实重定向目标，工程根同秒生成 0 字节 `$null`。
5. 14:26:31，同一命令改用 `shell:"powershell"` 重试，正常返回；说明生成源是前一次 shell 解析方式，不是 PIE 或正常 PowerShell。
6. 14:26:49，PIE 将工程内容复制到 `Saved\UGCLinuxDebug\IslandAuctionKing\`，上传副本出现第二个 0 字节 `$null`。副本比源文件晚 32 秒。
7. 14:34:46，并发会话扫描到工程根 `$null`；14:35:56 通过字符拼接删除工程根文件，但未确认上传副本。
8. 本次复核删除上传副本，并对整个 `ShadowTrackerExtra` 递归扫描，`$null` 命中数为 0。

## 三、根因结论

1. **源头不是 PIE**：PIE 按上传流程复制工程，上传副本晚于工程根文件生成；修复必须回到工程根或外部命令。
2. **源头是并发 Codex 会话的错误 shell 调用**：该会话已加载禁止 `$null` 的规则，但仍发出了 5 条 `2>$null` 命令；其中第一条以 `shell:"bash"` 发出，在 Windows 包装层形成 `cmd.exe` 语义，生成真实 `$null`。
3. **规则不会自动执行**：规则写入 `AGENTS.md`、全局提示词和归档，只能约束后续被正确遵循的命令，不能阻止模型继续发出违规命令，也不能自动清理已落盘文件。
4. **清理必须覆盖两处**：只删工程根文件会让 PIE 在下一轮再次复制；必须同时检查并删除 `Saved\UGCLinuxDebug\IslandAuctionKing\` 下的副本，再复扫为 0。

## 五、后续约束

1. 在 UGC 工程目录执行命令前，确认实际 shell；不要把 PowerShell 的 `>$null` / `2>$null` 交给未确认的 `bash` 包装层。
2. 丢弃输出统一使用 `2>&1 | Out-Null`、`| Select-Object -Last N` 或 `-ErrorAction SilentlyContinue`。
3. 每次任务收尾扫描工程根与 `Saved\UGCLinuxDebug\<项目名>\`；先删源文件，再删上传副本，最后复扫为 0。
4. 若发现上传副本存在而工程根不存在，优先回溯最近并发 Codex 会话和文件创建时间，而不是修改 Lua。
