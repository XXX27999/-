# FTableRowStyle

Represents the appearance of an STableRow

## Fields

| Name | Type | Description |
| --- | --- | --- |
| SelectorFocusedBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used as a selector when a row is focused |
| ActiveHoveredBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when a selected row is active and hovered |
| ActiveBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when a selected row is active |
| InactiveHoveredBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when a selected row is inactive and hovered |
| InactiveBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when a selected row is inactive |
| EvenRowBackgroundHoveredBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when an even row is hovered |
| EvenRowBackgroundBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when an even row is in its normal state |
| OddRowBackgroundHoveredBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used when an odd row is hovered |
| OddRowBackgroundBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush to used when an odd row is in its normal state |
| TextColor | [FSlateColor](../FS/FSlateColor.md) | Text color used for all rows |
| SelectedTextColor | [FSlateColor](../FS/FSlateColor.md) | Text color used for the selected row |
| DropIndicator_Above | [FSlateBrush](../FS/FSlateBrush.md) | Brush used to provide feedback that a user can drop above the hovered row. |
| DropIndicator_Onto | [FSlateBrush](../FS/FSlateBrush.md) | Brush used to provide feedback that a user can drop onto the hovered row. |
| DropIndicator_Below | [FSlateBrush](../FS/FSlateBrush.md) | Brush used to provide feedback that a user can drop below the hovered row. |
