## 一、现象

结算界面右侧 6x6 仓库格上出现不属于仓库格的内容：橙色名称框条（`NameFrameImage`）压在格子上方并溢出到相邻格，部分格子被灰色层（`ItemArt` 面板）覆盖，藏品之间互相叠压。

用户提供的运行态截图（剪贴板 PNG，1920x944）已核对：橙色条位于每个格子顶部并横向越出格子右沿，与 `NameFrameImage` 的 `(8,8) 152x34` 设计位置一致；中部偏右的半透明灰块与 `ItemArt` 的 `(10,12) 236x182` 一致。两者都远大于 `82` 的单格尺寸，属于典型的子控件溢出父控件边界且未开启裁切。

## 二、查证

1. 官方：`UWidget.Clipping` 说明「Normally content that overflows the bounds of the widget continues rendering. Enabling clipping prevents that overflowing content from being seen.」，即控件默认不裁切，溢出内容会继续渲染。
2. 官方枚举：`EWidgetClipping` 取值 `Inherit=0 / ClipToBounds=1 / ClipToBoundsWithoutIntersecting=2 / ClipToBoundsAlways=3 / OnDemand=4`；`ESlateVisibility` 取值 `Visible=0 / Collapsed=1 / Hidden=2 / HitTestInvisible=3 / SelfHitTestInvisible=4`。
3. 项目：`AuctionSettlementUIService.lua` 的 `InitializeWarehouseGrid`、`LayoutSettlementGridCells`、`ConfigureImageOnlyWidget` 三处都通过 `UGCObjectUtility.LoadClass("/IslandAuctionKing/Asset/Blueprint/Prefabs/UI/CollectibleCodexItemUI.CollectibleCodexItemUI_C")` 复用图鉴卡片当仓库格，但只收起 `ItemNameText / ValueText / IncomeText / TypeQualityText / CollectionStateText / QualityBar / CardBackground`，**遗漏 `NameFrameImage` 与 `ItemArt`**。
4. 项目尺寸：图鉴卡片设计尺寸 `256x268`，`NameFrameImage` 位于 `(8,8)` 尺寸 `152x34`，`ItemArt` 位于 `(10,12)` 尺寸 `236x182`；仓库单格 `UI.SettlementWarehouse.CellSize` 默认 `82`，两张装饰层都远大于单格。
5. 横向对比：`CollectibleCodexUIService.InitializeItemWidget` 已用 `pcall(itemWidget.NameFrameImage.SetVisibility, itemWidget.NameFrameImage, ESlateVisibility.Collapsed)` 收起名称底图，结算侧未同步这一处理。

## 三、修复

文件：`Script/Function/AuctionSettlementUIService.lua`

新增 `ApplyWarehouseCellChrome(cellWidget)`：收起 `NameFrameImage / ItemArt / QualityBar / ItemNameText / ValueText / IncomeText / TypeQualityText / CollectionStateText / CardBackground`，并对控件调用 `SetClipping(EWidgetClipping.ClipToBounds)`；枚举缺失时回退数值 `1`，`SetClipping` 不可用时打日志不中断。

调用点：

- `InitializeWarehouseGrid`：建格后调用
- `ConfigureImageOnlyWidget`：覆盖层与揭示动画层只保留图片
- `LayoutSettlementGridCells`：36 格改挂父 Canvas 后同样裁切

附带：`LayoutSettlementGridCells` 成功后 `widget.WarehouseGrid:SetVisibility(ESlateVisibility.Collapsed)`，36 格已改挂父 Canvas，空 WrapBox 不再参与渲染。

新增函数全文：

```lua
-- 收起图鉴卡片在结算仓库中不需要的装饰层，并开启裁切，避免 256x268 卡片内容画到相邻仓库格上。
-- 参数：cellWidget 结算仓库格、藏品覆盖控件或揭示动画控件。
-- 返回：无。
local function ApplyWarehouseCellChrome(cellWidget)
    ugcprint("【AuctionSettlementUIService+ApplyWarehouseCellChrome】入口 cellWidget=" .. tostring(cellWidget))
    if cellWidget == nil then
        ugcprint("【AuctionSettlementUIService+ApplyWarehouseCellChrome】出口 success=false error=CellWidgetNil")
        return
    end
    if cellWidget.NameFrameImage ~= nil then
        cellWidget.NameFrameImage:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.ItemArt ~= nil then
        cellWidget.ItemArt:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.QualityBar ~= nil then
        cellWidget.QualityBar:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.ItemNameText ~= nil then
        cellWidget.ItemNameText:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.ValueText ~= nil then
        cellWidget.ValueText:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.IncomeText ~= nil then
        cellWidget.IncomeText:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.TypeQualityText ~= nil then
        cellWidget.TypeQualityText:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.CollectionStateText ~= nil then
        cellWidget.CollectionStateText:SetVisibility(ESlateVisibility.Collapsed)
    end
    if cellWidget.CardBackground ~= nil then
        cellWidget.CardBackground:SetVisibility(ESlateVisibility.Collapsed)
    end
    local clipValue = EWidgetClipping ~= nil and EWidgetClipping.ClipToBounds or 1 -- 裁切枚举，枚举缺失时回退 ClipToBounds
    local clipOK, clipError = pcall(cellWidget.SetClipping, cellWidget, clipValue)
    if not clipOK then
        ugcprint("【AuctionSettlementUIService+ApplyWarehouseCellChrome】分支 控件不支持SetClipping error=" .. tostring(clipError))
    end
    ugcprint("【AuctionSettlementUIService+ApplyWarehouseCellChrome】出口 success=true nameFrameHidden=" .. tostring(cellWidget.NameFrameImage ~= nil) .. " itemArtHidden=" .. tostring(cellWidget.ItemArt ~= nil) .. " clipOK=" .. tostring(clipOK))
end
```
