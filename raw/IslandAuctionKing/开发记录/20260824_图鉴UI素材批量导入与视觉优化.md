## 3. 图鉴 UI 视觉与逻辑优化

1. **配色方案对齐参考图**：
   - 选中/激活状态按钮高亮：金橙色 `#FF9C2B` (`{R = 1.00, G = 0.62, B = 0.16, A = 1.00}`)
   - 未选状态按钮：质感深灰 `#2B2D31` (`{R = 0.18, G = 0.20, B = 0.22, A = 1.00}`)
   - 卡片背景：已收集与未收集分别呈现层级暗灰色，搭配对应品质色条
   - 关闭按钮：金橙高亮底色

2. **动态贴图绑定与配置表读取** (`Script/Function/CollectibleCodexUIService.lua`)：
   - 使用辅助函数 `GetCodexTexture(key, fallbackPath)`，优先通过 `AuctionConfig.GetString("UI.Codex.Texture." .. key)` 动态获取配置表贴图路径
   - 在图鉴初始化时调用 `ApplyVisualTheme` 函数安全绑定各面板的贴图纹理
   - 保持全部控件契约与 RPC 事件绑定完整
