# 非运行辅助文件索引与调用规范

> 类型：通用知识 / 治理规范
> 主题：非运行辅助文件 / 索引 / 查阅 / 调用
> 适用范围：所有地图项目；网页、Python、文档、报告、截图及其他与地图运行无关的文件
> 证据状态：用户明确要求 / 仓库工程约定
> 来源：本次会话（2026-09-14）用户要求“辅助文件即使不在项目中也能正常被相关联问题索引、查阅、调用”
> 更新时间：2026-09-14
> 关联主题：知识库分层与索引隔离、资源导入与路径规范、蓝图与 MCP 写入流程、调试备份存放
> 排除范围：蓝图、Lua、项目运行所需导入资产等运行文件的项目部署；`raw/docs/` 原始资料内容
> 官方依据：知识库文件索引和调用契约属于仓库工程约定，官方未覆盖

## 一、核心结论

非运行辅助文件不放入 UGC 工程，但不能成为“孤立文件”。每个文件必须同时满足：

1. **可发现**：有稳定登记项，登记绝对路径和精确关联实体。
2. **可查阅**：登记用途、证据状态、查阅入口和依赖，相关问题先查索引再读文件。
3. **可调用**：登记可复制执行的入口、参数、输入、输出和失败处理；调用使用绝对路径，不依赖项目目录。

## 二、存放与登记位置

| 文件范围 | 文件实际位置 | 登记位置 |
| --- | --- | --- |
| 通用网页、Python、文档、模板、截图 | `备份\<ProjectName>\<YYYYMMDD>_<Theme>\` 或 `raw\知识\通用\<领域>\` | 对应领域 `000_目录.md` 或关联 Raw 页 |
| 项目专属网页、Python、文档、报告、截图 | `备份\<ProjectName>\<YYYYMMDD>_<Theme>\` | `raw\<ProjectName>\000_项目索引.md` 或 `raw\<ProjectName>\开发记录\000_辅助文件索引.md` |
| 一次性临时文件 | 知识库备份主题目录 | 登记用途和清理状态；完成后删除或标记已归档 |

`备份/` 不进入全局 Wiki 正文，但登记页必须保留绝对路径，使项目索引、领域目录和相关问题能够反向定位实际文件。

## 三、登记项模板

在对应索引页追加以下表格行或等价 Markdown 小节：

```markdown
### AUX-YYYYMMDD-001 <文件主题>

- 文件绝对路径：`D:\知识库\和平精英绿洲起源\备份\IslandAuctionKing\20260914_Auxiliary\Example.py`
- 文件类型：Python / 网页 / 文档 / 截图 / 其他
- 关联实体：完整 API、函数名、资产路径、配置行名、错误文本、功能主题
- 用途：一句话说明解决的相关问题
- 查阅入口：具体 Raw 页、截图查看路径或网页文件路径
- 调用入口：`py -3 -X utf8 "D:\...\Example.py" --project IslandAuctionKing`
- 输入：参数、环境变量、前置文件或无
- 输出：文件、日志、截图、返回码或页面
- 依赖：工具、库、项目只读路径、相关文档
- 证据状态：官方确认 / 项目实测 / 经验归纳 / 推断 / 待查证
- 生命周期：临时 / 可复用 / 已归档；清理条件：<条件>
- 更新时间：YYYY-MM-DD
```

## 四、检索、查阅和调用流程

### 4.1 检索

先查 `wiki\000_索引.md` 和目标领域目录，再用完整实体检索登记页：

```powershell
$kb = 'D:\知识库\和平精英绿洲起源'
$terms = '完整函数名|资产路径|错误文本|功能主题'
rg -n $terms "$kb\wiki\000_索引.md" "$kb\raw\知识\通用" "$kb\raw\IslandAuctionKing"
```

命中登记项后，读取其“关联实体”和“文件绝对路径”；不得用目录猜测或只按 `*.py` 扫描替代登记查询。

### 4.2 查阅

- 文档：按登记的 Raw 路径读取正文，保留证据状态和适用范围。
- 截图：按登记的绝对路径查看，不把截图内容自动升格为官方结论。
- 网页：按登记的入口直接打开；若依赖资源，登记页必须列出资源绝对路径或启动目录。

### 4.3 调用

- Python：使用登记的解释器、绝对脚本路径和参数，例如 `py -3 -X utf8 "D:\...\Example.py" --help`。
- 网页：优先使用登记的本地服务命令并明确根目录；纯静态页可直接打开绝对路径。
- 文档/截图：不可执行，按登记的查阅入口调用为上下文来源。
- 调用前检查路径、依赖和输入；调用后把返回码、输出路径或错误写入对应来源记录/项目日志。

辅助文件可以读取项目文件作为输入，但不得因为被调用就把自身复制到 UGC 工程；涉及蓝图、Lua 或运行资产的实际修改仍必须回到项目 MCP 流程。

## 五、校验清单

1. 登记项的绝对路径存在，文件名合法，UTF-8 文本无 BOM。
2. 关联实体至少包含一个完整 API/函数名、资产路径、错误文本或明确功能主题。
3. `查阅入口` 和 `调用入口` 可执行或明确标注“不可执行，仅供查阅”。
4. 入口引用的依赖文件存在，且没有把 UGC 工程内的临时路径作为唯一依赖。
5. 调用命令使用绝对路径；Python、网页和文档不会写入或残留 UGC 工程。
6. 临时文件完成后删除，或在登记项中标记归档路径和保留原因。
