# FEditableTextStyle

Represents the appearance of an SEditableText

## Fields

| Name | Type | Description |
| --- | --- | --- |
| Font | [FSlateFontInfo](../FS/FSlateFontInfo.md) | Font family and size to be used when displaying this text. |
| ColorAndOpacity | [FSlateColor](../FS/FSlateColor.md) | The color and opacity of this text |
| BackgroundImageSelected | [FSlateBrush](../FS/FSlateBrush.md) | Background image for the selected text |
| BackgroundImageComposing | [FSlateBrush](../FS/FSlateBrush.md) | Background image for the selected text |
| CaretImage | [FSlateBrush](../FS/FSlateBrush.md) | Image brush used for the caret |
