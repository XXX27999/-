## 一、归档目标

让绿洲起源的 AI 协作能力**脱离单一客户端**：

1. **可恢复**：本机任一端（WorkBuddy / Codex / cc-switch 共享源）技能或 MCP 配置损坏、误删、被市场版本覆盖时，可按归档目录直接还原。
2. **可移植**：换机或换客户端时，技能包与 MCP 配置有唯一权威副本，不必逐处重装。
3. **可追溯**：每份归档都有绝对路径、来源绝对路径、字节数与 SHA256，可判定漂移。
4. **可持续**：后续新增的技能 / 插件 / MCP 一律进入本目录，不再散落在客户端私有目录。

### 7.1 校验

```powershell
# 逐文件比对归档完整性（应无 FAIL 输出）
$root = 'D:\知识库\和平精英绿洲起源\工具\AI配置归档'
Get-Content "$root\归档记录\校验清单_SHA256.txt" | Where-Object { $_ -notmatch '^#' -and $_.Trim() } | ForEach-Object {
  $p = $_ -split '\s+'
  $f = Join-Path $root $p[1]
  if (-not (Test-Path $f)) { "MISSING $($p[1])" }
```
