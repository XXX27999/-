# FEditableTextBoxStyle

Represents the appearance of an SEditableTextBox

## Fields

| Name | Type | Description |
| --- | --- | --- |
| BackgroundImageNormal | [FSlateBrush](../FS/FSlateBrush.md) | Border background image when the box is not hovered or focused |
| BackgroundImageHovered | [FSlateBrush](../FS/FSlateBrush.md) | Border background image when the box is hovered |
| BackgroundImageFocused | [FSlateBrush](../FS/FSlateBrush.md) | Border background image when the box is focused |
| BackgroundImageReadOnly | [FSlateBrush](../FS/FSlateBrush.md) | Border background image when the box is read-only |
| Padding | [FMargin](../FM/FMargin.md) | Padding |
| Font | [FSlateFontInfo](../FS/FSlateFontInfo.md) | Font family and size to be used when displaying this text. |
| ForegroundColor | [FSlateColor](../FS/FSlateColor.md) | The foreground color of text. |
| BackgroundColor | [FSlateColor](../FS/FSlateColor.md) | The background color applied to the active background image |
| ReadOnlyForegroundColor | [FSlateColor](../FS/FSlateColor.md) | The read-only foreground color of text in read-only mode. |
| HScrollBarPadding | [FMargin](../FM/FMargin.md) | Padding around the horizontal scrollbar |
| VScrollBarPadding | [FMargin](../FM/FMargin.md) | Padding around the vertical scrollbar |
| ScrollBarStyle | [FScrollBarStyle](../FS/FScrollBarStyle.md) | Style used for the scrollbars |
