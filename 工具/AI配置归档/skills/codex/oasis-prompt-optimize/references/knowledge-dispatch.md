# 检索、回写与派发提示词

仅在任务需要知识库检索、回答后回写、或多开子任务时读取本页。

## 检索

提示词必须要求 L0 → L1，再按条件扩展 L2/L3：

1. L0：`wiki\000_索引.md` 与目标领域 `raw\知识\通用\<领域>\000_目录.md`
2. L1：精确命中的 Raw 主文档
3. L2：仅主文档声明的直接依赖
4. L3：官方核验、冲突、待查证、API/生命周期/端侧、蓝图写入或项目证据

项目问题先读 `raw\<项目名>\000_项目索引.md`，不扫描其他项目。`wiki\` 只是导航；详细正文在 `raw\知识\通用\` 或 `raw\<项目名>\`。`raw\docs\` 只读。

检索实体优先完整 API/函数名、蓝图或资产路径、错误原文、配置行名。同义词只用于第二轮。禁止用「UI」「脚本」「错误」直接扫全库。

事实优先级：`raw/docs/api` → `raw/docs/wiki` → `raw/知识/通用` → `raw/docs/ai` → `raw/<项目名>` → `$sq-skill`。优先级不替代适用范围：项目实测只证明该项目结果，不能单独改写官方 API 定义。

## 回写

提示词应要求回答后只做一次增量自检。没有新事实、纠正、项目证据、来源记录或待查证项时，回复「无需回写」。

有内容时：

- 通用知识：`raw\知识\通用\<领域>\`
- 项目数值、资产、DataTable 行、蓝图/UI 回读、截图、日志：`raw\<项目名>\`
- 新 Raw 必须在 Wiki 或目录登记，并与至少一个直接关联页互链
- `wiki\概念\` 和 `wiki\来源\` 只建短索引，不写完整教程、代码或日志
- 页首记录类型、主题、适用范围、证据状态、来源、更新时间、关联主题、排除范围、官方依据
- 冲突保留双方来源，禁止静默覆盖
- 文件 UTF-8 无 BOM；禁止改 `raw\docs\`

详细规则入口：`raw\知识\通用\知识库治理\003_准确性与关联性读取写回规范.md`。

## 技能调用

不要在每个提示词里无条件堆技能：

- `$oasis-official-docs`：API 存在性、参数、生命周期、端侧、官方 Wiki 机制
- `$sq-skill`：官方未覆盖的社区经验
- `$ugc-log-bug-analyzer`：崩溃、异常、PIE 失败、端侧差异、日志定位
- `$oasis-ui-screenshot`：编辑器 UI 截图，不负责改资产
- `$oasis-image-import`：批量导图
- `$oasis-dev-record`：用户消息含 `（记录）` 或明确要求开发记录
- `$ui-ux-pro-max`：新 UI 设计预览

同时命中社区经验和日志时，顺序是 `$sq-skill` → `$ugc-log-bug-analyzer`。工具或资料缺失必须写明原因。

## 子任务派发

派发词必须自带文件边界，不能让子任务自己扩大范围：

- 可改文件、禁止文件、只读资料
- 输入、验证命令、返回格式：绝对路径、关键符号、验证输出、未解决问题
- 多个子任务不得同时改同一 Lua、蓝图或 DataTable
- 蓝图/配置表写入仍走 MCP PRV，不能用子代理绕过
- 默认继承当前父级模型，禁止写死 `gpt-5.6-luna`
- 未获用户明确授权时，不要把任务改写成 Sol + Luna 分工

主任务提示词还要写清：子任务失败由主任务收回或改派；两个任务争同一文件时只留一个负责写入。
