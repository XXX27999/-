   - 正文: 「放置了盒体触发器 + 写了 Lua 脚本但车子不刷新」最常见的原因是：
- 触发器没有正确绑定 Overlap 事件；
- Lua 脚本没有实际调用刷车 API；
- 刷车 API 在客户端调用，但需要在服务器端执行。
建议先用蓝图验证触发器事件是否触发，再逐步接入 Lua 脚本和刷车逻辑。
