## 一、核心判据：属性不一定跨局保存

写"限时权益"（限时卡、天气、buff、每日次数）之前，**必须先确认该属性是否在工程自己的持久化名单里**。

pet_paradise 的权威名单是 `Script\gamemode\PlayerExitGame.lua` 的 `PlayerAttributeNames`（L10-18），共 25 项，含 `WorkIncome`、`WorkDouble`、`WorkMaxCount` 等。

**不在名单里的属性，退出重进一律归零。** 实测反例：`WorkIncomeTime`（打工收益卡截止时间戳）不在名单里，`PlayerExitGame.PlayerAttributeNames` 只有 `WorkIncome`；因此只写 `WorkIncomeTime` 的限时卡权益，退出重进即丢失。

## 二、错误写法与正确写法

**错误（只写运行时属性）**：

```lua
local nowTimeStamp = TimeUtils.GetCurrentTimeSec()
local curDeadline = UGCAttributeSystem.GetGameAttributeValue(PlayerPawn, 'WorkIncomeTime') or 0
UGCAttributeSystem.SetGameAttributeValue(PlayerPawn, 'WorkIncomeTime', curDeadline + 24 * 3600)
```

症状：当场生效、退出重进消失；且"其他道具能正常保存"具有强误导性——只有依赖**非持久化属性**的权益会丢。

**正确（属性 + 存档键双写，且以存档键为准）**：

```lua
WorkTimedCardHelper.ActivateTimedCard(playerOwner, archiveKey, attrName, durationSec)
-- 内部：ControllerExitGame.UpdatePlayerArchive(...) 写 playerData[archiveKey] = nextEndTime
--      再 AttributeHelper.setValue(ownerPawn, attrName, 1)
WorkTimedCardHelper.RefreshTimedCardState(playerOwner, archiveKey, attrName)
-- 登录/重进时用存档键反推属性，过期则清零存档键
```

要点：
1. 存档键保存**绝对结束时间戳**，续期时以 `max(存档结束时间, now)` 为起算点，天然支持叠加。
2. 恢复路径必须存在且被登录流程调用（pet_paradise：`RefreshAllWorkCardStates` 在登录时刷新）。
3. 存档写入统一走 `ControllerExitGame.UpdatePlayerArchive`，不要各自 `SetPlayerArchiveData`。
4. 属性只作运行时镜像；**唯一真值是存档键**。

## 三、排查顺序（症状 → 动作）

1. 症状"退出重进权益消失，其他道具正常" → 先查该权益依赖的属性是否在持久化名单里。
2. 属性不在名单 → 不要往名单里加属性了事（名单是全局口径，加错会污染其他逻辑）；应改为**存档键 + 属性镜像**。
3. 属性在名单里但仍丢失 → 查 `PlayerAttributeZeroAllowedMap`：合法可归零的属性被判成"读取失败"会被默认值覆盖（见 [[2026-09-16_商业化测试用例核查与整改]]`BoostNum` 案例）。
4. 恢复路径写了但无效 → 检查**写入端是否真的写过存档键**（本次事故正是"恢复端齐全、写入端缺失"）。

## 四、物品本身的持久化是另一件事

道具（ItemV2）能否跨局保存取决于物编的持久化配置与 `UGCBackpackSystemV2` 的持久化数据，与属性/存档键是两条独立链路。判断"卡片不继承"时先分清是**权益丢了**还是**道具丢了**：前者查属性/存档键，后者查物编持久化。官方接口 `GetBackpackPersistData(Player, ContainsNoPersist)`（同一 API 页）可用于只读分析持久化数据规模与是否被排除。

## 五、API 依据

- `UGCBackpackSystemV2.GetBackpackPersistData`（服务器）— 获取背包完整持久化数据（只读）。
- `UGCBackpackSystemV2.IsCellCapacityFull(Player)`（服务器&客户端）— 背包格子是否已满；配套 `GetCellItemCount`/`GetCellCapacity`/`GetMaxCellCapacity`。
