## 核心结论

1. `双击运行本地同步.cmd` 会调用 `tools\Sync-OasisDocs.ps1`，先在 `D:\oasis-skill-plus` 执行 `node src/cli.mjs sync-all`，成功后再完整替换 `raw/docs/wiki` 与 `raw/docs/api`。
2. 退出码 `-1073740791` 不是 PowerShell 业务异常，而是 Node 进程崩溃。对应 Windows NTSTATUS `0xC0000409`（`STATUS_STACK_BUFFER_OVERRUN`）。此时 Wiki 可能已经写完，知识库镜像不会开始。
3. 2026-09-11 实测：Wiki 同步完成（323 词条，新增 9、更新 18、删除 1、下载图片 102），API 目录 4/4 完成后，详情停在 `2734/6196 (44%)` 崩溃。
4. 修复后的同步器改用 `src/http-client.mjs` 原生 HTTP、20 秒超时、429/5xx/超时重试、默认 4 路并发，并在抓到每条 API 详情后立即写盘。
5. 远端已经拉成功时，可用 `-SkipRemote` 只镜像，避免再跑一次会崩的全量抓取。

## 可执行步骤

### 正常全量同步

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\知识库\和平精英绿洲起源\tools\Sync-OasisDocs.ps1"
```

或双击 `D:\知识库\和平精英绿洲起源\双击运行本地同步.cmd`。

成功标志：

- 控制台出现 `Wiki 同步完成。` 和 `API 同步完成。`
- 随后出现 `Mirror verified` 与 `[DONE] Local official docs synced and mirrored successfully!`

### 远端已成功、只需回填知识库

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\知识库\和平精英绿洲起源\tools\Sync-OasisDocs.ps1" -SkipRemote
```

该开关不会再调用 `node src/cli.mjs sync-all`，只复制 `D:\oasis-skill-plus\docs\wiki` 和 `docs\api`。

### 只补 API

Wiki 已成功、只需重跑 API 时，在同步仓库执行：

```powershell
cd D:\oasis-skill-plus
node src/cli.mjs sync-api
```

完成后再用 `-SkipRemote` 镜像到知识库。

## 常见错误

- 把 `-1073740791` 当成 PowerShell `throw` 的业务错误。若没有 `同步失败：...` 中文行，就是 Node 自己崩了。
- Wiki 成功后立刻再双击全量同步。Wiki 已新、API 未完成时，应先修同步器或只跑 `sync-api`。
- 用旧的 `raw/docs` 当“最新官方文档”。镜像脚本只有远端 `sync-all` 成功后才会替换；崩溃时知识库仍是上一份完整镜像。
- 在 API 详情阶段用 12 路 `fetch` 把全部正文堆内存。Node 24 on Windows 上会在约四成进度崩溃。
