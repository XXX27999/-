# 称号3DUI架构重构

> 日期：2026-06-24  
> 功能：将称号3DUI从「单一通用动态Widget」改为「按需挂载/卸载专用Widget」

---

## 一、架构变更

### 旧方案
- Pawn 创建时（`ReceiveBeginPlay`）挂载通用 `ChenHao.lua` widget
- Widget 内部通过定时器轮询 `GlobalSelectedTitleMap`，动态读表加载纹理
- 问题：传送超时后远程 Pawn 脱离相关性，widget 被引擎清理后不会自动重建

### 新方案
- 选中称号时：`AddObjectPositionUI` 挂载同名专用 Widget（`GeRenXingXi/ChenHao/{TitleName}.{TitleName}_C`）
- 取消/切换时：`RemoveObjectPositionUI` 卸载旧 Widget
- 蓝图设好图片，脚本只保留空壳（`Construct` → `LuaInit`）
- 客户端 5 秒定时器 `RefreshTitleWidgets` 遍历 `GlobalSelectedTitleMap`，强制重挂载，解决远距离引擎清理后不重建问题

## 三、问题与解决方案

### 问题1：UGameplayStatics.GetPlayerCameraManager 不存在
- **原因**：Oasis 没有 `UGameplayStatics` 全局表
- **解决**：改用 `UGCGameSystem.GetLocalPlayerController().PlayerCameraManager`
- **验证**：`LuaHelper/Source/Lua/PlayerCameraManager.lua#L160` 有 `GetCameraLocation`

### 问题2：UGCObjectUtility.IsValid 不存在
- **原因**：API 名称错误
- **解决**：改为 `UGCObjectUtility.IsObjectValid(Obj)`
- **验证**：`LuaHelper/Source/Lua/UGCObjectUtility.lua#L101`

### 问题3：传送后 GetTargetActor() 返回 nil
- **原因**：传送过程中 ObjectPositionWidget 的绑定暂时断开
- **解决**：新增 `GetValidPawn()` 层，成功时缓存到 `self._cachedPawn`，失败时回退到缓存并用 `IsObjectValid` 验证

### 问题4：传送离开超 10 秒后回来，远程 Pawn 称号消失
- **原因**：引擎相关性系统清理了远程 Pawn 上的 widget
- **解决**：客户端 5 秒定时器 `RefreshTitleWidgets` 遍历 `GlobalSelectedTitleMap` 强制 `SetActiveTitleWidget`（内部先卸载再挂载）

### 问题5：称号缩放异常（越远越大，盖住角色）
- **原因**：3D UI 默认随角色等比缩放，但 world space 下远处角色缩小导致称号相对变大
- **解决**：Tick 中计算 `Scale = ReferenceDistance / Distance`，距离越远缩放越小

### 问题6：缩放对自己无效
- **原因**：本地玩家摄像机紧贴角色，距离≈0，Scale 恒为 clamp 上限 3.0
- **解决**：判断 `Pawn == LocalPawn` 时固定 `SetRenderScale({1.0, 1.0})`

### 问题7：称号偶尔突然变大一下
- **原因**：`GetCameraLocation` 跳变（传送、视角切换）导致计算突变
- **解决**：每帧限制 `MaxDelta = 0.3`；`Construct` 中立即设初始 Scale

## 五、关键代码模式

### Pawn 上挂载/卸载称号 Widget

```lua
function UGCPlayerPawn:SetActiveTitleWidget(TitleName)
    self:ClearActiveTitleWidget()
    if not TitleName or TitleName == "" then return end
    local WidgetPath = UGCGameSystem.GetUGCResourcesFullPath(
        'Asset/Blueprint/Prefabs/UI/GeRenXingXi/ChenHao/' .. TitleName .. '.' .. TitleName .. '_C'
    )
    self.ActiveTitleWidgetIndex = UGCWidgetManagerSystem.AddObjectPositionUI(
        self, WidgetPath, { X = 0, Y = 0, Z = 100 }, true, false, false, true
    )
end

function UGCPlayerPawn:ClearActiveTitleWidget()
    if self.ActiveTitleWidgetIndex then
        UGCWidgetManagerSystem.RemoveObjectPositionUI(self, self.ActiveTitleWidgetIndex)
        self.ActiveTitleWidgetIndex = nil
    end
end
```

### Widget 距离反比缩放 + 增量限制

```lua
function Widget:Tick(MyGeometry, InDeltaTime)
    local Pawn = self:GetTargetActor()
    if not Pawn then return end
    local LocalPC = UGCGameSystem.GetLocalPlayerController()
    if not LocalPC then return end
    local LocalPawn = LocalPC:K2_GetPawn()
    if LocalPawn and Pawn == LocalPawn then
        self.Image:SetRenderScale({ X = 1.0, Y = 1.0 })
        self._lastScale = 1.0
        return
    end
    local TargetPos = Pawn:K2_GetActorLocation()
    local CamPos = LocalPC.PlayerCameraManager:GetCameraLocation()
    local Distance = math.sqrt((TargetPos.X-CamPos.X)^2 + (TargetPos.Y-CamPos.Y)^2 + (TargetPos.Z-CamPos.Z)^2)
    if Distance <= 0 then return end
    local TargetScale = ReferenceDistance / Distance
    if TargetScale < 0.3 then TargetScale = 0.3 end
    if TargetScale > 3.0 then TargetScale = 3.0 end
    local MaxDelta = 0.3
    local PrevScale = self._lastScale or TargetScale
    if TargetScale > PrevScale + MaxDelta then TargetScale = PrevScale + MaxDelta
    elseif TargetScale < PrevScale - MaxDelta then TargetScale = PrevScale - MaxDelta end
    self._lastScale = TargetScale
    self.Image:SetRenderScale({ X = TargetScale, Y = TargetScale })
end
```

### 客户端定时器重挂载远程称号

```lua
function UGCPlayerController:RefreshTitleWidgets()
    if self:HasAuthority() then return end
    _G.GlobalSelectedTitleMap = _G.GlobalSelectedTitleMap or {}
    for strKey, titleName in pairs(_G.GlobalSelectedTitleMap) do
        if titleName and titleName ~= "" then
            local Pawn = UGCGameSystem.GetPlayerPawnByPlayerKey(tonumber(strKey))
            if Pawn and Pawn.SetActiveTitleWidget then
                Pawn:SetActiveTitleWidget(titleName)
            end
        end
    end
end
```
