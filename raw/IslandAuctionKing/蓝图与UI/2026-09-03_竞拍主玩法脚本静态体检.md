## 结论

主玩法服务端阶段机、出价/锁定/道具 RPC 白名单和 GameMode 薄包装静态对齐。发现一处会直接卡住竞拍 UI 初始化的控件契约：`AuctionTestUIService.REQUIRED_WIDGET_NAMES` 仍强制 `PhaseText`，但当前 `AuctionTestUI.lua` 的 `---@field` 列表没有 `PhaseText` / `RoundSubtitleText`。

已把 `PhaseText` 从必填契约中移除，刷新公共状态时改为 `FindNamedWidget` 可选查找；副标题缺失时轮次文案写入 `RoundText`。

## 已核对链路

- `UGCPlayerController:GetAvailableServerRPCs()` 返回 `"KHDRPC_Call","FWDRPC_Call"`
- 客户端请求：`CallUnrealRPC(..., "KHDRPC_Call", "ServerRPC_*")`
- `CF_KHDRPC` 白名单：Submit / Lock / PrivateState / SelectHouse / SelectPropGroup / UseProp / SelectCharacter
- `CF_FWDRPC` 白名单：PrivateState / PublicState / OperationResult / PropIntel / SettlementUI
- `UGCGameMode:Auction_*` 与 `AuctionGameService` 同名业务一一对应
- `UGCGameState:ReceiveBeginPlay` 调用 `AuctionConfig.LoadFromTable`
- 阶段 Tick：Preparing -> StartSingleWarehouse；Bidding -> AutoLockTimedOutBids；Reveal -> BeginFinal；Final -> FinishGame
- `OpenSkillPanelButton` 仅作为可选角色技能入口；缺失时折叠，不阻断主 UI

## 冲突保留

官方 Wiki 示例要求在 `GetAvailableServerRPCs()` 直接注册 `ServerRPC_*`。本项目继续使用 KHDRPC 包装入口。2026-08-28 日志曾出现客户端 forbidden call；后续 MCP 删除过蓝图 `KHDRPC_Call`。本轮无新 PIE 日志，不宣称 RPC 已恢复或已失效。
