> 类型：通用知识
> 主题：UI / CanvasPanelSlot 位置尺寸准确性
> 适用范围：全局通用（绿洲 UMG 编辑器）

## 结论

绿洲固定布局 UI 的位置尺寸，必须同时满足五件事，缺一都会看起来“摆不准”：

1. 设计舞台固定，通常为 `SizeBox` 1920×1080，外层 `ScaleBox.Stretch=ScaleToFit`。业务坐标只写设计舞台像素，不写截图像素，也不写被 CSS `transform: scale()` 放大后的预览像素。
2. 先读 `Anchors` 和 `Alignment`，再解释 `Position/Size`。`Anchors.Min==Max` 时 Offsets 是 `(X,Y,W,H)`；四向拉伸时 Offsets 是四边留白，`GetSize()` 可能为 `(0,0)`，这不是控件损坏。
3. 位置尺寸只通过 `Slot.SetPosition` / `SetSize` / `SetAnchors` / `SetAlignment` 写入。`widget_slot` 实测不能写 Position/Size。写入后必须 MCP 回读，不能用 API 返回 `None` 当成功。
4. 控件必须落在自己的父容器和用户标注框内。父容器改了以后，子控件要用相对坐标重排，不能继续沿用旧绝对坐标。重复槽位要把图片层、点击层、文本层、状态叠加层分开量、一起验收；用户只框一格时，该格是模板而不是唯一修改目标。
5. 贴图框尺寸优先等于导入素材像素，或按素材比例等比缩放。不要把按钮框拉得比素材还大再靠拉伸填满，那会让点击区和视觉区错位。
6. 用户参考图、切图对照和编辑器 UI 修改一律以 1920×1080 为基准。参考图若不是该尺寸，先改成 1920×1080 再量坐标；禁止继续按 1639×960 或其他旧舞台尺寸改编辑器控件。

## 推荐测量顺序

0. 确认参考图和编辑器设计舞台都是 1920×1080。参考图不是该尺寸时，先备份原图，再把参考图改成 1920×1080；编辑器侧 SizeBox.WidthOverride=1920、HeightOverride=1080。
1. 回读父容器：`pos/size/anchors/align/vis/z`。
2. 回读目标控件同样字段，确认父级不是拉伸槽。
3. 若有网页预览：舞台必须 1920×1080，HTML `id` 与控件名同名，且预览没有对主界面做非等比 `transform: scale()`，预览坐标才能直接当 `SetPosition/SetSize` 入参。主界面 HUD、贴边条、斜切页签不满足这三条时，先回读底图锚点和 Offsets，再把文字放进底图内容区；详见 [绿洲 UMG 文字、透明点击层与贴边锚点摆放](绿洲UMG文字透明点击层与贴边锚点摆放.md)。若预览对主界面做了非等比 `transform: scale()`，弹窗不要跟着那段缩放走，应按素材原尺寸居中。
4. 若有用户红/绿框：用未裁切的内部格子或标题控件做锚点，把框换算到画布；禁止用整张截图宽高直接比例映射。
5. 写入 6 列/网格时，用 `start + (n-1)*step + size <= bound` 校验右缘和底缘，并预留 1–2px 内边。
6. FlaUI 设计态截图只证明编辑器可见结果；涉及初始化、配置表、蓝图结构时仍要重新 PIE。

## 常见误差来源

- 把 1620×971 旧舞台坐标直接乘到 1920×1080，弹窗会整体偏大。
- 参考图仍是 1639×960，却把切图或控件硬拉满 1920×1080，比例会变形，后续对照会越改越偏。
- 用用户裁切图的外框当缩放基准，红框会被放大到比现有格子还大。
- 只改图片层，不改 Button 点击层。
- 用户只框一格/一席，却只改被框住的那一个，未把相对偏移复制到同名序号控件族。
- 用画布绝对坐标把已对齐席位的数字贴到另一席，名称和报价会与卡头脱节。
- 把选中勾、角标做成整行按钮同尺寸，勾会出现在左侧图标上而不是右侧标记位。
- 设计态绑了导入贴图，运行时 Lua 仍用品质占位表覆盖。
- 标题、页脚和格子共用同一行，后改格子时没复核标题底边。
- 设计态 `Collapsed` 的估价文本被当成运行时控件，真正显示在另一个 TextBlock 上。
- 空 `UImage.Brush.ResourceObject` / `UBorder.Background.ResourceObject` 在编辑器设计态会画成白矩形，即使运行时 Lua 会 `SetBrushFromTexture`。设计态必须直接写 `Brush.ResourceObject` 或 `Background.ResourceObject`，并设 `DrawAs=Image(3)`、白色 Tint。
- 绿洲 UI 编辑器设计器仍可能预览 `Collapsed` 文本。旧说明层除了 `Visibility=Collapsed`，必要时移出画布；动态道具图不要长期停在画布外，否则运行时 `SetBrushFromTexture` 会对空槽。
- TextBlock 默认文案若写成字面 `\\n`，设计态和运行时都会把反斜杠 n 当字符显示。换行必须写入真实换行符，并打开 `AutoWrapText`。
- 按网页 CSS 绝对像素写主界面页签/匹配文字，忽略底图已是右上/右下/左下锚点，字会被挤出内容带。
- 透明点击层和文字共用按钮几何中心；斜切页签上字不在可见标题区。
- 用户已在设计器里摆正并保存后，仍用上一轮估算坐标或运行时 ApplyLayout 旧默认值覆盖。

## 重复槽位：一格示例等于全族模板

证据状态：项目实测归纳。官方 API 只提供单控件 `SetPosition/SetSize`，没有“按示例复制全族”的接口。

用户标注常常只框一格，并写“其余按这个示例”。该格是几何模板，不是唯一写入目标。

执行顺序：

1. 识别控件族：同一前缀加序号，例如图片 `PropImage01..N`、点击区 `CellButton01..N`、文本 `Name01..N`。
2. 回读已验收实例，得到它相对父卡/标题/行容器的偏移和尺寸，不要使用画布绝对 XY 当模板。
3. 对每个兄弟实例：`pos = localOrigin + templateOffset`，`size = templateSize`。
4. 回读必须包含首个、用户标注个、末个。只回读被框住的那一个，不能声称全族已对齐。

相对复制只统一卡内关系（标题到图片间距、图片到点击区内缩、勾相对行右缘）。各卡自己的卡头原点、暗槽 Y 仍然不同，不能把席位 4 的绝对坐标写到席位 1。

## 重复槽的四层，必须分开量

同一暗槽通常有四层独立 Slot，对齐一层不等于对齐整槽：

| 层 | 典型职责 | 常见错误 |
| --- | --- | --- |
| 图片层 | 更小、内缩，贴导入素材像素或绿框 | 只改了被框的那一格 |
| 点击层 | 更大，覆盖序号、图片、报价 | 与图片不同尺寸时漏改 |
| 文本层 | 名称、报价、卡头标题 | 图片对齐后名称仍与其他席不一致 |
| 状态叠加层 | 选中勾、角标、数量 | 继承整行 Size，勾跑到左侧图标上 |

图片层与点击层可以故意不等大。用户绿框和红框同时出现时，分别写入对应层，禁止把两层写成同一个 Rect。

## 叠加层先移位，再用显隐

位置错了先 `SetPosition/SetSize`。不要先 `Collapsed` 或删除后再补控件。显隐只由选中/数量等运行时状态控制，例如未选中 `Collapsed`、选中 `HitTestInvisible`。

叠加层默认对齐方式不要抄整行按钮；应对所在行做镜像或贴边，并确认 `inside=true`。

## 设计态贴图和运行时贴图是两条链路

- 设计态空 `Brush.ResourceObject` 会画白块，导入素材后必须写设计态画刷。
- 运行时 Lua 若继续 `SetBrushFromTexture(品质占位)`，会盖掉设计态图。
- DataTable 的 object 贴图列内部名是 `FriendlyName_序号_GUID`。脚本要先读显示名再扫前缀；列值为空时才回退占位图。

对象列字段名规则见 [配置表与结构体的MCP编辑](../工具与流程/配置表与结构体的MCP编辑.md)，不要把某张表的具体 GUID 写成通用默认值。

## Python 写入时的控件字段陷阱

证据状态：项目实测归纳（IslandAuctionKing AuctionTestUI，2026-09-04）。官方 API 文档覆盖 UCanvasPanelSlot.SetPosition/SetSize，不覆盖绿洲 Python 绑定里 FVector2D 与 FSlateFontInfo 的具体构造方式。

1. 二维坐标构造函数是 `ue.FVector2D(x, y)`。`ue.Vector2D` 不存在，写入会在事务里抛错并回滚。
2. 编译蓝图用模块函数 `ue.compile_blueprint(bp)`。`bp.compile_blueprint()` 不是对象方法。
3. `TextBlock.Font` 是 `UScriptStruct`（`FSlateFontInfo`），只能 `font.set_field("Size", n)` / `set_field("FontObject", roboto)` / `set_field("TypefaceFontName", "Bold")`。不要写 `f.Size = n; w.Font = f`，这会把 `FontObject` 清成 `None`、`Size` 变成 0，文字消失。
4. 未勾选 `bIsVariable` 的控件不会出现在 `widget.Name` 上。运行时用 `widget:GetWidgetFromName("Name")` 读取；若 Lua 要长期持有，写入前把 `bIsVariable=True`。
5. 提示文字若与右侧按钮重叠，先缩短文本 Slot 宽度并打开 `AutoWrapText`，让换行发生在按钮之前，不要靠加高把字推到按钮下面。
6. 列表槽文本和详情区文本是两层。用户红框要名称、绿框要名称加作用时，分别改对应 TextBlock，不要把详情格式写进每一个列表槽。
