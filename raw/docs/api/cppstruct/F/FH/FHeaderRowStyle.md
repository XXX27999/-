# FHeaderRowStyle

Represents the appearance of an SHeaderRow

## Fields

| Name | Type | Description |
| --- | --- | --- |
| ColumnStyle | [FTableColumnHeaderStyle](../FT/FTableColumnHeaderStyle.md) | Style of the normal header row columns |
| LastColumnStyle | [FTableColumnHeaderStyle](../FT/FTableColumnHeaderStyle.md) | Style of the last header row column |
| ColumnSplitterStyle | [FSplitterStyle](../FS/FSplitterStyle.md) | Style of the splitter used between the columns |
| BackgroundBrush | [FSlateBrush](../FS/FSlateBrush.md) | Brush used to draw the header row background |
| ForegroundColor | [FSlateColor](../FS/FSlateColor.md) | Color used to draw the header row foreground |
